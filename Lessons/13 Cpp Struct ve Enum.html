Struct ve Enum

Struct Nedir?

Struct, C programlama dilindendir beri var olan ve C++ ile geliştirilmiş bir değişken tipi tanımlama aracıdır. Aynı sınıflar gibi hem içerisinde değişkenler, fonksiyonlar ve başka Struct'lar yazabiliyor hemde erişim belirteçleri ile de OOP özelliklerinden yararlanabilinmektedir.

Struct Kullanımı

Struct aracını kullanmak için struct + structIsmi yapısı kullanılır ve ardından kod blokları açılır. Daha sonra kod bloklarında özellikler tanımlanabilir. Ardından aynı sınıfıntan nesne oluşturur gibi Struct'lardan yani yapılardan nesne oluşturulur.
Örnek olması için bir vatandaş yapısı oluşturalım. Bir vatandaşın; ismi, soyismi, evi adresi ve yaşı gibi bilgiler bulunur. Gelin beraber bu sistemi kodlayalım:


#include <iostream>

using namespace std;

struct vatandas // Vatandaş yapımızı oluşturduk
{
    string vatandasIsim; // Vatandaşın isim bilgisi, ayrıca özellik tanımlarken bu şekilde tanımı yapılır. Tanımın hemen ardından noktalı virgül konulur
    string vatandasSoyisim; // Vatandaşın soyismi bilgisi

    string vatandasEvAdres; // Vatandaşın ev adresi bilgisi

    int vatandasYas = 0; // Vatandaşın yaş bilgisi. Ayrıca C'de yapılarda önceden tanımlı değişkenler tanımlanamıyorken C++11 standartı ile bu durum C++'da desteklenir hale gelmiştir
};

int main()
{
    vatandas ali; // Vatandaş nesnemizi oluşturduk
    ali.vatandasIsim = "Ali";
    ali.vatandasSoyisim = "Karakulak"; // Soyisim bilgisini bu şekilde atayabiliriz
    ali.vatandasEvAdres = "Izmir/Konak"; // Ali İzmir Konak'ta otursun
    ali.vatandasYas = 23; // Ali 23 yaşında olsun

    // Bilgiler hazır şimdi sırayla yazdıralım...

    cout << "Vatandas " << ali.vatandasIsim << "'nin bilgileri:" << endl << endl;
    cout << "Soyismi: " << ali.vatandasSoyisim << endl;
    cout << "Ev Adresi: " << ali.vatandasEvAdres << endl;
    cout << "Yasi: " << ali.vatandasYas << endl;

    return 0;
}

Çıktı;
Hadi gelin bu örneği biraz daha geliştirilem. Ancak sizi temin ederim ki şuan yapı üzerinde değişikliklerimizi yapabilceğimizi sağlayan C++11 standartıdır. Yani C programlama dilindeki eski yapı aracını C++ nasıl bir süper araca döndürtüğüne!

Bildiğiniz üzere vatandaşlık sisteminde sizin bilgileriniz yer almakla beraber annenizin ve babanızın bilgileri olduğunu bir kısım vardır. O kısımlara bastığınızda sizin görebilceğiniz özellikler bulunur. Gelin bu sistemi geliştirelim:

#include <iostream>

using namespace std;

struct vatandas
{
    private:
        string vatandasEvAdres; // Ev adresinizi kimse göremez sizden başka

    public:
        string vatandasIsim;
        string vatandasSoyisim;

        vatandas* anaVatandas = NULL; // Bu şekilde yapı içerisinde kendi yapını kullanabilirsiniz
        vatandas* babaVatandas = NULL; // İlk başta NULL olarak tanımlayalım

        int vatandasYas = 0;
        
        void vatandasEvAdrisiniDegistir(string dogruVatandasMi, string yeniAdres) // Adres bilgisi gizli olduğunu için bir ara katman yerleştirilem
        {
            if (dogruVatandasMi == vatandasIsim) // Girilen isim ile değiştirilmek istenen vatandaşın ismi aynı mı?
            { // Aynı ise
                vatandasEvAdres = yeniAdres; // Eşitle

                cout << "Basarili bir sekilde islem tamamlandi!" << endl << endl; // Bilgilendir
            }
            else // Değil ise
                cout << "Islem red edildi. Izinsiz giris!" << endl << endl; // Bilgilendir
        };

        void vatandasBilgiYazdir() // Bilgileri yazdıralım
        {
            cout << vatandasIsim << " adli vatandasin bilgileri;" << endl << endl;
            cout << "Soyismi: " << vatandasSoyisim << endl;
            cout << "Yas: " << vatandasYas << endl;
            cout << "Ev Adresi: " << vatandasEvAdres << endl;

            // Vatandaşın temel bilgileri bu kadar. Şimdi ana ve baba kaydı varsa onlarında bilgilerini yazdıralım
            
            if (anaVatandas != NULL && babaVatandas != NULL)
            {
                cout << endl << "Ana bilgileri;" << endl;
                cout << "Adi: " << anaVatandas->vatandasIsim << endl;
                cout << "Yasi: " << anaVatandas->vatandasYas << endl;

                // Yapılardan eğer Pointer şeklinde kullanılıcaksa eğer bir eksi ve büyüktür işareti(->) ile içindeki bilgiler kullanılır. Normal şartlar her Pointer tipi gibi yıldız(*) ile bellek adresindeki bilgiyi erişirdik. Fakat C ve C++'da yapılar sıklıkla kullanıldığı için böyle bir kolaylık sağlanmıştır. Aynı mantık C++'da pek tabi sınıflar içinde geçerlidir

                cout << endl << "Baba bilgileri;" << endl;
                cout << "Adi: " << babaVatandas->vatandasIsim << endl;
                cout << "Yasi: " << babaVatandas->vatandasYas << endl;
            }
            else
                cout << "Ana veya baba kaydi girilmemistir." << endl;
        }
};

int main()
{
    // Vatandaşımızın kendisi
    vatandas ali;
    ali.vatandasIsim = "Ali";
    ali.vatandasSoyisim = "Karakulak";
    ali.vatandasYas = 23;
    ali.vatandasEvAdrisiniDegistir(ali.vatandasIsim, "Izmir/Konak");

    // Babasının ve anasının bilgileri
    vatandas ahmet;
    ahmet.vatandasIsim = "Ahmet";
    ahmet.vatandasSoyisim = "Karakulak";
    ahmet.vatandasYas = 47;
    ahmet.vatandasEvAdrisiniDegistir(ahmet.vatandasIsim, "Izmir/Karsiyaka");
    vatandas ayse;
    ayse.vatandasIsim = "Ayse";
    ayse.vatandasSoyisim = "Karakulak";
    ayse.vatandasYas = 45;

    ayse.vatandasEvAdrisiniDegistir(ahmet.vatandasIsim, "Izmir/Karsiyaka"); // Yanlış bir giriş yapalım

    ali.anaVatandas = &ayse; // Kayıtlarını girdik, Pointer şeklinde tanımladığımız için bellek adresini gönderdik
    ali.babaVatandas = &ahmet;

    ali.vatandasBilgiYazdir();

    return 0;
}

Çıktısı;
Son olarak sınıflarda olduğu gibi yapılarda yapıcılar ve yıkıcılarda kullanılabilir. Ayrıca typedef ile aynı değişken tiplerinin isimlerini değiştirebildiğimiz gibi de yapıların isimlerini değiştirebiliriz.

Union Nedir?

Union, aynı Struct yani yapılar gibi kendi içerisinde birden fazla veri türünü sahip değişkenleri depolanabilcek olan bir araçtır. Fakat önemli bir detay var ki Union Struct gibi değerlerini farklı farklı bellek kısımlarında depolarken, Union'da bu durum tek bir bellek yuvasına gerçekleşir. Tanımlama ise union + unionIsmi şeklinde yapılır.
Yani siz Union içerisinde üç adet değişken oluşturduğunuz diyelim... Normal şartlarda yapılarda bir tanımladığımız değişken diğerini etkilemez fakat Union'da tüm değişkenler tek bir bellek adresinde depolandığı için bir değişiklik tüm değişkenleri etkiler. Gelin sizeof ile gözlemleyelim bu durumu:

#include <iostream>

using namespace std;

union ornekUnion // Union'umuz
{   // Değişkenleri
    int s1;
    int s2;
    int s3;
};

struct ornekYapi // Yapımız
{   // Değişkenleri
    int s1;
    int s2;
    int s3;
};

int main()
{
    ornekUnion union1;
    ornekYapi yapi1;

    cout << "Union1'in bellekte kaplidigi yer: " << sizeof(union1) << endl;
    cout << "Yapi'in bellekte kaplidigi yer: " << sizeof(yapi1) << endl;

    return 0;
}

Çıktısı ise;
Yapının boyutu on iki bayt iken Union'nun ki neden dört bayt? Az önce konuştuğumuz gibi yapı her bir değişken için ayrı ayrı bellek bölümleri kullanırken, Union ise tüm değişkenlerini tek bir bellek bölümünde depolar. Ayrıca Union, içerisindeki en büyük RAM boyutu istiyen veri türüne göre kendisi ilk başta boyutlandırır ki bu yüzden dört baytlık yani Integer veri türünün RAM'de istediği alan miktarıdır. Long türünü yazsaydık eğer sekiz baytlık alan kaplıcak olurdu.
Gelin bu durumu bir örnek ile açıklayalım:

#include <iostream>

using namespace std;

union ornekUnion
{
    int s1;
    int s2;
    int s3;
};

struct ornekYapi
{
    int s1 = 0;
    int s2 = 0;
    int s3 = 0;
};

// Aşırımı yükleme ile yazdırma fonksiyonları
void degerleriYazdir(ornekYapi y)
{
    cout << endl << "Yapinin degiskenlerinin degeri;" << endl << endl;
    cout << "s1: " << y.s1 << endl;
    cout << "s2: " << y.s2 << endl;
    cout << "s3: " << y.s3 << endl;
}
void degerleriYazdir(ornekUnion u)
{
    cout << endl << "Union'nun degiskenlerinin degeri;" << endl << endl;
    cout << "s1: " << u.s1 << endl;
    cout << "s2: " << u.s2 << endl;
    cout << "s3: " << u.s3 << endl;
}

int main()
{
    ornekUnion union1;
    ornekYapi yapi1;

    // Değişkenlerine sırayla değerler atıyalım ve değerlerini ekrana yazdıralım
    union1.s1 = 1;
    yapi1.s1 = 1;

    degerleriYazdir(union1);
    degerleriYazdir(yapi1);

    cout << "---------------------------------" << endl;

    union1.s2 = 2;
    yapi1.s2 = 2;

    degerleriYazdir(union1);
    degerleriYazdir(yapi1);

    cout << "---------------------------------" << endl;

    union1.s3 = 3;
    yapi1.s3 = 3;

    degerleriYazdir(union1);
    degerleriYazdir(yapi1);

    cout << "---------------------------------" << endl;

    return 0;
}

Çıktı;
Gördüğünüz gibi yapılarda değişkenler birbirlerini etkilemezken Union'da tüm değişkenler etkilenir.

Enum Nedir?

Enum, kendi özel veri değelerimizi oluşturabildiğimiz araçtır.
Enum, ne yapı nede Union gibi verileri daha sonra atabilceğimiz araçlar gibi değildir. Daha çok sabit tanımlamlama ve verileri düzenleme gibi işlemlerde kullanılır. enum + enumIsmi şeklimde tanımlanır.
Örnek olması açısından girilen yaşın yaş grubunu hesaplayan bir sistem tasarlayalım:

#include <iostream>

using namespace std;

enum yasGrublari // Yaş gruplarının Enum'ları. Ayrıca sabit oldukları için büyük harfle yazılması tavsiye edilir
{
    COCUK,
    GENC,
    YETISKIN,
    ORTA_YASLI,
    YASLI
};

int main()
{
    cout << "Yasinizi giriniz: ";

    int yas;
    cin >> yas;

    yasGrublari yasGrubu; // Enum'lı veri değerlerimizi tutacak olan değişken

    // Yaş aralılları ile yaş grubunu belirleme
    if (yas <= 18)
        yasGrubu = COCUK;
    else if (yas > 18 && yas <= 25)
        yasGrubu = GENC;
    else if (yas > 25 && yas <= 40)
        yasGrubu = YETISKIN;
    else if (yas > 40 && yas <= 60)
        yasGrubu = ORTA_YASLI;
    else if(yas > 60)
        yasGrubu = YASLI;

    // Switch-Case ile de yas grubuna göre çıktı verme
    switch (yasGrubu)
    {
        case COCUK:
            cout << endl << "Yasiniz COCUK kategorisinde!" << endl;
            break;

        case GENC:
            cout << endl << "Yasiniz GENC kategorisinde!" << endl;
            break;

        case YETISKIN:
            cout << endl << "Yasiniz YETISKIN kategorisinde!" << endl;
            break;

        case ORTA_YASLI:
            cout << endl << "Yasiniz ORTA_YASLI kategorisinde!" << endl;
            break;

        case YASLI:
            cout << endl << "Yasiniz YASLI kategorisinde!" << endl;
            break;
    }

    return 0;
}

Çıktı ise;
