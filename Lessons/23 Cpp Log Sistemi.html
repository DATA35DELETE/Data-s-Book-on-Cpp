Log Sistemi

Log Nedir?

Log veya Türkçesiyle günlük; bir sistemde veya uygulamada, hangi aşamda olduğunu veya hangi kısımda hatalar çıktığını bir formatta yapımcıya bildirme sistemine denir.
Yani Log sistemi bizim için bir uygulamada neler olup bittiğini ayni bir günlük defteri gibi incelememizi sağlar. Böylelikle herhangi bir beklenmedik bir durumda program çöktüğünde neden çöktüğünü Log sayesinde nedenini anlamamıza yardımcı olur.

Log Seviyeleri

Birden fazla olduğu için birden fazla Log seviyesi vardır. Log seviyeleri bizim için çıktıların önemini ve anlamını bizlere bildirir. Aşağıdaki Log seviyelerinin anlamlarıyla beraber tabloda verilmiştir;
Seviye Anlamı
INFO Normal durumlar için kullanılır. Örnek olarak bir fonksiyonun başarılı bir şekilde çalışıp bittiğini bu şekilde bildirebiliriz.
DEBUG INFO'dan daha detaylıdır. Örnek olarak bir fonksiyona verilen parametreleri ve sonucunda ne döndüğünü belirtir.
TRACE Bir işlevi adım adım hangi işlemlerin gerçekleştirildiğinden tutunda API Key'lere kadar detaylı bir şekilde anlatan bir Log seviyesidir. Kapalı kaynak uygulamarında bu seviyenin çıktılanması ana uygulamada olmaması tavsiye edilir.
WARNING Bir fonksiyonun çalışmadığına veya istenen çıktı elde edilmediğinde kullanılır. Örnek olarak yolu yanlış verilen bir dosyayı açmak gibi...
ERROR Çoğu durumda program çökmez ama çökmesine yol açıkcak olan hataları Loglamak için kullanılır. Örnek olarak Buffer Overflow verilebilir.
FATAL Programın çöktüğü zamanlarda kullanılır. Örnek olarak işlemlerde nullptr kullanılması gibi.

Log Formatı

Log formatı, Loglamada kullanılıcak olan bir veri sırasıdır. Genel kabul görmüş bir format olmasada genelde saati, dakikası, tarih, satır numarası, seviyesi ve içeriği şekilinde bir formatta Loglama gerçekleştirilir.
2026/08/17 14:08:13, 102 [LOG SEVİYESİ] Log icerigi

Konsola Loglama

Konsola Loglamak için aşağıdaki kodlar kullanılır;

#include <iostream>
#include <time.h> // Güncel zamanı almak için gerekli C kütüphanesi
#include <string.h> // Güncel zamanı ayarlamak için gerekli C kütüphanesi(strlen için)

using namespace std;

void konsolaLogla(int satirNumarasi, char* seviyesi, char* icerigi) // Konsola Loglamak için kullanıcağımız fonksiyon
{
    time_t guncelZaman = time(0); // Güncel zamanı alıyoruz
    char* guncelZamanStr = ctime(&guncelZaman); // ctime ile zamanı bizim okuyabilceğimiz şekilde çeviririz

    for (int i = 0; i < strlen(guncelZamanStr); i++) // String'e çevirme sırasında gereksiz \n karakterini siliyoruz
        if (guncelZamanStr[i] == '\n')
            guncelZamanStr[i] = '\0';
    

    cout << guncelZamanStr <<
    ", " << satirNumarasi <<
    " [" << seviyesi << "] " <<
    icerigi; // Ardında yazdıroruz
}

int main()
{
    konsolaLogla(__LINE__,"ERROR","Beklenmeyen bir durum yasandi!");

    return 0;
}

Çıktımız ise;

Dosyaya Loglama

Konsola Loglama örneğimizin dosya versiyonu;

#include <iostream>
#include <fstream>
#include <time.h>
#include <string.h>

using namespace std;

void dosyayaLogla(ofstream *loglanacakDosya ,int satirNumarasi, char* seviyesi, char* icerigi)
{
    time_t guncelZaman = time(0);
    char* guncelZamanStr = ctime(&guncelZaman);

    for (int i = 0; i < strlen(guncelZamanStr); i++)
        if (guncelZamanStr[i] == '\n')
            guncelZamanStr[i] = '\0';
    

    (*loglanacakDosya) << guncelZamanStr <<
    ", " << satirNumarasi <<
    " [" << seviyesi << "] " <<
    icerigi; // Dosyamıza Logluyoruz
}

int main()
{
    ofstream sistemLog(".log"); // Log dosyamız

    dosyayaLogla(&sistemLog,__LINE__,"INFO","Her şey yolunda!"); // Fonksiyonu çalıştırdık

    sistemLog.close();

    return 0;
}

Klasörümüzde oluşan .log dosyasının içeriği ise;
