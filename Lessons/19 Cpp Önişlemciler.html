Önişlemciler

Önişlemciler Nedir?

Önişlemciler, programın derleme zamanından önceki zamanında kaynak kodunun programıcının tanımladığı şeklinde düzenlenmesi ve düzenlenmiş bir şekilde derlenmesine sağlıyan bir araçlar bütünüdür.
"Giriş" sayfasında bahsedilen ve "Derlenme Süreci" ana başlığı altında "Önişlemci" alt başlığında anlatılan konuya gelmiş bulunmaktayız. Bu konu aslında daha çok koşullu derleme, kodlama kolaylığı veya kütüphane ekleme gibi işlemlerde kullanılır. Koşullu derlemelerde veya işletim sistemine özel derleme sürecinde, işletim sistemlerinde özel olarak tanımlanan ve "Makro" olarak nitelendirilen elemanlar ile yapılır. Kodlama kolaylığı ise "Makrolar" ile var olur. Kütüphane ekleme ise "Başlık" dosyaların #include

#define

#define, programamızda makro tanımlamamızı sağlayan bir elemandır. Makrolar, önişlemci aşamasında kaynak kodda, makroda belirtilen veriyi direkt olarak kendi yerine yazan araçlara denir.
Örnek olması açısından Pi sayısını makro olarak tanımlayalım ve kullanalım;

#include <iostream>

#define PI 3.14f // Makromuzu tanımladık
//      |    |
//      v    v
//    İsmi Değeri

using namespace std;

int main()
{
    cout << "Pi = " << PI << endl; // Kullandık

    return 0;
}

Çıktısı ise;
Makro tanımlamak bir nevi sabit bir değişken tanımlamaya benzer... Fakat tek sıkıntısı tür kontrolünün olmamasıdır. Yani tür bağımsız tanımlı olan değeri direkt yazdırır. Bu durum bazı durumlarda programın çökmesine kadar varan hatalarla sonuçlanabilir.
Aslında önişlemcileri daha iyi anlamak şöyle bir görsel sunabiliriz;

#ifdef / #ifndef / #endif / #else

Bu elemanlar ise makroların varlığı üzerine bazı önişlemci işlemleri yapmamızı sağlayan araçlardır. #ifdef eğer makro tanımlı ise kodları dahil et, #ifndef eğer makro tanımlı değil ise kodları dahil et, #else eğer yukarıdaki #ifdef veya #ifndef makro kontrolcüleri kodlarını dahil etmezler ise bu kodları dahil et ve #endif dahil edilicek kodların sonu olarak kullanılır.
Giriş kısmında bahsettiğimiz gibi bu önişlemci araçları koşullu derleme yapabilmemizi sağlarlar. Bunuda işletim sisteminde özel tanımlı makrolar ile yaptıklarını söz etmiştik. Şimdi ise bir program yazalım. Program eğer Windows'da derlendi ise "Windows'da derlendim" yazsın, Windows'da derlenmediyse "Windows'da derlenmedim" yazsın;

#include <iostream>

using namespace std;

int main()
{
#ifdef WIN32 // Eğer WIN32 adlı bir makro tanımlı ise ki bu Widows'a özel bir makrodur

    cout << "Windows'da derlendim" << endl;

#else // Eğer WIN32 adlı makro tanımlı değilse. Koşullu derleme genelde Windows üzerinden yürür. "Windows'da isek bu değilse bu" gibi bir mantık yürütülür
 
    cout << "Windows'da derlenmedim" << endl;

#endif

// Şimdi tam tersini yazalım

#ifndef WIN32

    cout << "Dolayısıyla POSIX kütüphanesini kullanabilirim!" << endl;

#else
 
    cout << "Dolayisiyla 'windows.h' kutuphanesini kullanabilirim!" << endl;

#endif
    return 0;
}

Şimdi ise derliyelim ve çıktıları gözlemleyelim;
Daha iyi anlamak için bir görsel sunalım;

#include

#include önişlemcilerde kütüphane eklemizi sağlayan bir elemandır. Aslında yaptığı işlem belirtilen dosyayı kaynak dosyasının içerisine yerleştirmektir. Bir nevi "kütüphane" veya "eklenti" görevi görür. Bu ekleme işlemi önişlemci zamanında gerçekliştirilir. Amacı ise kodları ayrı olarak yönetmek ve kullanım kolaylığı sağlamaktır.
İlerleyen sayfalarda daha net göreceğiz fakat şimdilik bir C++ başlık dosyası ".hpp" (".h" C programlama diline aittir fakat C++ programlama dilinde de kullanılabilir) oluşturalım ve ana programamıza ekliyerek kullanalım. Basit bir toplama fonksiyonu yazalım;

topla.hpp

#ifndef _TOPLA_H_P_P_ // Eğer _TOPLA_H_P_P_ adlı bir makro yoksa. Bu kontrol yapılır çünkü aynı başlık dosyası birden fazla çağrılırsa koddaa fonksiyon karmaşası yaşanır ve program çöker
#define _TOPLA_H_P_P_ // _TOPLA_H_P_P_

int toplaFunc(int x, int y) // Fonksiyonumuz
{
    return x + y;
}

#endif // topla.hpp dosyasının sonu

Şimdi ana program;
main.cpp

#include <iostream>
#include "topla.hpp" // Programamıza dahil ediyoruz

/*
#include'un 2 adet modu vardır.

<>
    Küçüktür ve büyüktür işaretleri ile yapılan bu mod, başlık dosyalarını ana kütüphane dizininde aramasını sağlatır.

""
    Çift tırnak işaretleri ile yapılan bu mod, başlık dosyalarını ana programın dizininde aramasını sağlatır.
*/

using namespace std;

int main()
{
    cout << "4 + 6 = " << toplaFunc(4, 6) << endl; // Başlık dosyamızdan gelen fonksiyonu kullanıyoruz

    return 0;
}

Şimdi derliyelim;

g++ main.cpp topla.hpp -o main

Çıktısı;
#include için başka bir görsel daha gösterelim;

Makrolu Fonksiyonlar

Makroulu fonksiyonlar, tıpkı makrolar gibi önişlemci zamanında koda yazdırılan fonksiyonların içeriğidir. Bu yöntem genellikle bellek yönetimi için kullanılır. Çünkü makrolar RAM'de tutulmaz.
Örnek olması açısından "topla" fonksiyonunu makrolu bir şekilde kullanalım. Ayrıca bu bir kural değil fakat yazılımcılar tarafından kabul görmüş bir yazılış biçimi olan "Makro ise BÜYÜK YAZ" yöntemi kullanılır. Anlam açısından oldukça faydalıdır;

#include <iostream>

#define TOPLAFUNC(x,y) \ 
x + y
// Bu şekilde tanımladık. Gördüğünüz gibi tür kontrolu yapılmaz

// Makro tek satırda tanımlamaya izin verirler. Ancak "\" karateri ile diğer satırlarıda eklenmesini sağlayabiliriz

using namespace std;

int main()
{
    cout << "4 + 6 = " << TOPLAFUNC(4, 6) << endl; // Kullandık

    return 0;
}

Çıktımız değişmicektir
Makrolu fonksiyonlar içinde bir görsel sunalım;

Önceden Tanımlı Makrolar

Önceden tanımlı makrolar, C++ içerisinde bulunan ve programın bazı meta verilerini içeren makrolardır. C++ programlama dilinin önceden tanımlı makroları aşağıdaki tabloda verilmiştir;
İsim Açıklama
__FILE__ Kaynak dosyasının ismini verir.
__LINE__ Kullanıldığı satırın numarasını verir.
__DATE__ Derlenme tarihini verir.
__TIME__ Derlenme zamanını verir.
__cplusplus C++ kodunun hangi standart ile derlendiğini; Yılı + sürümü numarası olarak verir. 
Örnek olarak hepsini kullandığımız bir program yazalım;

#include <iostream>

using namespace std;

int main()
{
    cout << "Programin kaynak kodunu iceren dosya adi: " << __FILE__ << endl << endl;
    cout << "Bu cikti " << __LINE__ << ". satirdan gelmistir" << endl << endl;
    cout << "Bu program " << __DATE__ << " tarihinde derlenmistir" << endl << endl;
    cout << "Bu program " << __TIME__ << " saatinde derlenmistir" << endl << endl;

    cout << "Bu program " << __cplusplus << " tarihi + surum numarasi seklindeki standartta derlenmistir" << endl << endl;
}

Tamamdır şimdi C++23 standartı ile derliyelim;

g++ main.cpp -o main --std=c++23
