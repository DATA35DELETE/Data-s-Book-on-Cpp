Soket İşlemleri

Soket Nedir?

Soket, global veya yerel bir internet ortamında bilgisayarın dış Dünya'ya açılan internet adresidir.
Yani sizin bilgisayarınızın dış Dünya'ya açılan bir kapı gibidir. İnternetten gelen tüm verileri bilgisayarınız internet adresine gelir. Bu adresler, bilgisayarın Ip adresini ve numaralı açılan kapısı olan port'unun birleşimi ile oluşur. Yani sizin Ip adresiniz "192.106.43.123", açmak istediğiniz kapı "9584" ise soketiniz "192.106.43.123:9584" şeklinde yazılır. İnternet adresleri(Örn: www.google.com) yapıların arkasında işte bu Ip adresi ve Port numarası bulunur. Peki nasıl biz o adresi yazmadan sadece Url ile o adrese ulaşabiliyoruz? Her alınan Url aslında bir kayıt defteri gibi bir sistemde bir sokete karşılık gelir. Bu kayıt defteride Url'nin alındığı sistem oluyor. Aslında biz farkında olmasakta yazdığımız ifade birer sokettir. Peki Ip adresi internetdeki adresimiz konumunda peki Port adresi ne anlama geliyor? Onuda evimizin birden fazla dış kapıya sahip olmasına benzetebiliriz. Örneğin "192.106.43.123:9584" demek "192.106.43.123 adresindeki evin 9584 numaralı kapısına git" şeklinde bilgisayara ifade eder. Teknik olarak en fazla 65535 kadar port açılabilir. Epeyce dış kapımız varmış... Meraklısına bu sayı 16-bit'in sınırıdır.

TCP ve UDP

Evet soketin ne olduğunu biliyoruz. Tabi soketlerinde türleri vardır. En bilindikleri TCP ve UDP'dir.
TCP, el sıkışmalı bir soket türüdür. El sıkışma, iki soketin verilerini birbirlerine "aldım" veya "verdim" sinyallerine denilen bir terimdir. Aslında mantık çok basit; Gönderici olarak biz karşı tarafa verimizi göndeririz. Oda bize ona ulaşan verinin Hash verisini gönderir bizde doğrular ve bu bilgiyi ona tekrardan göndeririz. Bu zamanında internetin daha yeni yeni popüler olduğu dönemlerde mühim bir durumdu. Çünkü veri intetnette giderken genelde ya kayboluyordu ya da bir kısmı eksik gidiyordu. O zamanlarda el sıkışma gibi bir kontrol mekanizmasıda bulunmadığı için kullanıcılar doğru dürüst internetten veri alamıyorlardı. Daha sonra TCP icat edildi ve veri doğruluğu kontrol sistemi getirildi ve verilerimiz eksiksiz internette gezebildi. Daha iyi anlamak için bir görsel sunalım;
Gördüğünüz gibi üç adımlı bir işlemle veri aktarılır ve tabikide internetinizi zorlar. Fakat UDP öyle değildir. UDP, TCP'nin bir parçası olan ve veri iletimini sağlayan bir kısımdır. Daha sonraları UDP'ninde tek başına veri iletme özelliğini aldılar ve tek bir soket türü olan UDP'yi geliştirdiler. UDP, TCP'ye göre herhangi bir el sıkışma işlemine sahip değildir. Tabiri cahizse verileri etrafa saçardı. Ta ki biri o verileri tutup kendine alana kadar. Verilerde uçtan uca ve RSA ile şifrelendiği için sadece sahibi veriyi görebilirdi. UDP'de el sıkışması olmadığı için ve verileri etrafa saçtığı için akış sistemlerinde yani canlı olarak bir video izlemede veya uzaktan kumandalı sistemlerinde tercşh edilir. TCP ise hızın daha çok verinin doğrulu önemli olan sistemlerde kullanılır. Bankacılık ve oyunlarda gibi sistemlerde tercih edilir. Bir görsel daha sunalım;

TCP İletişimi

Hem Windows hemde Linux'da kodlar neredeyse aynıdır. Sadece Windows'da tüm kodlar winsock2.h kütüphanesinde yer alırken, Linux'da dağıtık şeklinde kütüphaneler bulunur.
Şimdi proje olarak, bir tarafın diğer tarafa uctan uca ve şifreli bir şekilde mesaj göndermesini yapabiliriz.
Bunun için ilk olarak göndericinin Ip adresini bulmamız gerekir. 
            
Windows için; ipconfig
Çıktısında bağlı olduğunuz ağa ve bağlantı şeklinize(Ethernet ise Ethernet Adapter, kablosuz ise Wireless LAN adapter) göre Ip adresiniz "IPv4 Address" kısmında yazıcaktır. Ben gönderici olarak Windows bilgisayarımı seçiceğim. Siz dilerseniz Linux bilgisayarınızı gönderici seçebilirsiniz.
Linux'da Ip adresini öğrenmek istersek;

ip a
Çıktısında bağlı olduğunuz ağa ve bağlantı şeklinize(Ethernet ise eth, kablosuz ise wlan) göre Ip adresiniz "IPv4 Address" kısmında yazıcaktır.
Ben Linux cihazımı alıcı olarak seçtim.
Cihazlar ve Ip adresleri hazır ise kodları yazabiliriz. İlk olarak gonderici.cpp

#include <iostream>
#include <fstream>

#include <openssl/rsa.h>
#include <openssl/pem.h>
#include <openssl/sha.h>
#include <unistd.h>

// Şimdi soket açmak için kütüphanelerimiz çağralım

#ifdef WIN32 // Windows da isek

#include <winsock2.h>

#else // Değil isek

#include <netinet/in.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#endif

#ifndef WIN32

typedef int SOCKET;

#endif

using namespace std;

#define gonderlicekMesaj "Selam alici! Ben gonderici." // Bu makro göndericinin, alıcıya göndericiği mesajdır

int main()
{
#ifdef WIN32 // Windows'da isek soket fonksiyonlarının çalışabilmesi için başlatmamız gereken bir aracı vardır
    WSADATA wsa;
    WSAStartup(MAKEWORD(2,2), &wsa);
#endif // Linux'da gerek yoktur

    SOCKET gondericiSoket = socket(AF_INET, SOCK_STREAM, 0); // Soketimizi açıyoruz
    // SOCKET gondericiSoket = ; Açılan soketin atanıcağı değişken
    // AF_INET; İnternet türü. Biz IPv4 kullancağımız için AF_INET
    // SOCK_STREAM; TCP soket türü
    // 0; Protokol türü. Şimdilik varsayılanda

    sockaddr_in gondericiBilgileri; // Gönderici tarafın bilgilerini bu yapıya atayacağız
#ifdef WIN32 // Windows'da isek, hangi akla hizmet bilinmez Windows'da bu şeklinde Ip ayarlanması yapılır
    gondericiBilgileri.sin_addr.S_un.S_addr = inet_addr("192.168.1.104"); // Gönderici Ip'sini ayarlıyoruz
#else // Değil isek
    gondericiBilgileri.sin_addr.s_addr = inet_addr("192.168.1.104");
#endif
    gondericiBilgileri.sin_family = AF_INET; // İnternet türümüzü ayarlıyoruz
    gondericiBilgileri.sin_port = htons(8282); // Portumuzu ayarlıyoruz

    bind(gondericiSoket, (sockaddr*)&gondericiBilgileri, sizeof(gondericiBilgileri)); // Açılan soketimizle bilgileri birleştiriyoruz. Böylelikle Ip adresi ile soketimiz birbirlerine bağlanmış oluyorlar
    // gondericiSoket; Açılan soketimiz
    // (sockaddr*)&gondericiBilgileri; Soket bilgilerinin bulunduğu yapı
    // sizeof(gondericiBilgileri); Soket bilgilerinin bulunduğu yapının boyutu

    listen(gondericiSoket, 5); // Soketimizi dinliyoruz ki gelecek olan bağlantıları yakalayabilelim
    // gondericiSoket; Dinlenicek olan soket
    // 5; Maksimum bağlantı sırasında kalıcak olan bağlantı sayısı

    SOCKET aliciSoket = 0; // Alıcı için soket. Gelen istekler bir soket olarak kayıt edilir
    char aliciVerisi[1024]; // Alıcıdan gelecek olan veriler için ayrılmış kısım. Char dizisi çünkü bu tarz sistemler C tabanlıdır

    aliciSoket = accept(gondericiSoket, nullptr, nullptr); // Gelen isteği kabul eder. Bu istek alıcı tarafındaki "connect" fonksiyonudur
    // aliciSoket = ; İsteğini gönderen soketi alır
    // gondericiSoket; İsteklerin geldiği soket
    // nullptr, nullptr; İsteksek gelen isteğin bilgilerinide alabiliriz. Şimdilik nullptr ile almıyoruz

    while (1) // Ana döngümüz. Bütün sistem bu döngüde çalışıcak
    {
        memset(aliciVerisi, 0, 1024); // Bu sistem bir döngü ile çalıştığı için bir önceki turdaki yazılan veriyi temizliyoruz

        recv(aliciSoket, aliciVerisi, 1023, 0); // Gelen isteğin verisini alır
        // aliciSoket; İsteğin soketi
        // aliciVerisi; Kayıt edilcek verinin değişkeni
        // 1023; Boyutu
        // 0; Güvenlik ayarı

        if (!strncmp("1.1: ", aliciVerisi, 5)) // 1.1. Aşama, kendi RSA anahtarlarını oluştur
        {
            RSA* gondericiRSA = RSA_new();

            RSA_generate_key_ex(gondericiRSA, 2048, NULL, NULL);

            FILE* gondericiPrivate = fopen("gondericiPrivate.pem", "wb");
            PEM_write_RSAPrivateKey(gondericiPrivate, gondericiRSA, NULL, NULL, NULL, NULL, NULL);
            fclose(gondericiPrivate);

            FILE* gondericiPublic = fopen("gondericiPublic.pem", "wb");
            PEM_write_RSAPublicKey(gondericiPublic, gondericiRSA);
            fclose(gondericiPublic);

            send(aliciSoket, "1.2: ", 6, 0); // Karşı tarafa veri gönderir.
            // aliciSoket; Tarafın soketi
            // "1.2: "; Veri
            // 5; Verinin uzunluğu
            // 0; Güvenlik ayarı
        }
        else if (!strncmp("2.1: ", aliciVerisi, 5)) // 2.1. Aşama, karşı tarafa kendi Public anahtarını gönder
        {
            ifstream gondericiPublic("gondericiPublic.pem");
            string gonderilcekVeri = "2.2: ";
            string publicVeriOkuyucusu;

            while (getline(gondericiPublic, publicVeriOkuyucusu))
            {
                gonderilcekVeri += publicVeriOkuyucusu + '\n';
            }
            gondericiPublic.close();
            
            send(aliciSoket, gonderilcekVeri.c_str(), 1023, 0);
        }
        else if (!strncmp("2.3: ", aliciVerisi, 5)) // 2.3. Aşama, karşı taraftan gelen Public anahtarı kaydet
        {
            ofstream aliciPublic("aliciPublic.pem");

            for (int i = 5; i < 431; i++)
            {
                aliciPublic << aliciVerisi[i];
            }
            aliciPublic.close();

            send(aliciSoket, "2.4: ", 6, 0);
        }
        else if (!strncmp("3.1: ", aliciVerisi, 5)) // 3.1. Aşama, gönderilcek olan veriyi karşı tarafın Public anahtarı ile şifreleyip gönder
        {
            RSA* aliciPublicRSA = RSA_new();

            FILE* aliciPublic = fopen("aliciPublic.pem", "rb");
            aliciPublicRSA = PEM_read_RSAPublicKey(aliciPublic, &aliciPublicRSA, NULL, NULL);
            fclose(aliciPublic);

            char gonderilicekVeri[261] = "3.2: ";
            char sifreliVeri[256];

            RSA_public_encrypt(sizeof(gonderlicekMesaj), (unsigned char*)gonderlicekMesaj, (unsigned char*)sifreliVeri, aliciPublicRSA, 1);

            for (int i = 5; i < 261; i++)
            {
                gonderilicekVeri[i] = sifreliVeri[i - 5];
            }

            send(aliciSoket, gonderilicekVeri, 261, 0);
        }
        else if (!strncmp("3.3: ", aliciVerisi, 5)) // 3.3. Aşama, karşı taraf mesajı aldıktan sonra orjinal mesajın Hash verini gönder
        {
            SHA256_CTX sha;

            SHA256_Init(&sha);
            SHA256_Update(&sha, gonderlicekMesaj, sizeof(gonderlicekMesaj));

            char shaVerisi[32];

            SHA256_Final((unsigned char*)shaVerisi, &sha);

            char gonderilcekVeri[37] = "3.4: ";

            for (int i = 5; i < 37; i++)
            {
                gonderilcekVeri[i] = shaVerisi[i - 5];
            }

            send(aliciSoket, gonderilcekVeri, 37, 0);
        }
    }
    
}

#include <iostream>
#include <fstream>

#include <openssl/rsa.h>
#include <openssl/pem.h>
#include <openssl/sha.h>
#include <unistd.h>

// Şimdi soket açmak için kütüphanelerimiz çağralım

#ifdef WIN32 // Windows da isek

#include <winsock2.h>

#else // Değil isek

#include <netinet/in.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#endif

#ifndef WIN32

typedef int SOCKET;

#endif

using namespace std;

int main()
{
#ifdef WIN32 // Windows'da isek soket fonksiyonlarının çalışabilmesi için başlatmamız gereken bir aracı vardır
    WSADATA wsa;
    WSAStartup(MAKEWORD(2,2), &wsa);
#endif // Linux'da gerek yoktur

    SOCKET gondericiSoket = socket(AF_INET, SOCK_STREAM, 0); // Soketimizi açıyoruz
    // SOCKET gondericiSoket = ; Açılan soketin atanıcağı değişken
    // AF_INET; İnternet türü. Biz IPv4 kullancağımız için AF_INET
    // SOCK_STREAM; TCP soket türü
    // 0; Protokol türü. Şimdilik varsayılanda

    sockaddr_in gondericiBilgileri; // Gönderici tarafın bilgilerini bu yapıya atayacağız
#ifdef WIN32 // Windows'da isek, hangi akla hizmet bilinmez Windows'da bu şeklinde Ip ayarlanması yapılır
    gondericiBilgileri.sin_addr.S_un.S_addr = inet_addr("192.168.1.104"); // Gönderici Ip'sini ayarlıyoruz
#else // Değil isek
    gondericiBilgileri.sin_addr.s_addr = inet_addr("192.168.1.104");
#endif
    gondericiBilgileri.sin_family = AF_INET; // İnternet türümüzü ayarlıyoruz
    gondericiBilgileri.sin_port = htons(8282); // Portumuzu ayarlıyoruz

    connect(gondericiSoket, (sockaddr*)&gondericiBilgileri, sizeof(gondericiBilgileri)); // Gönderici soketine bağlanıyoruz. Göndericide bu isteği "accept" fonksiyonu ile kabul edicek
    // gondericiSoket; Bağlanılıcak olan soket
    // (sockaddr*)&gondericiBilgileri; Bağlanılıcak olan soketin bilgileri
    // sizeof(gondericiBilgileri); Bağlanılıcak olan soketin bilgilerinin boyutu

    char gondericiVerisi[1024]; // Göndericiden gelen verileri kayıt etmek için değişken

    send(gondericiSoket, "1.1: ", 6, 0); // Bağlantının ardından göndericiye 1.1. aşama geçirt.

    while (1)
    {
        memset(gondericiVerisi, 0, 1024);

        recv(gondericiSoket, gondericiVerisi, 1023, 0);

        if (!strncmp("1.2: ", gondericiVerisi, 5)) // 1.2. Aşama, kendi RSA anahtarlarını oluştur
        {
            RSA* aliciRSA = RSA_new();

            RSA_generate_key_ex(aliciRSA, 2048, NULL, NULL);

            FILE* aliciPrivate = fopen("aliciPrivate.pem", "wb");
            PEM_write_RSAPrivateKey(aliciPrivate, aliciRSA, NULL, NULL, NULL, NULL, NULL);
            fclose(aliciPrivate);

            FILE* aliciPublic = fopen("aliciPublic.pem", "wb");
            PEM_write_RSAPublicKey(aliciPublic, aliciRSA);
            fclose(aliciPublic);

            send(gondericiSoket, "2.1: ", 6, 0);
        }
        else if (!strncmp("2.2: ", gondericiVerisi, 5)) // 2.2. Aşama, gondericinin RSA Public anahtarını kaydet ve kendi RSA Public anahtarını gönder
        {
            ofstream gondericiPublic("gondericiPublic.pem");

            for (int i = 5; i < 431; i++)
            {
                gondericiPublic << gondericiVerisi[i];
            }
            gondericiPublic.close();

            ifstream aliciPublic("aliciPublic.pem");
            string gondericilekVeri = "2.3: ";
            string publicVeriOkuyucu;

            while(getline(aliciPublic, publicVeriOkuyucu))
            {
                gondericilekVeri += publicVeriOkuyucu + '\n';
            }
            aliciPublic.close();
            
            send(gondericiSoket, gondericilekVeri.c_str(), 1023, 0);
        }
        else if (!strncmp("2.4: ", gondericiVerisi, 5)) // 2.4. Aşama, anahtar paylaşımı ardından göndericiyi 3.1. aşamaya geçirt
        {
            send(gondericiSoket, "3.1: ", 6, 0);
        }
        else if (!strncmp("3.2: ", gondericiVerisi, 5)) // 3.2. Aşama, alıcının RSA Public anahtarı ile şifrelenmiş olan veriyi alıp kaydet
        {
            char gondericiSifreliMesaj[256];
            
            for (size_t i = 5; i < 261; i++)
            {
                gondericiSifreliMesaj[i - 5] = gondericiVerisi[i];
            }

            ofstream sifreliMsg("msg");
            for (int i = 0; i < 256; i++)
            {
                sifreliMsg << gondericiSifreliMesaj[i];
            }
            
            send(gondericiSoket, "3.3: ", 6, 0);
        }
        else if (!strncmp("3.4: ", gondericiVerisi, 5)) // 3.4. Aşama, göndericiden gelen orjinal mesajın Hash verisini al ve daha önceden gelen şifreli veriyi alıp kendi RSA Private anahtarı ile çöz. Ardından çıktı olarak yazdır
        {
            char gondericiSha[32];

            for (size_t i = 5; i < 37; i++)
            {
                gondericiSha[i - 5] = gondericiVerisi[i];
            }

            RSA* aliciPrivateRSA = RSA_new();

            FILE* aliciPrivate = fopen("aliciPrivate.pem", "rb");
            aliciPrivateRSA = PEM_read_RSAPrivateKey(aliciPrivate, &aliciPrivateRSA, NULL, NULL);
            fclose(aliciPrivate);

            char sifresiCozunmusVeri[256];
            char gondericiMesaj[256];

            ifstream sifreliMsg("msg");
            sifreliMsg.read(gondericiMesaj, 256);
            sifreliMsg.close();

            int cozulmusunBoyutu = RSA_private_decrypt(256, (unsigned char*)gondericiMesaj, (unsigned char*)sifresiCozunmusVeri, aliciPrivateRSA, 1);

            char cozulmusSHA[32];

            SHA256_CTX sha;

            SHA256_Init(&sha);
            SHA256_Update(&sha, sifresiCozunmusVeri, cozulmusunBoyutu);

            SHA256_Final((unsigned char*)cozulmusSHA, &sha);

            if (!strncmp(gondericiSha, cozulmusSHA, 32)) // Hash'leri kontrol et. Aynı ise yazdır
            {
                cout << "Gondericiden gelen mesaj; " << sifresiCozunmusVeri << endl;
            }
            else // Değil ise 3.1. aşamsına tekrar geç
                send(gondericiSoket, "3.1: ", 6, 0);

            break;
        }
        
    }
    
    return 0;
}
