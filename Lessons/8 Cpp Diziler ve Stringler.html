Diziler ve Stringler

Dizi Nedir?

Dizi, C++ programlama dilinde birden fazla verileri tek bir değişkende tutmamızı sağlayan, boyutu sabit ve tanımlanan tek bir veri türünündeki değerli depolayan bir yapıdır.
Örnek olarak bir markete gittidiğinizde size ne alıcağınızı belirten bir program yazdığnızı düşünün. O sistemde kullanıcı alıcaklar listesi hazırlarken arka planda siz kullanıcının girdikleri verileri bir dizinin içerisine kayıt edersiniz. Daha sonra gerek döngülerle gerek farklı durumlarda çalışan kod parçalarıyla kullanıcının girdiği verileri ekrana yazdırırsınız.
Diziler sabit ve tek tür verileri depolamak için harika yapılardır. Bu sebeble çoğu sistemde verileri birer bütün şeklinde depolamak için diziler kullanılır.
Tanımlamak için iki şekilde yönetem yer almaktadır.

Birinci yöntem
int sayilarDizini[5]; // Boyutu önceden tanımlı bir dizi oluşturabiliriz. Dizilerin boyutları köşeli parantezlerin([]) içerisine yazılır. Bu ifadede biz bilgisayardan "5 adet Integer veri türünü depolayabilceğimiz bir değişken" isteğinde bulunmuş olduk.

sayilarDizini[0] = 12; // Ayrıca dizilerin içerisindeki verileri erişmek ve değiştirmek içinde köşeli parantezlerde dilediğimiz verinin Index numarasını girerek erişebiliriz. Index bir listeleme sistemidir. İlk elemanı 0 olarak sayar ve sonsuza kadar gider. Bu ifadede 0. yani birinci elemanın değerini 12 yaptık

İkinci yöntem
int sayilarDizini[] = {1,4,7,8}; // Boyutu belirtmeden önceden değerlerini atıyabiliriz. C++ bizim için, değerlerin sayısını hesaplar ve dizinin boyutunu ona göre ayarlar

cout << sayilarDizini[2] << endl; // Aynı şekilde Index numarasına görede değerlere erişebiliriz

Tek Boyotlu Diziler

Tek boyutlu diziler, tek bir sıra şeklinde değerlerin sıralandığı dizilerdir. Tek bir köşeli parantez([]) ile kullanılır.
Bir üst konuda verdiğimiz örneklerin hepsi bir boyutlu dizilere örnektir. Şimdi on,yirmi,otuz,kırk ve elli sayılarını içeren bir dizi tanımlayalım ve "Döngü Yapıları" sayfamızda değindiğimiz Range tabanlı For ile ekrana yazdıralım.

#include <iostream>

using namespace std;

int main(){

    int sayilar[] = {10,20,30,40,50};

    for (int sayi : sayilar) // Dizideki elemanların veri türü Integer olduğu için int veri türündeki "sayi" değişkenine atadık
    {
        cout << sayi << endl; // Range tabanlı For'dan gelen verileri ekrana yazdırıyoruz
    }
    
}

Çıkıt;

Çok Boyutlu Diziler

Çok boyutlu diziler, bir Index içerisinde başka bir Index tanımlayabildiğimiz, sütünlar ve satırlar gibi yapılar kurabildiğimiz dizilerdir. Çok boyutlu dizileri tanımlamak için birden fazla köşeli parantezlerle, bir bütün olarak tutacak olan süsle parantezlerine({}) içerisine ikinci boyutdaki değerli süslü parantezlerine yazarız.
Şimdi ise tek boyutta yaptığımızı bu sefer çok boyutlu şekilde yapalım.

#include <iostream>

using namespace std;

int main(){

    int sayilar[2][5] = {
                      {10,20,30,40,50}, 
                      {1 , 2, 3, 4, 5}
                    }; // Bu şekilde çok boyutlu diziler tanımlanır. Boyutları önceden girilmelidir

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 5; j++)
        {
            cout << sayilar[i][j] << "|";
        }   

        cout << endl;
    } // Tablo gürünümü elde etmek için bu şekil bir iç içe For yapısı kullandık

    return 0;
}

C++ Array

C dilinde bulunmayan C++11 standartıyla gelen bir dizi türü olan Array, Array kütüphanesinde yer almaktadır.
Peki C tarzıyla oluşturulan dizilerden farkı nedir? Tabi ki OOP'nin nimetlerinden faydalanarak dizileri kullanma imkanıdır. C dili her ne kadar hızlı, performanslı ve fikrimce mükemmel olsada yapısı gereği tüm her işlevleri kendiniz yazmanız gerekir. Örnek olarak bir String ifadesinde belirli bir kısmı String olarak almak istersek biz bu işlemi C'de kendimizi yazarız. Bu durum bazen yorucu veay uğraştırıcı bir hal aldığında işler bir miktar sıkıcı hale gelmektedir. Bu sıkıcılık C++ programcılarında aklına gelecek olucak ki OOP'nin gücü ile hazır metodlar yazmışlardır. İşte C++ Array'de bu ihtiyaç durumunda ortaya çıkmıştır.
Array tanımlamak için yeni görcek olacağımız bir OOP özelliği olan Temple ile tanımlarız. Temple, "<>" karaterlerin arasında parametre veriyormuşuz gibi belirli başlı değerler vermemizi sağlayan bir yapıdır. Şimdi örnek olarak bir Array tanımı yapalım.

std::array ornekBirArray = {10,20,30,40,50}; // Yazılma şekli olarak C'deki dizilere benzetebeliriz
// Temple'ın içerisindeki birinci argüman hangi tür için dizi oluşturucağı ifadesini belirler. Biz burada Integer veri türünce tanımladığımız için "int" yazdık
// Temple'ın içerisindeki ikinci argüman ise dizinin kaç elemanlı olucağını ifade eder. Dizimiz 5 değer içerdiği için "5" ifadesini yazdık

OOP'den bahset ki Array'ın de OOP'den sayesinde var olduğunu da söyledik. Şimdi hazır fonksiyonlarına bir göz atalım;

#include <iostream>
#include  // Array nesnesini kullanmamız için kütüphanemiz

using namespace std;

int main(){

    std::array<int, 5> ornekBirArray = {10,20,30,40, 50};

    int arraydekiElemanAlma = ornekBirArray.at(2); // Array'den Index ile eleman alma
    cout << "2. Index'deki elemanin degeri; " << arraydekiElemanAlma << endl << endl;

    cout << "3. Index'deki elemanin degeri; " << ornekBirArray[3] << endl << endl; // C tarzı ile Index'li eleman alma

    int arraydekiIlkElemaniAlma = ornekBirArray.front(); // Array'deki ilk elemanı alır
    cout << "Array'deki ilk eleman; " << arraydekiIlkElemaniAlma << endl << endl;

    int arraydekiSonElemaniAlma = ornekBirArray.back(); // Array'deki son elemanı alır
    cout << "Array'deki son eleman; " << arraydekiSonElemaniAlma << endl << endl;

    bool arrayBosMu = ornekBirArray.empty(); // Array'in boş olup olmadını kontrol eder. Boşsa True değilse False döndürür
    cout << "Array bos mu; " << ((arrayBosMu) ? "evet" : "hayir" ) << endl << endl;

    int arrayBoyutu = ornekBirArray.size(); // Array'in boyutunu alır
    cout << "Array'in boyutu; " << arrayBoyutu << endl << endl;

    int arrayinMaksBoyutu = ornekBirArray.max_size(); // Array'in maksimum boyutunu alır
    cout << "Array'in maksimum boyutu; " << arrayinMaksBoyutu << endl << endl;

    ornekBirArray.fill(32); // Array'deki tüm değerleri parantezlerindeki değer ile üzerlerine yazar

    cout << "4. Index'deki elemanin degeri; " << ornekBirArray[4] << endl;
    cout << "2. Index'deki elemanin degeri; " << ornekBirArray[2] << endl << endl;

    array arrayinBaskaBirIcerigi = {1,2,3,4,5}; // İstersekde Temple'sız da tanımlayabiliriz. C++ bizim yerimize Temple'in içeriğini doldurucaktır

    ornekBirArray.swap(arrayinBaskaBirIcerigi); // Array'in içeriğini başka bir Array'in içeriği ile değiştirir

    cout << "4. Index'deki elemanin degeri; " << ornekBirArray[4] << endl;
    cout << "2. Index'deki elemanin degeri; " << ornekBirArray[2] << endl;

    return 0;
}

String Yapısı

String, C dilinde bulunmayan bir değişken türüdür. Fakat zamanında bu ihtiyacı eskiden Char dizisi karşılardı. Programcılar bellekte depolıcakları yazıları Char dizisi olarak saklar ve zamanı geldiğinde kullanırdı. Zaman geçtikçe program karmaşıklaştıkça veri yapılarıda karmaşıklaştı. C dilinde String yapısı hala bulunmamakta fakat onun yerine dolduran ve C standartlarıyla geliştirilen Char dizisi fonksiyonları bulunmakta fakat onlarda günümüzün en azından "Rahat kod yazma" işlevine sahip olmadıkları için C++ dilinde özel bir veri yapısı olarak String çıkarılmıştır. Mantık aynı fakat işleyişi programcılar yerine artık C++ içerisinde çalışıcak olan otomatik kodlar yapmaktadır. Böylece o eski Char dizisi ile işlemleri biz yerine artık makineler kendilerine yazılan kodlar sayesinde yapmaktadır.
Şimdi gelin sizlerle beraber basit bir örnek yapalım. İlk olarak C programlama dili ve C++ programlama dili ile bir String ifadesine ekleme örneği yazalım. Ardından iki kod ile karşılaştırma yapalım.

C Kodu
#include <stdio.h> // C'de G/Ç işlemleri için olan kütüphane
#include <string.h> // Char dizisi(String) türü için kütüphane

int main(){

    char ornekBirStringIfadesi[38] = "Hello World"; // Tanımlama

    strncat(ornekBirStringIfadesi, " of Low-Level Programming!", 27);
    // Strncat Char dizisi ifadelere ekleme yapan bir C fonksiyonudur
    // ornekBirStringIfadesi; Hedef ifade
    // " of Low-Level Programming!"; Kaynak ifade
    // 27; Kaynak ifadesinin boyutu, boyut belirtirmelidir yoksa bellek hataları başımızı ağrıtabilir

    printf("%s\n", ornekBirStringIfadesi); // Yazdırma fonksiyonu

    return 0;
}

C++ kodu
#include <iostream>

using namespace std;

int main(){

    string ornekStringIfadesi = "Hello World"; // String ifadesi tanımlayalım

    ornekStringIfadesi += " of Low-Level Programming!"; // Ekleme işlemini sanki bir sayısal değişkene değer ekliyormuş gibi yapılır

    cout << ornekStringIfadesi << endl; // Yazdırma

    return 0;
}

Çıktıları her ikisininde aynı olasada yapma şekilleri birbirinden farklıdır. C'de her durum ve işlem programıcının elindedir. Ne yapılcaksa ilk önce hesaplanmalı ve mantık oturturarak yazılmalıdır. C++ programlama dili ise bu tarz "uğraştırıcı" işlemleri bizim yermize yapmaktadır. Böylelikle daha "rahat" kod yazabilmemizi sağlar.

String Fonksiyonları

Gelin String türünün bizlere sunduğu hazır fonksiyonlara göz atalım.
#include <iostream>

using namespace std;

int main(){

    string ornekStringIfadesi = "Hello World";
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi += " of Low-Level Programming!";
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi.append(" And You!"); // String ifadeye parantezlerindeki ifadeyi ekler
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi.assign("Selam Dusuk Seviye Programlama! Ve Sanada!"); // Parantezlerindeki belirtilen ifadeyi String'in içeriği ile değiştirir
    cout << ornekStringIfadesi << endl << endl;

    char stringinBirKarateriniAlma = ornekStringIfadesi.at(4);
    cout << "String ifadenin 4. Index'deki elemani; " << stringinBirKarateriniAlma << endl << endl;

    char stringinIlkKarakteriniAlma = ornekStringIfadesi.front();
    cout << "String ifadenin Ilk karateri; " << stringinIlkKarakteriniAlma << endl << endl;

    char stringinSonKarakteriniAlma = ornekStringIfadesi.back();
    cout << "String ifadenin Ilk karateri; " << stringinSonKarakteriniAlma << endl << endl;

    const char *C_YazimSekliIleCharDizisiAlma = ornekStringIfadesi.c_str(); // C++ String ifadesini C'deki Char dizisine dönüştürme
    cout << "C'deki Char dizisi ile String" << C_YazimSekliIleCharDizisiAlma << endl << endl;

    int stringinKapasitesi = ornekStringIfadesi.capacity(); // String ifadenin kapasitesini alır
    cout << "String ifadenin kapasitesi; " << stringinKapasitesi << endl << endl;

    ornekStringIfadesi.clear(); // String ifadenin içeriğini siler
    cout << "String ifadenin icerigi; '" << ornekStringIfadesi << "'" << endl << endl; 

    string stringIfadeninBaskaBirIcerigi = "Yeni Icerik";
    ornekStringIfadesi.swap(stringIfadeninBaskaBirIcerigi);

    bool stringIfadelerAyniMi = ornekStringIfadesi.compare("Yeni Icerik"); // String ifadeleri karşılaştırır. Eğer aynı ise False, değil ise True sonucunu verir
    cout << "Yeni Icerik == " << ornekStringIfadesi << " = " << ((stringIfadelerAyniMi) ? "False" : "True") << endl << endl;
    
    char stringIfadeninKopyasi[5]; // Kopya String için bir Char dizisi
    ornekStringIfadesi.copy(stringIfadeninKopyasi, 4, 0); // String ifadenin Char dizisi şeklinde belirli bir kısmını kopyalayıp Char dizi değişkenine atamamızı sağlar
    // stringIfadeninKopyasi; Atanacak Char dizisi
    // 4; Nereye kadar
    // 0; Nerden kopyalancağı
    cout << stringIfadeninKopyasi << endl << endl;

    bool stringBosMu = ornekStringIfadesi.empty();
    cout << "String bos mu; " << ((stringBosMu) ? "evet" : "hayir" ) << endl << endl;

    ornekStringIfadesi.erase(0,5); // String ifadeden belirli kısımları siler
    // 0; Nerden
    // 5; Nereye kadar sileceği
    cout << ornekStringIfadesi << endl << endl;

    int stringIfadenin_i_Nerede = ornekStringIfadesi.find("i"); // Parantezlerindeki karaterin kaçıncı Index'de olduğunu bulur
    cout << "String icerisindeki 'i' karakterinin Index numarasi; " << stringIfadenin_i_Nerede << endl << endl;

    ornekStringIfadesi.insert(ornekStringIfadesi.begin()+2, 'E'); // String ifadanin karakterlerinin arasına bir Char değerini yazmamızı sağlar
    // ornekStringIfadesi.begin()+2; Bir nevi String ifadenin başını veren bir metod olan .begin adında bir fonksiyon ile, Bu ifadede String ifadenin başından 2 karakter ilerisine 'E' karakterini yaz dedik
    cout << ornekStringIfadesi << endl << endl;

    int stringinUzunlugu = ornekStringIfadesi.length();
    cout << "String ifadenin uzunlugu; " << stringinUzunlugu << endl << endl;

    long long unsigned int stringinMaksBoyutu = ornekStringIfadesi.max_size();
    cout << "String ifadenini maksimum uzunlugu; " << stringinMaksBoyutu << endl << endl;

    ornekStringIfadesi.pop_back(); // Sondaki karateri siler
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi.push_back('k'); // Sona karater ekler
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi.replace(ornekStringIfadesi.begin(), ornekStringIfadesi.end(), "Degistirilmis Icerik"); // String ifadenin içeriğini belirli bir yerden başka bir yere değiştirme
    // ornekStringIfadesi.begin(); Başlangıç Iterator'u
    // ornekStringIfadesi.end(); Sondaki Iterator'u
    // "Degistirilmis Icerik"; Değiştirilecek olan içerik
    cout << ornekStringIfadesi << endl << endl;

    ornekStringIfadesi.reserve(100); // Kapasitesini düzenlememizi sağlar
    stringinKapasitesi = ornekStringIfadesi.capacity();
    cout << "String ifadenin kapasitesi; " << stringinKapasitesi << endl << endl;

    int stringinBoyutu = ornekStringIfadesi.size(); // String ifadenini boyutunu alır
    cout << "String ifadenin boyutu; " << stringinBoyutu << endl << endl;

    ornekStringIfadesi.resize(100); // String ifadenin boyutunu düzenler
    stringinBoyutu = ornekStringIfadesi.size();
    cout << "String ifadenin boyutu; " << stringinBoyutu << endl << endl;

    ornekStringIfadesi.shrink_to_fit(); // String ifadenin gerekli alan kadar kapasitesini düzenler
    stringinKapasitesi = ornekStringIfadesi.capacity();
    cout << "String ifadenin kapasitesi; " << stringinKapasitesi << endl << endl;

    string ornekStringIfadesininBirKismi = ornekStringIfadesi.substr(0,14); // String bir ifadenin belirli bir kısmını String olarak alma
    // 0; Nerden
    // 14; Nereye alınacak olan karakterler
    cout << "String ifadenin 0 ila 14 arasindaki karakterlerin String ifadeli seklinde degeri; " << ornekStringIfadesininBirKismi << endl;

    return 0;
}

String_View Türü

String_View, String türünün salt okunur(Sadece okunur, değiştirilemez veya eklenemez) şeklindeki bir varyasnudur. C++17 standartı ile C++ programlama diline katılan, String türünün donanım üzerindeki maaliyetlerinden dolayı ortaya çıkmıştır türdür.
Amaç ise sadece "yazı" olarak kullanılan String ifadelerin daha saf ve değiştirilemez dolayısıyla kaynak tasarufu yapabilceğimiz bir değişken türüdür. Gelin bir örnek yapalım;

#include <iostream>

using namespace std;

int main(){

    string_view saltOkunurStringIfade = "C++ bir Low-Level Programlama dilidir."; // Kullanımı

    //saltOkunurStringIfade += " Hayir degildir";
    // Bu komut sizlere hata vericektir. Çünkü String_View değiştirileme veya eklenemez

    cout << saltOkunurStringIfade << endl;

    return 0;
}
