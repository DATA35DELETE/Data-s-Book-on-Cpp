Diziler ve Stringler

Dizi Nedir?

Dizi, C++ programlama dilinde birden fazla verileri tek bir değişkende tutmamızı sağlayan, boyutu sabit ve tanımlanan tek bir veri türünündeki değerli depolayan bir yapıdır.
Örnek olarak bir markete gittidiğinizde size ne alıcağınızı belirten bir program yazdığnızı düşünün. O sistemde kullanıcı alıcaklar listesi hazırlarken arka planda siz kullanıcının girdikleri verileri bir dizinin içerisine kayıt edersiniz. Daha sonra gerek döngülerle gerek farklı durumlarda çalışan kod parçalarıyla kullanıcının girdiği verileri ekrana yazdırırsınız.
Diziler sabit ve tek tür verileri depolamak için harika yapılardır. Bu sebeble çoğu sistemde verileri birer bütün şeklinde depolamak için diziler kullanılır.
Tanımlamak için iki şekilde yönetem yer almaktadır.

Birinci yöntem
int sayilarDizini[5]; // Boyutu önceden tanımlı bir dizi oluşturabiliriz. Dizilerin boyutları köşeli parantezlerin([]) içerisine yazılır. Bu ifadede biz bilgisayardan "5 adet Integer veri türünü depolayabilceğimiz bir değişken" isteğinde bulunmuş olduk.

sayilarDizini[0] = 12; // Ayrıca dizilerin içerisindeki verileri erişmek ve değiştirmek içinde köşeli parantezlerde dilediğimiz verinin Index numarasını girerek erişebiliriz. Index bir listeleme sistemidir. İlk elemanı 0 olarak sayar ve sonsuza kadar gider. Bu ifadede 0. yani birinci elemanın değerini 12 yaptık

İkinci yöntem
int sayilarDizini[] = {1,4,7,8}; // Boyutu belirtmeden önceden değerlerini atıyabiliriz. C++ bizim için, değerlerin sayısını hesaplar ve dizinin boyutunu ona göre ayarlar

cout << sayilarDizini[2] << endl; // Aynı şekilde Index numarasına görede değerlere erişebiliriz

Tek Boyotlu Diziler

Tek boyutlu diziler, tek bir sıra şeklinde değerlerin sıralandığı dizilerdir. Tek bir köşeli parantez([]) ile kullanılır.
Bir üst konuda verdiğimiz örneklerin hepsi bir boyutlu dizilere örnektir. Şimdi on,yirmi,otuz,kırk ve elli sayılarını içeren bir dizi tanımlayalım ve "Döngü Yapıları" sayfamızda değindiğimiz Range tabanlı For ile ekrana yazdıralım.

#include <iostream>

using namespace std;

int main(){

    int sayilar[] = {10,20,30,40,50};

    for (int sayi : sayilar) // Dizideki elemanların veri türü Integer olduğu için int veri türündeki "sayi" değişkenine atadık
    {
        cout << sayi << endl; // Range tabanlı For'dan gelen verileri ekrana yazdırıyoruz
    }
    
}

Çıkıt;

Çok Boyutlu Diziler

Çok boyutlu diziler, bir Index içerisinde başka bir Index tanımlayabildiğimiz, sütünlar ve satırlar gibi yapılar kurabildiğimiz dizilerdir. Çok boyutlu dizileri tanımlamak için birden fazla köşeli parantezlerle, bir bütün olarak tutacak olan süsle parantezlerine({}) içerisine ikinci boyutdaki değerli süslü parantezlerine yazarız.
Şimdi ise tek boyutta yaptığımızı bu sefer çok boyutlu şekilde yapalım.

#include <iostream>

using namespace std;

int main(){

    int sayilar[2][5] = {
                      {10,20,30,40,50}, 
                      {1 , 2, 3, 4, 5}
                    }; // Bu şekilde çok boyutlu diziler tanımlanır. Boyutları önceden girilmelidir

    for (int i = 0; i < 2; i++)
    {
        for (int j = 0; j < 5; j++)
        {
            cout << sayilar[i][j] << "|";
        }   

        cout << endl;
    } // Tablo gürünümü elde etmek için bu şekil bir iç içe For yapısı kullandık

    return 0;
}

Çıktı ise;
