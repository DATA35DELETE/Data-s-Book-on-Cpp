OOP

OOP, açılımıyla Object Oriented Programming(Nesne Yönelimli Programlama) bir dil yeteneğidir. OOP yeteneğine sahip programlama dillerinde; Class'lar kullanılabilir, nesneler oluşturabilir ve kalıtım gibi işlemler yapılabilir.
Eski zamanlarda daha C++ programlama dili ortaya çıkmamışken C programlama dili vardı biliyorsunuz. C programcıları zaman geçtikçe zorlanmaya ve daha fazla kod yazmaya başladılar. Sorun ise yapıların yani C programlama dilindeki ilkel Class diyebilceğimiz yapılar yüzündendi. Yapılar, tıpkı bir değişken türü gibi işlev gören ve kendimiz oluşturabildiğimiz ve kullanabildiğimiz yapılardır. Yapılar ilk başta cidden çok iş görmüşlerdir. Lakin zaman geçtikçe programlar karmaşıklaşmış ve programlar karmaşıklaştıkça kodlarda aynı şekilde etkilenmiş. İşte tam bu zamanlarda OOP ortaya çıkmıştır. OOP sayesinden programcılar yapıların eksiklerini kapatan ve oluşturması daha kolay olan Class'lara geçmişlerdir. Class'ların bir çok özelliği bulunmasından mütevellit daha kısa kodlar yazılmaya başlanmıştır. Ardından Bell Labs'de çalışan Bjame adlı bir bilgisayar bilimci ilk olarak "C with Classes" adlı projesiyle ortaya çıkmış ardından projenin ismi C++ olarak dünyaca ünlü ve neredeyse her sistemin temelinde olan dil haline gelmiştir. Uzun lafın kısası OOP, bir ihtiyaç halinde geliştirilmiş bir yetenektir. Tıpkı bir canlının seçilim baskısından dolayı evrim geçirip ortama ayak uydurması gibi...
Peki neden OOP? Ortaya çıkış hikayesinden anlaşılcağı üzere yapıların yani Struct'ların yetersizliği sonucu ortaya çıkmış bir yetenektir. OOP bizlere daha az kod yazma, daha efektif ve performanslı yapıları kurmamızı sağlar. İçerisindeki kalıtım, çokbiçimlilik, soyutlama ve kapsülleme gibi yetenekler sayesinde kod tasarufu yapmamızı sağlar. Bu sebeble bir çok dilde OOP desteklenir. Fakat güncel olarak çıkmış dilerde OOP pek fazla desteklenmemektedir. Başta Rust olmak üzere OOP'nin bellek ve güvenlik açıklarına yol açtığı ilere sürülmüş, sonucunda Rust OOP desteğini kaldırmışlardır. Ama konumuz şuan C++ ve C'den ayıran en önemli özelliği olan OOP konusudur. Bu sebeble programlama dünyasında bir devrime imza atmış C++ ve OOP konusunu anlatalım.
Değindiğimiz gibi C++ programlama dilinin C'den ayıran en önemli özelliği olan OOP'i pek tabi C'nin yapısı gereği yapılamazdı. C'de Class'lara en yakın olan sistem yapılardır ve yapılar OOP yeteneği için pekde uygun değildir. C, yapısı gereği sizlere hazır neredeyse hiç bir fonksiyon sağlamaz bu sebeble OOP'i de desteklememektedir. Fakat C++'da OOP'i desteklendiği için C'de belkide binlerce satır kod sürecek bir işin C++'da yüzlerce satır koda indirebilmemizi sağlayan çok performanslı bir yetenektir.

Class(Sınıf)'lar ve Object(Nesne) Kavramları

Class'lar türkçesiyle sınıflar, değikenleri ve fonksiyonları bir arada barındabilen ve kullanabilen yapılardır. Object türkçesiyle nesne, sınıfların bir değişkene değer olarak atanan değişkenlere denir.

Sınıf Tanımlama

Sürekli bahsettiğim Class diyerek aklınızı karıştırdığım ama aslında sınıflar olan yapıyı tanımlayalım.
#include <iostream>

using namespace std;

// Class tanımlama
class ornekClassTanimlama // class + classIsmi
{
    public: // Class'ın herkese açık olan kısmı
        string degisken1; // Örnek String değişkeni tanımlama
        int degisken2 = 42; // Örnek Integer değişkeni

        void ornekClassIcerisindeOrnekFunc() // Örnek fonksiyon tanımlama
        {
            cout << "Ornek cikti" << endl; // Örnek fonksiyon içeriği
        }
};

int main()
{
    ornekClassTanimlama ornekNesne1; // Örnek nesne tanımlama. Bahsettiğimiz gibi oluşturduğumuz sınıf bir nevi değişken türü görevi görmektedir.

    ornekNesne1.degisken1 = "Merhaba"; // Örnek nesnenin içerisindeki bir değişkene atama işlemi
    ornekNesne1.degisken2 = 443;

    ornekNesne1.ornekClassIcerisindeOrnekFunc(); // Örnek nesnenin içerisindeki fonksiyonu çağırma

    ornekClassTanimlama ornekNesne2; // Sınıfları çok kez nesne olarak tanımlayabilir

    // Diğer işlemler

    return 0;
}

Çıktısı; "Ornek cikti" olucaktır.
Eğer kafanıza pek yerleşmeşdiyse sınıfları bir nevi fabrika, nesneleri ise o fabrikanın ürünleri gibi düşünebilirsiniz. Fabrikanın üreteceği ürünün içeriğini tanımlarken belirliyoruz. Ardından nesne tanımlarken de fabrikadan içeriğini belirlediğimiz ürünü üretilmesini ve bize verilmesini istiyoruz. İyi anlamasınız çünkü sınıflar OOP'nin temelidir.

Erişim Belirteçleri

Erişim belirteçleri, sınıflar içerisindeki bir değeri veya fonksiyonun sınıflarca veya fonksiyolarca erişibilirtesini belirteçlerdir. C++ programlama dilinde üç adet erişim belirteçleri bulunur. Tablo şeklinde açıklayalım.
İsmi Açıklaması
Public Tanımlanan değişenkenleri ve fonksiyonları nereden olursa olun erişmeyi ve kalıtımına izin verir.
Protected Public'ten farklı olarak tanımlanan değişkenleri ve fonksiyonları sadece o sınıfta ve o sınıftan türetilmiş sınıflara erişimi izin veren bir belirteçtir. Ayrıca dışarıdaki fonksiyonlara kapalıdır.
Private Tanımlanan değişkenleri ve fonksiyonları sadece sınıf içerisinde erişimi izin verir. 
Örnek olarak bir hesap sistemi yazalım. Sadece bu sayfa göreceğimiz kalıtım konusu ufaktan göreceğiz. Çünkü erişim belirteçleri neredeyse direkt kalıtım üzerinden işlenirler. Kalıtım kısaca bir sınıfın özellikelerini direkt olarak alarak kendi içene katar ve dilenirse kendi özelliklerine ekliyebilir. Şimdi örneğimize geçelim.

#include <iostream>

using namespace std;

class hesap // Hesap sınıfımız
{
    public: // Herkese açık olan kısım. Hesabın sadece bu kısımda bilgilerini alabiliyoruz
        string hesapIsminiAl() { return hesapIsmi; };
        string hesapSifresiAl() { return  hesapSifresi; };

    protected: // Korunan kısım. Sadece sınıfın içi ve türelen sınıflarda erişim bölgesidir
        void hesapIsminiDegistir(string isim, bool erisimIzni) // Erişim izinli bir sistem yaptık ki güvenlik katmanı oluşsun
        { 
            if (erisimIzni) // Eğer erişim izinin varsa
            { // Uygula
                hesapIsmi = isim; // Gelen ismi özel bölgedeki hesap ismine ata

                cout << "Basaliyla hesap ismi degistirildi!" << endl << endl; // Bildir
            }
            else // Yoksa
            {
                cout << "Islem basarisiz, erisim yetkiniz yok!" << endl << endl; // Bildir
            }
        };

        void hesapSifresiDegistir(string sifre, bool erisimIzni) // Aynı işlemler şifre için uygula
        { 
            if (erisimIzni)
            {
                hesapSifresi = sifre;

                cout << "Basaliyla sifre degistirildi!" << endl << endl;
            }
            else
            {
                cout << "Islem basarisiz, erisim yetkiniz yok!" << endl << endl;
            }
        };

    private: // Sınıfın kendisine özel kısmıdır
        string hesapIsmi; // Direkt erişime izin vermemek için bu bilgiler bu erişim belirtecinde
        string hesapSifresi;
};

class onGuvenlikliHesap : hesap // Bir sınıfı kalıttık. hesap sınıfındaki bilgileri(public ve protected kısımlardaki) direkt olarak onGuvenlikliHesap sınıfına aktardık
{
    public:
        bool guvenlikErisimi = false; // Erişim yetkisi ilk olarak kapalı gelir

        void guvenliHesapIsminiDegistir(string guvenliIsim){ hesapIsminiDegistir(guvenliIsim, guvenlikErisimi); }; // Kalıtım sayesinde protected kısımda yer alan fonksiyonlarda aktarılmıştır
        void guvenliHesapSifreniDegistir(string guvenliSifre) { hesapSifresiDegistir(guvenliSifre, guvenlikErisimi); };

        string guvenliHesapIsminiAl() { return hesapIsminiAl(); }; // Her ne kadar hesap sınıfının fonksiyonu olsada kalıtım sayesinde bu sınıfa da aktarılmıştır
        string guvenliHesapSifresiAl() { return hesapSifresiAl(); };
};

int main()
{
    onGuvenlikliHesap hesap1; // İlk olarak nesnemizi oluşturalım

    cout << "hesap1'in ismi; '" << hesap1.guvenliHesapIsminiAl() << "'" << endl << endl; // Hesap ismini alma. Erişim yetkisi istemez
    cout << "hesap1'in sifresi; '" << hesap1.guvenliHesapSifresiAl() << "'" << endl << endl; // Hesap sifresi alma

    hesap1.guvenliHesapIsminiDegistir("Data"); // İsmi değiştirmeyi çalışalım. Lakin başarısız olucaktır çünkü biz erişim izni vermedik

    hesap1.guvenlikErisimi = true; // Yetki verelim

    hesap1.guvenliHesapIsminiDegistir("Delete"); // Şimdi değiştirelim
    hesap1.guvenliHesapSifreniDegistir("123");

    cout << "hesap1'in ismi; '" << hesap1.guvenliHesapIsminiAl() << "'" << endl << endl; // Hesap ismini tekrardan alma
    cout << "hesap1'in sifresi; '" << hesap1.guvenliHesapSifresiAl() << "'" << endl << endl; // Hesap sifresi tekrardan alma

    return 0;
}

Constructor ve Destructor

Constructor yani yapıcı, bir sınıfın nesnesi oluşturulduğunda kendini çağıran bir fonksiyondur. Destructor yani yıkıcı, bir sınıfın nesnesi silindiğinde kendisi çağıran bir fonksiyondur.
Yapıcı ve yıkıcı, fonksiyonlarını amacı ise nesne oluşturulduğu veya yol edildiğinde sınıfın başlatılması veya bellektede ayrılan kısımaları serbest bırakmak gibi işlemler için kullanılır.
Örnek olarak bir kediyi simüle edicek bir sınıf oluşturalım. Kedi sınıfında nesne ilk oluştuğunda kedinin yaşını sıfır olarak belirlesin. Ardından fonksiyonlar bir kedinin yaptığı aktiviteleri fonksiyon olarak kuralım. Yıkıcı olarak kedinin hayatını kaybettiğini yaşıyla ve yaptığı aktivilerin sayısıyla beraber bildirsin.

#include <iostream>

using namespace std;

class kedi // Kedimizin sınıfı
{
    public:
        int kediYas; // Kedinin yaşının tutulacağı değişken

        // Aktivitelerin sayısılarını tutacak değişkenler
        int kediMiyavlamaSayisi = 0;
        int kediYemekYemeSayisi = 0;
        int kediOyunOynamaSayisi = 0;
        
        float kedininAldigiYol = 0;

        kedi() // Sınıfın yapıcı fonksiyodur. Yapıcı fonksiyonlar, sınıflar aynı isme sahip almalıdır
        {
            kediYas = 0; // Kedi doğdunda yaşını direkt 0 değerine atadık

            cout << "Bir kedi dogdu!" << endl << endl; // Bildirme
        }

        // Kedinin aktiviteleri için işlemler ve bildirme
        void kediMiyavla()
        {
            kediMiyavlamaSayisi++;

            cout << "Kedi miyavladi" << endl << endl;
        }
        void kediYemekYe()
        {
            kediYemekYemeSayisi++;

            cout << "Kedi yemek yedi" << endl << endl;
        }
        void kediOyunOyna()
        {
            kediOyunOynamaSayisi++;

            cout << "Kedi oyun oynadi" << endl << endl;
        }
        void kediYolAl(float aldigiYol)
        {
            kedininAldigiYol += aldigiYol;

            cout << "Kedi " << aldigiYol << "cm yol aldi" << endl << endl;
        }

        ~kedi() // Yıkıcı fonksiyonlar. Yıkıcı, sınıfın isminin başına yaklaşık işareti(~) ile tanımlanır
        { 
            // Kedinin hayatını kaybetme bildirimleri

            cout << "Kedi " << kediYas << " yasinda hayatini kaybetti..." << endl << endl;
            cout << "Hayati boyunca yaptikleri;" << endl;
            cout << "Kedi'nin miyavlama miktari " << kediMiyavlamaSayisi << endl;
            cout << "Kedi'nin yemek yedigi miktari " << kediYemekYemeSayisi << endl;
            cout << "Kedi'nin oyun oynama miktari " << kediOyunOynamaSayisi << endl;
            cout << "Kedi'nin aldigi yol miktari " << kedininAldigiYol << "cm" << endl << endl;
        }
};

int main()
{
    kedi boncuk; // Kedimiz doğdu

    for (int i = 0; i < 12; i++) // Kedimiz 12 kere miyavlasın
    {
        boncuk.kediMiyavla();
    }

    for (int i = 0; i < 32; i++) // Kedimiz 32 kere yemek yesin
    {
        boncuk.kediYemekYe();
    }
    
    for (int i = 0; i < 23; i++) // Kedimiz 23 kere oyun oynasın
    {
        boncuk.kediOyunOyna();
    }

    boncuk.kediYolAl(132.212f); // Kedimiz 132.212 santım yol alsın

    boncuk.kediYas = 1; // Kedimiz 1 yaşında oldu

    return 0; // Program bu kısımda bittiğinden mütevellit boncuk nesnesin yıkıcı fonksiyonu çalışır. Kedimiz hayatını kaybetti o7
}

Copy Constructor

Copy Constructor türkçesiyle yapıcı kopyalama, tüm sınıflarda varsayılan olarak mevcut olan bir özelliktir. Amacı ise mevcut olan bir yapıcıyı kopyalarak başka bir yapıcıya aktarmaktır. İki türü vardır.
Shallow Copy yani üstünkörü kopyalama, kopyalama yönetemi ise aslında birebir kopyadan ziyade iki nesneyi aynı bellek adresine yönlendirme yöntemi ile kopyalar. Aynı orjinal ile kopyadaki değişiklikler birbirleri direkt olarak etkiler. Bir örnek yazalım;

#include <iostream>

using namespace std;

class ornekClass
{
    public:
        int x = 43; // Örnek olması açısından bir değişken tanımladık
};

int main()
{
    ornekClass nesne1; // Birinci nesnemiz
    ornekClass nesne2(nesne1); // İkinci nesnemiz, içerisindeki bahsedilen yapıcı ile çağırdık

    cout << "nesne1'deki X'in degeri; " << nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << nesne2.x << endl << endl;

    cout << "nesne1'deki X'in Pointer degeri; " << &nesne1.x << endl;
    cout << "nesne2'deki X'in Pointer degeri; " << &nesne2.x << endl << endl;

    nesne1.x += 7; // Birinci nesnedeki x'e 7 değerini ekledik. Bellek adresleri aynı olduğu için hem nesne1 hemde nesne2'deki x'e etki etmiş oldu

    cout << "nesne1'deki X'in degeri; " << nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << nesne2.x << endl << endl;

    nesne2.x += 10; // İkinci nesnenin x'ine 10 değerini ekledik

    cout << "nesne1'deki X'in degeri; " << nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << nesne2.x << endl << endl;
    
    return 0;
}
        
Çıktı;
Deep Copy yani derin kopyalama, bu işlem ise kopyalama yapıcı fonksiyonu düzenliyerek Pointer'ların farklı olarak kopyalanmasını sağlar. Yani orjinal ile kopya birbirlerini etkilemezler. Az önceki örneği bu yöntem ile yeniden düzenleyelim;

#include <iostream>

using namespace std;

class ornekClass
{
    public:
        int *x; // Farklı Pointer'lar için Integer Pointer'ı

        ornekClass(const int newX) // Değiştirilmiş yapıcı kopyalama fonksiyonu
        {
            x = new int; // Yeni Pointer oluşturduk
            *x = newX; // Parametre olarak girilen değeri girdik
        };

        ~ornekClass() // Yıkıcı fonksiyonumuz
        {
            delete x; // Yeni Pointer oluşturdurduğumuzdan dolayı sildik
        };
};

int main()
{
    ornekClass nesne1(43); // Birinci nesnemiz
    ornekClass nesne2(43); // İkinci nesnemiz

    cout << "nesne1'deki X'in degeri; " << *nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << *nesne2.x << endl << endl;

    cout << "nesne1'deki X'in Pointer degeri; " << nesne1.x << endl;
    cout << "nesne2'deki X'in Pointer degeri; " << nesne2.x << endl << endl;

    *nesne1.x += 7; // Birinci nesnedeki x'e 7 değerini ekledik. Bellek adresleri farklı olduğu için hem nesne1 hemde nesne2'deki x'e etki etmemiş oldu

    cout << "nesne1'deki X'in degeri; " << *nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << *nesne2.x << endl << endl;

    *nesne2.x += 10; // İkinci nesnenin x'ine 10 değerini ekledik

    cout << "nesne1'deki X'in degeri; " << *nesne1.x << endl;
    cout << "nesne2'deki X'in degeri; " << *nesne2.x << endl << endl;
    
    return 0;
}

Move Constructor

Move Constructor yani yapıcı taşıma, std kütüphanesinde yer alan ve nesnelerin içeriğini belirtilen nesye direkt olarak aktaran bir yapıcı türüdür.
Örnek olarak bu özelliğe sahip bir sınıf yazalım;

#include <iostream>

using namespace std;

class ornekClass
{
    public:
        int *x;

        ornekClass()
        {
            x = new int;
            *x = 12;
        };
        ornekClass(ornekClass&& clss) // std::move'un çağracağı yapıcı
        {
            x = clss.x; // Eski nesneden gelen Pointer'ı yeni nesneye aktarma
            clss.x = nullptr; // Eski nesnedeki Pointer'ı boşaltma
        };

        ~ornekClass()
        {
            delete x;
        }

        void yazdir() // Yazdırma fonksiyonu
        {
            if (x) // x Pointer'ı nullptr değil ise
            {
                cout << "X; " << *x << endl << endl;
            }
            else // nullptr ise
            {
                cout << "HATA" << endl << endl;
            }  
        };
};

int main()
{
    ornekClass nesne1; // Birinci nesnemiz
    ornekClass nesne2 = std::move(nesne1); // Birinci nesnemizi taşıdık

    nesne1.yazdir();
    nesne2.yazdir();

    return 0;
}

This Pointer'ı

This, mevcut sınıfı Pointer şeklinde kullanmak için kullanılan bir anahtar kelimedir.
Örnek olması için bir hesap makinesi yapalım;

#include <iostream>

using namespace std;

class hesapMakinesi // Hesap makinesi sınıfı
{
    public:
        int *sayi; // Hesap makinesinde kullanılıcak olan değişkenin kayıt edilceği Pointer

        hesapMakinesi(int *s) // Yapıcı fonksiyonunda hangi değişkene işlemlerin uygulanacağı
        {
            sayi = new int;

            sayi = s;
        }
        ~hesapMakinesi() // Yıkıcı ile Pointer'ı sildik
        {
            delete sayi;
        }

        // Basit matematiksel işlemlerin fonksiyonları. Her fonksiyonun sonucunda 'this' ile mevcut sınıfın Pointer'ını döndürür. Böylelikle topla()->cikar() gibi yapılar oluşturulabilir
        hesapMakinesi* topla(int s)
        {
            *sayi += s;

            return this;
        }
        hesapMakinesi* cikar(int s)
        {
            *sayi -= s;

            return this;
        }
        hesapMakinesi* bol(int s)
        {
            *sayi /= s;

            return this;
        }
        hesapMakinesi* carpma(int s)
        {
            *sayi *= s;

            return this;
        }
};

int main()
{
    int sayi1 = 100; // Mevzu bahis değişkenimiz

    hesapMakinesi hM(&sayi1); // Yapıcıya gönderdik

    hM.topla(10)->cikar(20)->carpma(2)->bol(10); // This ile yapımız
    // ((100 + 10 - 20) * 2) / 10 = Matematiksel gösterim karşılığıdır

    cout << "sayi1 degeri; " << sayi1 << endl; // Yazdırıyoruz
}

Sınıflarda Akıllı Pointer'lar Kullanımı

"Pointerlar" sayfasında kısaca değindiğimiz akıllı Pointer'ların devamını inceleyelim. Üç adet türü vardır. "Memory" kütüphanesinde yer alırlar.

Unique_ptr

Unique_ptr, yalnızca tek bir Pointer saklayan ve kopylama izin vermeyen bir akıllı Pointer'dır. Sadece Move fonksiyonu ile taşınabilir.
Örnek kullanımı;

#include <iostream>
#include <memory> // Kütüphanemiz

using namespace std;

class ornekClass
{
    public:
        int *s;

        ornekClass()
        {
            s = new int;
        }
        ~ornekClass()
        {
            delete s;
        }
};

int main()
{
    unique_ptr<ornekClass> sayi1 = make_unique<ornekClass>();
    *sayi1->s = 123; // Değer atadık

    cout << "sayi1'deki s'in degeri; " << *sayi1->s << endl << endl;

    //ornekClass* sayi2 = sayi1; Bu tarz bir kullanıma izin vermez
    unique_ptr<ornekClass> sayi2 = move(sayi1); // Taşıma ile verileri aktardık
    cout << "sayi2'deki s'in degeri; " << *sayi2->s << endl << endl;

Kapsülleme

Kapsülleme; nesne yönelimli programlama destekliyen yazılım dillerinde, atama ve üzerinde işlemler yapılma veya veriyi çağırma işlemlerin önüne bir fonksiyon gibi işlevler yazabildiğimiz OOP yöntemidir. Getter ile değişken çağrılırken Setter'da değişkene işlem yapılır.
Kapsülleme bir nevi ön ayar veya ön kontrol sistemi gibi çalışır. Örnek olarak bir değişkene sıfır atanmamasını sağlayabiliriz;

#include <iostream>

Kalıtım

Kalıtım, bir sınıfın içeriğini başka bir sınıfa direkt olarak miras alarak düzenleme veya kullanımı sağlayan bir OOP özelliğidir. Sınıfı kalıtmak için sinif1 : kalitilicakSinif şeklinde iki nokta(:) ile sağlanır.
Örnek olarak canlı örneğini yapalım;

#include <iostream>

using namespace std;

class canli // Genel canlı sınıfı
{
    public:
        // Canlılarda bulunan genel fonksiyonları
        void beslenme()
        {
            cout << "Canli beslendi!" << endl;
        }
        void hareket()
        {
            cout << "Canli hareket etti!" << endl;
        }
        void buyudu()
        {
            cout << "Canli buyudu!" << endl;
        }
};

class kedi : public canli // Kedi sınıfını canlı sınıfından kalıttık. Public yazdık ki public kısımlar direkt olarak aktarılsın
{
    public:
        void miyavlama() // Kediye özgü bir özellik ekledik
        {
            cout << "Kedi miyavladi!" << endl << endl;
        }
};

class kopek : public canli // Köpek sınıfını canlı sınıfından kalıttık
{
    public:
        void havlama() // Köpeklere özgü bir özellik 
        {
            cout << "Kopek havladi!" << endl << endl;
        }
};

int main()
{
    kedi kedi1;
    kedi1.beslenme(); // Canlı sınıfında olmasına rahmen, kalıtıldığından dolayı sınıfa aktarıldığı için kullanabiliyoruz
    kedi1.buyudu(); // Kedi büyüdü
    kedi1.hareket(); // Kedi hareket etti
    kedi1.miyavlama(); // Kedi sınıfının kendisinde bulunan fonksiyonunu çağırdık

    kopek kopek1;
    kopek1.beslenme(); // Canlı sınıfında olmasına rahmen, kalıtıldığından dolayı sınıfa aktarıldığı için kullanabiliyoruz
    kopek1.buyudu(); // Köpek büyüdü
    kopek1.hareket(); // Köpek hareket etti
    kopek1.havlama(); // Köpek sınıfının kendisinde bulunan fonksiyonunu çağırdık

    return 0;
}

Elmas Problemi

Elmas problemi, birden fazla kalıtımı yapıldığında karşımıza çıkan ve programda belirsizlik yaratan bir hatadır. Sebebi ise bir sınıfın birinci neslinden türetilen ikinci neslinde ata sınıftan gelen özellikleri kullanımından çıkar. Çünkü ikinci nesildeki kullanılmak istenen özellik hem birinci nesil hemde ata sınıf sahip olduğu için karışıklık olur ve bu iki sahip arasında program kararsız kalır ve derlenemez.
Bu hatayı çözmek için ise "virtural" sözcüğü kullanılır. Kelime anlamıyla sanal yöntemi, sınıfları aktarırken sahipliği üzerine yazılmadığı süreççe özelliği aktarmaz. Çok biçimlilik konusunda daha detaylı göreceğiz fakat kalıtım yönteminde elmas problemini çözebildiğini bilmemiz yeterlidir.
Şimdi gelin şöyle yapalım. Kedinin ve köpeğin bir mucize aracılığıyla bir yeni tür çıktığını varsayalım. Adı ise "kopdi" olsun. Kopdi sınıfı doğal olarak hem kedi hem canlı hemde köpek sınıflarının özelliğini taşımalı. Demek ki kalıtım uygulacağız fakat elmas problemi yüzünden canlı sınıfındaki özellikleri aktaramayız. İşte bu durumda köpek ve kedi sınıfını canlı sınıfından kalıtırken virtural olarak aktarıcağız ki canlı sınıfındaki özelliklerin sahipliği canlı sınıfında kalsın.
        
#include <iostream>

using namespace std;

class canli
{
    public:
        void beslenme()
        {
            cout << "Canli beslendi!" << endl;
        }
        void hareket()
        {
            cout << "Canli hareket etti!" << endl;
        }
        void buyudu()
        {
            cout << "Canli buyudu!" << endl;
        }
};

class kedi : virtual public canli // Sanal olarak aktardık ki özelliklerin sahiplikleri canlı sınıfında kalsın
{
    public:
        void miyavlama()
        {
            cout << "Kedi miyavladi!" << endl << endl;
        }
};

class kopek : virtual public canli // Sanal olarak aktardık
{
    public:
        void havlama()
        {
            cout << "Kopek havladi!" << endl << endl;
        }
};

class kopdi : public kedi, public kopek{}; // Direkt olarak aktarabiliriz. Çünkü köpek ve kedi sanal olarak canlı sınıfını taşımakta

int main()
{
    kopdi kopdi1; // Kopdi nesnemiz
    kopdi1.beslenme();
    kopdi1.buyudu();
    kopdi1.hareket();
    kopdi1.havlama();
    kopdi1.miyavlama();

    return 0;
}

Sanal Fonksiyonlar

Geldik çok biçimliliği var eden özelliğe; Çok biçimli nesneler veya beni tabirimle "mış" gibi yapan nesnelere... Peki nedir bu "mış" gibi yapan nesneler? Kısaca ata sınıfından oluşturulmuş bir nesneyi diğer nesillere uydurma biçimidir. Yani nesne olarak "canli" olarak gözüksede özelliklerini "kedi" sınıfından alır.
Peki sanal fonksiyonlar nedir? Onlar ise bu "mış" gibi yapan nesnelerin atadan gelen özellikleri nesile göre üzerine yazmamızı sağlayan fonksiyon türledir. Aynı şekilde virtural kelimesi ile sanallaştırılır, override ile de sanal fonksiyonların üzerlerine yazılır.
Örnek olması açısından kalıtımdaki örneğimizi sanal fonksiyonlar ile yeniden yazalım;

#include <iostream>

using namespace std;

class canli
{
    public:
        void beslenme()
        {
            cout << "Canli beslendi!" << endl;
        }
        void hareket()
        {
            cout << "Canli hareket etti!" << endl;
        }
        void buyudu()
        {
            cout << "Canli buyudu!" << endl;
        }

        virtual void sesCikar() {}; // Ses çıkarma fonksiyonunun bir sanal fonksiyon olduğunu belirttik
};

class kedi : public canli 
{
    public:
        void sesCikar() override // Sanal olarak tanımlanan fonksiyonu override ile üzerine yazdık
        {
            cout << "Kedi miyavladi!" << endl << endl;
        }
};

class kopek : public canli
{
    public:
        void sesCikar() override
        {
            cout << "Kopek havladi!" << endl << endl;
        }
};

int main()
{
    canli *canli1; // Pointer tanımladık ki farklı farklı nesnelerin içeriğini alalım
    kedi kedi1; // Kedi nesnemiz

    canli1 = &kedi1; // Kedi nesnemizin Pointer'ını canlı nesnemize aktardık ki çok biçimli oldu
    canli1->beslenme();
    canli1->buyudu();
    canli1->hareket();
    canli1->sesCikar(); // Kedi sınıfına ait olan fonksiyon çağrılır

    kopek kopek1;

    canli1 = &kopek1; // Köpek nesnemizin Pointer'ını canlı nesnemize aktardık ki çok biçimli oldu
    canli1->beslenme();
    canli1->buyudu();
    canli1->hareket();
    canli1->sesCikar(); // Köpek sınıfına ait olan fonksiyon çağrılır

    return 0;
}

Arkadaş Fonksiyonlar

Arkadaş veya ortak fonksiyonlar, sınıflarda sınıflara ortak olan ve onların private, protected ve public alanlarına erişimine sahip olan fonksiyon türüdür. friend kelimesi ile tanımlanır. Sınıf içinde imzaları bırakılır ardından tanımlanır.
Bilirsiniz ki en iyi arkadaşınız sizin her şeyinizi bilirler. Sırlarda dahil! Fakat diğer arkadaşlarınız sırlanırını bilmezler... İşte bu durumu C++ programlama dilinde kodlayalım;

#include <iostream>

using namespace std;

class ahmet
{
    private: // Özel alanınız
        string sir = "Geceleri anime izlemeden uyumam..."; // Sırrınız
        
    public:
        void sirriniSoyle() // Kendi sırrını bilirsin
        {
            cout << "Benim sirrim; " << sir << endl << endl; // Söylersin
        }

        friend void mehmetAgam(ahmet ahmetinKisiligi); // Mehmet en iyi arkadaşın olsun

        void ayse(ahmet ahmetinKisiligi); // Ayşe isminde de başka arkadaşın olsun
};

void mehmetAgam(ahmet ahmetinKisiligi) // Mehmet'in yeri
{
    cout << "Ahmet'in sirri; " << ahmetinKisiligi.sir << endl << endl; // Mehmet en iyi arkadaşınız olduğu için sırrınızı bilir
}

void ayse(ahmet ahmetinKisiligi) // Ayşe'nin yeri
{
    //cout << "Ahmet'in sirri; " << ahmetinKisiligi.sir << endl << endl; // Fakat Ayşe en iyi arkadaşınız olmadığı için sırrınızı bilmez

    cout << "Ahmet'in sirrini bilmiyorum..." << endl << endl;
}

int main()
{
    ahmet ben; // Kendinizi nesne olarak tanımladınız

    ben.sirriniSoyle(); // Kendi sırrını söyledin

    mehmetAgam(ben); // Mehmet'te senin sırrını söyledi
