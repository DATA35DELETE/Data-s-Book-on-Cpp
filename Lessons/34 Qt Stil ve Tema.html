Stil ve Tema

QSS

QSS yani Qt Style Sheets(Qt Stil Dili), Qt Widget kütüphanesindeki ögeler için CSS benzeri bir stil dilidir. Tıpkı CSS gibi yazılır ve CSS gibi stilleme işlemi gerçekleştirilir.
Ögelerin isimleri Id, sahip oldukları tür ise Class olarak geçmektedir. Stillemek istediğimiz ögenin veya ögelerin bu iki özellikle ile stilleyebiliriz.
BU sayfada "Stil ve Tema" konusunu görceğimiz için "stilVeTema" adlı projemizi açalım.

QSS Dosyası Bağlama

QSS dosyası bağlamak için Qt'nin Assets sistemini kullanmamız gerekir. Peki nedir bu Assets sistemi? Kısacası tanımlanan dosyaların bilgilerini uygulamanın içerisine gömen bir sistemdir. Böylelikle sistem dosyalarını ayrı bir dosya yerine uygulamanın içerisine gömülmüş şekilde kullanılır.
İlk olarak Assets sistemi için assets.qrc adlı bir dosya oluşturalım. Daha sonra main.qss adlı bir dosya oluşturalım ve main.qrc dosyasına ekliyelim. Ardından main.cpp dosyasının içeriğini şu şekilde değiştirelim;

#include "mainwindow.h"

#include <QApplication>
#include <QFile>

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);

    QFile qssSource(":/main.qss"); // main.qrc'deki main.qss dosyasına erişiyoruz
    QString source; // Kaynak kod
    QString sourceBuffer; // Kaynak kodu okumak için ara bellek

    qssSource.open(QFile::OpenModeFlag::ReadOnly); // Dosyayı sadece okuma modunda açıyoruz

    while((sourceBuffer = qssSource.readLine(500)) != nullptr) // 500 karakterlik sınır ile ile her satırı okuyoruz
    {
        source += sourceBuffer; // Ara belleğe atanan veriyi kaynak koduna ekliyoruz
    }

    qssSource.close(); // Dosyayı kapattık

    a.setStyleSheet(source); // Uygulamamızın genel QSS'nini bizim kendi okuduğumuz main.qss dosyasındaki kaynağını ayarlıyoruz

    MainWindow w;
    w.show();
    return QApplication::exec();
}

Stilleme

Stillemek için bir çok seçenek bulunmaktadır. Bunlardan bir çoğu aşağıdaki main.qss kodunda verilmiştir;

* { /* "*" işareti bütün ögeler anlamına gelir */

    background-color: red; /* Arka planı renklendirmek için renklerin İngilizce isimleri */
    /* background-color: #ffffff;  veya rengin HEX kodu girilir  */
    color: white; /* Yazı rengini ayarlamak için */
}

QPushButton{ /* Bu özellikler sadece QPushButton yani buttonlara özel olarak uygulanır */

    border: 2px solid blue; /* Ögenin etrafına 5 piksel kalınlığında mavi bir çerçeve çizer */
    border-radius: 10px; /* Çerçeveyi 10 piksel olucak şekilde ovallaştırır*/
}

QPushButton:hover{ /* ":" karakteri ile "Eğer bir olay varsa şunu yap" emridir. Bu örnekte "hover" "Fare üzerinde geldiğinde" demektir */

    background-color: gray;
}

QLabel{

    background-color: yellow;
    color: black;

}

#label{ /* "label" etiketine sahip bir ögenin özelliğini tanımlıyoruz */

    background-color: green; /* Etiket üzerinden yapılan değişiklikler her zaman diğer özelliklerden üstün gelir */
    color: red;

    margin: 6px; /* Dış kısımdan 6 piksel boşluk bırakır */
    padding: 2px; /* İç kısımdan 2 piksellik boşluk bırakır */

}

Font Ayarlama

Herhangi bir ögenin yazı kısmındaki fontu ayarlamak istersek, mainwindow.ui üzerinden gözlemleyelim;

Aydınlık/Karanlık Tema Ayarlama

Bu iki temada işletim sistemi tarafından verilen hazır bir renk paketidir. Bu sebeble main.qrc dosyasının içeriğini temizleyelim. Aydından tema için herhangi bir ayarlamaya gerek kalmaz. Zaten çoğu işletim sistemi varsayılan olarak aydınlık tema kullanılır. Ama eğer biz karanlık tema istersek main.cpp üzerinde bazı değişiklikler yapmamız gerekir;

#include "mainwindow.h"

#include <QApplication>

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);
    
    a.setStyle("fusion"); // Uygulamanın genel temasını ayarlar. Fusion genelde karanlı tema için kullanılır
    
    MainWindow w;
    w.show();
    return QApplication::exec();
}
