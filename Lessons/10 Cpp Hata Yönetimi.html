Hata Yönetimi

Hata Yönetimi Nedir?

Hata yönetimi, bir programda beklenmeyen bir durum ile karşılaştığındaki programın davranış biçimine hata yönetimi denir.
Hata yönetimi esasen çok önemli bir konudur. Çünkü neredeyse tüm hatalar programı çökertecek potansiyele sahiptir ve biz programın çökmesini elbette istemeyiz. İşte bu sebeble hata yönetimini iyi yapmalıyız ki beklenmeyen durumlara hazırlıklı olalım.

Errno

Errno, C'den beri var olan ve hata kodlarını kendine kayıt eden bir değişken görevi görür. Bir nevi eğer beklenmeyen bir durum gerçekleştiğinde haya kodu ilk olarak Errno'ya kayıt edilir.
Gelin beraber bir örnek yapalım. Dosya işlemlerinden olan dosya yazma komutnu kullanalım. "Dosya İşlemleri" sayfasında daha detaylı inceleceğimiz bu işlemde, komut eğer okunacak bir dosya bulamazsa bir hata kodu ile programa devam eder. İşte bu dönen hata kodu Errno'ya kayıt edilir. Gelin bu kodda bu örneği gözlemleyelim.

#include <iostream>

using namespace std;

int main(){
    
    FILE* ornekDosya = fopen("okunacakDosya.Uzantisi", "r"); // Dosya okuma işlemidir. Böyle bir dosya bulunmadığı için hata kodu vericektir ve NULL döner
    if (ornekDosya == NULL) // Birçok standart komut gibi fopen da başarısız olursa NULL döner. Bir başka hata yönetimi tekniğide budur
    {
        cout << "Hata kodu; " << errno << endl; // Kodu ilettik
    }
    
    fclose(ornekDosya);

}

Çıktı ise;
Hata kodları belirli başlı hataların ne anlama geldiğini sayısal olarak ifade etmek için kullanılır. Belirli başlı hataların kodlarını bu tabloda görebilirsiniz;
Hata Kodu Anlamı
0 Hata Yok
1 İşlemeye İzin Verilmiyor
2 Böyle Bir Dizin veya Dosya Yok
3 Böyle Bir Süreç Yok
4 Kesintiye Uğramış Sistem Çağrısı
5 G/Ç Hatası
6 Böyle Bir Cihaz veya Adres Yok
7 Argüman Listesi Çok Uzun
8 Yürütme Biçimi Hatası
9 Geçersiz Dosya Numarası
10 Çocuk Süreçleri Yok
11 Tekrar Deneyin
12 Hafıza Yetersiz
13 İzin Red Edildi

Perror ve Strerror

Perror ve Strerror, ikiside hata kodlarından hata mesajlarını almak için kullandığımız için fonksiyondur.
Perror, mevcut Errno'u alır ve parantezlerinde belirtilen hata ile beraber ekrana yazdırır. Strerror ise girilen hata koduna bağlı olan hata mesajını sonuç olarak verir.
Örnek olması açısından mevcut kodumuza bu iki özelliği ekliyelim

#include <iostream>
#include <string.h> // Strerror için C API'larından string.h'a ihtiyaç duyarız. Evet C'deki kodları istersek C++'da direkt olarak kullanabiliriz

using namespace std;

int main(){
    
    FILE* ornekDosya = fopen("okunacakDosya.Uzantisi", "r");
    if (ornekDosya == NULL)
    {
        cout << "Hata kodu; " << errno << endl;
        perror("Perror ile hata mesaji"); // Perror ile hata mesajını gösterdik
        cout << "Hata mesaji; " << strerror(errno) << endl; // Strerror ile de hata mesajını aldık
    }
    
    fclose(ornekDosya);

}

Çıktı;

Assert

Assert komutu bizlere bir programda hata yönetiminde direkt programı hata mesajı ile kapatmamızı sağlayan özel bir fonksiyondur.
Parantezlerindeki değer eğer sıfır ise programı durdurur ve hata mesajını ekrana bastırır.
Gelin bu özelliği programa dahil edelim

#include 
#include  // Assert fonksiyonu için gerekli kütüphane

using namespace std;

int main(){
    
    FILE* ornekDosya = fopen("okunacakDosya.Uzantisi", "r");
    
    assert(ornekDosya != NULL); // ornekDosya NULL olduğunu için Assert programı durdurur
    
    fclose(ornekDosya);

    return 0;
}

Çıktı;

İstisna Yönetimi

Geldik C'de bulunmayana fakat C++ ile gelen özelliğimize, istisna yönetimi! Bu yöntem C'deki gibi hata yönetimine kıyasla çok daha High-Level ve daha kullanışlı bir yöntemdir.

Try-Catch-Throw

Bu yapı C++ programlama dilinde bizlere istisna yönetimini mümkün kılan yapıdır. Mantığı ise try'ın blokları throw ile çıkartılıcak olan hataları yakalar ve catch gönderir, catch, throw ile çıkartılan hataların mesajlarını parametre olarak atar. Throw ise hata çıkartmamızı sağlar.
Gelin bu yeni özellikle ile kodumuzu geliştirelim;

#include <iostream>
#include <string.h>

using namespace std;

int main(){
    FILE* ornekDosya; // Değişkenini bu kısımda tanımladık çünkü fclose Try içerisine erişemez

    try // Throw ile hata çıkartılıcak olan kısım
    {
        ornekDosya = fopen("okunacakDosya.Uzantisi", "r");
        if (ornekDosya == NULL) // Açma kısmında hata çıkarsa
        {
            throw errno; // Hata kodunu gönder
        }
    }
    catch(int e) // Throw ile çıkartılan hataların geldiği kısım
    {
        cerr << "Hata mesaji; " << strerror(e) << endl; // Standart Error ile hata şeklinde çıktı çıkartalım
    }
    
    fclose(ornekDosya);

    return 0;
}

Çıktı ise;
Throw ile tabi Integer yerine başka veri türleride Catch'e gönderilebilir. Sadece Catch tarafında Throw'un gönderdiği değişken türünü yakalıcak bir kısım olsa yeterlidir.
