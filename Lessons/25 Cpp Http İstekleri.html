Http İstekleri

Http İsteği Nedir?

Http isteği, internet üzerinde istediğimiz verileri elde etmek için yaptığımız veri alışverişlerini sağlayan bir sistemdir.
Peki ne zaman kullanılır? Genelde uygulamamızda bazı hazır servisleri veya uzaktadaki sunucumuzla iletişim için kullanırız. Böylelikle internetle iletişim kurmuş oluruz.

libcurl Kütüphanesi

Libcurl, Http istediği atmamızı sağlayan Curl aracının kütüphane versiyonudur. Ayrıca kendisi bir C kütüphanesidir.
Kurmak için:

Windows; pacman -S mingw-w64-x86_64-curl
Linux; sudo apt install libcurl4-openssl-dev

Şeklinde bilgisayarımıza yükleriz.

GET İsteği

GET, Http isteklerinden biridir. GET, bir sunucudan bir veri almak için kullanılan bir yöntemdir. Yani sadece bir veri almak veya bir internet sayfasının içeriğini indirmek için kullanılan bir yöntemdir.
Şimdi gelin bir önceki sayfanın kaynak kodlarını Libcurl ile çekelim;

#include <iostream>
#include <curl/curl.h> // Kütüphanemiz

int main()
{
    CURL* curlAraci = curl_easy_init(); // Curl bizlere basit bir araç sunmak için "Easy" modunda bizlere bir çok fonksiyon sağlar. curl_easy_init komutu bizlere bir Curl aracı nesnesi verir

    if (curlAraci) // Eğer Curl aracı boş değil ise ki oluşturma başarısız olursa fonksiyon Null döner
    {
        curl_easy_setopt(curlAraci, CURLOPT_URL, "https://data35delete.github.io/Data-s-Book-on-Cpp/Lessons/24%20Cpp%20Veritabanı%20İşlemleri.html"); // Curl aracına tüm parametreleri curl_easy_setopt ile veririz. Mantık basit;
        // curlAraci; Etki edilicek olan Curl nesnesi
        // CURLOPT_URL; Parametre türü. Şuanlık URL ekliyoruz
        // "https://data35delete.github.io/Data-s-Book-on-Cpp/Lessons/24%20Cpp%20Veritabanı%20İşlemleri.html"; Parametrenin ekliceği veri. Biz GET isteği istediğimiz için site linkini yapıştırdık

        curl_easy_perform(curlAraci); // En son ayarlamalar bittiğinde ise Curl nesnesini çalıştırız ve çıktımız gözlemleriz. Bazı ayarlamlar yapılmazsa çıktı konsola yazdırılır.
    }

    curl_easy_cleanup(curlAraci); // Bellek yönetimi için serbest bırakıyoruz
    
}

Derliyelim;

g++ main.cpp -o main -lcurl

Çıktısı ise;

Çıktıyı Bir Fonksiyona Yönlendirme

Eğer çıktıyı bir fonksiyona göndermek istersek?
Şimdi çektiğimiz sayfade kaç adet karakterin olduğunu bizlere veren bir program yazalım. Bunu ise Libcurl'un bizlere sunduğu "CURLOPT_WRITEFUNCTION" parametresini kullanalım;
            
#include <iostream>
#include <curl/curl.h>

using namespace std;

string datasbookoncppVeritabaniIslemleriSayfasi; // Syafanın içeriğini barındırıcak olan değişken

unsigned long long curlAraciCallbackFonksiyonu(char *veri, size_t verininSirasi, size_t gelenVerininBoyutu,void *kullaniciVerisi) // Callback fonsiyonumuz. Gelen her veri bu fonksiyona gelicektir
// char *veri; Verinin kendisidir
// size_t verininSirasi; Gelen verinin sırasıdır
// size_t gelenVerininBoyutu; Gelen verinin gerçek boyutudur
// void *kullaniciVerisi; Kullanıcı tarafından gönderilen veridir
{
    for (int i = 0; i < gelenVerininBoyutu; i++)
    {
        datasbookoncppVeritabaniIslemleriSayfasi += veri[i]; // Her harfi teker teker ekliyoruz ki veri fazlası yaşanmasın
    }
    
    return verininSirasi * gelenVerininBoyutu; // Dönüş tipi olarak bu iki değerin çarpımını vermek zorundayız. Yoksa Curl Get işlemine devam etmez
}

int main()
{
    CURL* curlAraci = curl_easy_init();

    if (curlAraci)
    {
        curl_easy_setopt(curlAraci, CURLOPT_URL, "https://data35delete.github.io/Data-s-Book-on-Cpp/Lessons/24%20Cpp%20Veritabanı%20İşlemleri.html");

        curl_easy_setopt(curlAraci, CURLOPT_WRITEFUNCTION, curlAraciCallbackFonksiyonu); // Parametremizi ayarlıyoruz

        curl_easy_perform(curlAraci);
    }

    cout << "Data's Book on Cpp - Veritabani Islemleri sayfasinin boyutu; " << datasbookoncppVeritabaniIslemleriSayfasi.length() << endl; // Yazdırma

    curl_easy_cleanup(curlAraci);
}

Çıktımız ise; "Data's Book on Cpp - Veritabani Islemleri sayfasinin boyutu; 33592" olucaktır.

Çıktıyı Bir Dosyaya Yönlendirme

Bu seferde tanımladığımız bir dosyaya yazdırılsın. C kütüphanesi olmasından dolayı FILE* verilmelidir. Parametre olarak "CURLOPT_WRITEDATA" kullanılır.
Hadi uygulayalım;

#include <iostream>
#include <curl/curl.h>

using namespace std;

int main()
{
    CURL* curlAraci = curl_easy_init();

    FILE* curlCikti = fopen("curlCikti.html", "w"); // Çıktının yazılcak dosyamız

    if (curlAraci)
    {
        curl_easy_setopt(curlAraci, CURLOPT_URL, "https://data35delete.github.io/Data-s-Book-on-Cpp/Lessons/24%20Cpp%20Veritabanı%20İşlemleri.html");

        curl_easy_setopt(curlAraci, CURLOPT_WRITEDATA, curlCikti); // Parametremizi ayarlıyoruz

        curl_easy_perform(curlAraci);
    }

    fclose(curlCikti); // Dosyamızdan çıkıyoruz

    curl_easy_cleanup(curlAraci);
}

Program çalıştıktan sonra klasörümüzde çıkan "curlCikti.html" dosyasını açalım. Göreceğimiz görüntü ise beyaz bir arka planda sayfamızın içeriğidir.
