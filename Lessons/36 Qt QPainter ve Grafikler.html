QPainter ve Grafikler

QPainter Nedir?

QPainter; üzerine resim çizdirip, yazı yazdırabildiğimiz bir nesnedir. Kolaylık sağlayan fonksiyonları ile sadece konumu, boyutunu ve içeriği yazarak QPainter'ın içerisine bileşenler yazabiliriz.
Peki neden QPainter? Aslında soruda cevap saklıdır. "Painter" yani çizici veya ressem anlamına gelen bu nesne, kullanıcı yahut programcı tarafından çizim işleri için sıklıkla kullanılır.
Bu sayfada QPainter'ı öğreneceğimiz için "qpainter" adlı bir proje açalım.

QPainter

İlk olarak mainwindow.h ve mainwindow.cpp içeriklerini değiştirelim;

mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>
#include <QPainter> // Kütüphaneler
#include <QPaintEvent>


QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

protected:
    void paintEvent(QPaintEvent*); // paintEvent, hangi akla hizmet bilinmez ama QPainter işlemlerinin büyük kısmı paintEvent fonksiyonunda gerçekleşir. Ayrıca bu fonksiyona biz Override yani üzerine yazıyoruz

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::paintEvent(QPaintEvent *) // Fonksiyonumuz
{
    QPainter painter(this); // QPainter nesnemiz, this çünkü çizimler direkt olarak kendi penceremizde gözükücek
    painter.drawLine(0,100,300,100); // Örnek olarak bir çizgi çizdirelim
    // 0; Çizgi başlangıç noktasının x'si
    // 100; Çizgi başlangıç noktasının y'si
    // 300; Çizgi bitiş noktasının x'si
    // 100; Çizgi bitiş noktasının y'si
}

Çıktısı;
Gördüğünüz gibi ekranımızın sol üst köşesinde 300 piksellik bir çizgi oluşturduk.
Bunun gibi bir çok işlevi görelim;

mainwindow.cpp
#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::paintEvent(QPaintEvent *) // Fonksiyonumuz
{
    QPainter painter(this); // QPainter nesnemiz, this çünkü çizimler direkt olarak kendi penceremizde gözükücek

    painter.setPen(Qt::red); // Kalem ayarlar. Ondan sonraki renksiz çizimleri belirtilen renge göre çizer

    painter.drawLine(0,100,300,100); // Örnek olarak bir çizgi çizdirelim
    // 0; Çizgi başlangıç noktasının x'si
    // 100; Çizgi başlangıç noktasının y'si
    // 300; Çizgi bitiş noktasının x'si
    // 100; Çizgi bitiş noktasının y'si

    painter.setPen(Qt::blue);

    painter.setFont(QFont("Calibri", 24)); // Fontunu ayarlar

    painter.drawText(rect(), Qt::AlignHCenter, "Selamlar"); // Yazı yazdırtır
    // rect(); Çizilebilir alan olarak pencerenin boyutunu gönderiyoruz
    // Qt::AlignHCenter; Neresinde çizilcek
    // "Selamlar"; Yazı

    painter.drawRect(10, 200, 100, 100); // İçi boş dikdörtgen çizmemizi sağlar
    // 10; Dikdörtgen başlangıç noktasının x'si
    // 200; Dikdörtgen başlangıç noktasının y'si
    // 100; Dikdörtgenin uzunluğu
    // 100; Dikdörtgenin yüksekliği

    painter.fillRect(QRect(120, 200, 100, 100), QBrush(Qt::yellow)); // İçi dolu dikdörtgen çizmemizi sağlar
    // QRect(120, 200, 100, 100); Dikdörtgen bilgileri
    // QBrush(Qt::yellow); İçinin rengi

    painter.setPen(Qt::green);

    painter.drawRoundedRect(QRect(230, 200, 100, 100), 50.5, 33.2); // İçi boş köşelerinin yuvarlatılmış dikdörtgen çizmemizi sağlar
    // QRect(220, 200, 100, 100); Dikdörtgen
    // 50.5; Yataydan yapılcak yumuşatma pikselleri
    // 33.2; Dikeyden yapılcak yumuşatma pikselleri

    painter.setPen(Qt::GlobalColor::magenta);

    painter.drawEllipse(10, 320, 100, 100); // Daire çizmemizi sağlar
    // 10; Daire başlangıç noktasının x'si
    // 320; Daire başlangıç noktasının y'si
    // 100; Dairenin uzunluğu
    // 100; Dairenin yüksekliği

    painter.drawImage(QRect(120, 320, 100, 100) ,QImage("C:\\Users\\DATA\\Pictures\\workAndData.png")); // Belirtilen fotoğraf dosyasını belirli boyutlarda çizer
    // QRect(120, 320, 100, 100); Çizim alanı bilgisi
    // QImage("C:\\Users\\DATA\\Pictures\\workAndData.png"); Çizilcek fotoğrafın QColor ile yolu

    painter.setPen(Qt::GlobalColor::black);

    painter.drawPolygon(QPolygon({QPoint(230, 320), QPoint(280, 320), QPoint(230, 420)})); // Çokgen çizmemizi sağlar
    // QPoint(230, 320); Kordinat düzleminde konum belirtir
    // {QPoint(230, 320), QPoint(280, 320), QPoint(230, 420)}; Bu listede istenilen miktarda nokta konulabilir
}

QPixmap vs QImage vs QIcon

Bu üç nesnenin görevi resimleri yönetmek olsada yöntemleri birbirlerinen farklıdır.
QPixmap, fotoğrafların piksellerini görüntülenecek olan ögenin genişliğini ve yükseliğine göre fotoğrafı ayarlayan bir sınıftır. Yani otomatik bir boyutlandırıcı gibi çalışır. Bu sebeble QLabel'lerde sıklıkla kullanılır.
QImage, fotoğrafların görüntülenecek olan ögeden bağımsız olarak piksellere tam erişim sağlatan bir sınıftır. Boyutu önceden tanımlı fotoğraf ögelerinde kullanılır.
QIcon, yazıların yanına fotoğraf eklemek için kullanılır. Boyutlandıralabilir özelliği sayesinde QPixmap'e benzemektedir. Kendine has özelliği ise yazıların yanına tıpkı yaz gibi davranan bir fotoğraf sağlamasıdır. Bu sebeble QPushButton ögesinde sıklıkla kullanılır.
