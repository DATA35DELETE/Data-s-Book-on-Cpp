Layoutlar

Layoutlar, bizlere pencerenin boyutuna göre genişleyen veya daralan yani uyum sağlayan Widget'lar sunar.
Peki neden önemli? Çünkü adaptasyon! Her pencere istediğiniz uzunlukta veya genişilikte olmayabilir. Örneğin birisi pencereleri büyük sever, diğeri küçük. Normal şartlarda bu pek bir durum ifade etmez ama pencere tarafında ögelerimiz düzgün boyutlarda olmaya bilirler. Bunun en büyük örneği bilgisayar uygulamaları Qt üzerinden mobile taşınırken yaşanır. Bilgisayar ekranı (çoğu durumda) 1920x1080 piksel genişliğinde yani yataydır. Ama telefon ekranları dikeydir. Bu sebeble, çoğu öge ya ekrana yarım gözükür veya hiç gözükmezler. İşte tamda bu durumlarda Layoutlar bizim için bu sorunu çözerler. Layoutlar, türleriyle olmakla beraber pencerenin genişliğini ve uzunluğunu kontrol ederek, içlerindeki ögeleri otomatik olarak büyütür veya küçültür.
Örnek olması için aşağıda iki adet örnek verilmiştir. İlki Layoutsuz, diğeri ise Layoutludur. Ayrıca "layoutlar" adında bir proje oluşturalım.

QHBoxLayout

QHBoxLayout, içerisindeki ögeleri dikey olarak boyutlandırır. Hem öge hemde pencereye atanabilir durumdadır.

QVBoxLayout

QVBoxLayout, içerisindeki ögeleri yatay olarak boyutlandırır. Hem öge hemde pencereye atanabilir durumdadır.

QFormLayout

QFormLayout, içerisindeki ögeleri etiket-alan olarak ikili bir şekilde boyutlandırır. Etiket bilgi, alan ise bilginin aldığı kullanıcı verilerinin girildiği kısımdır. Yani Etiket QLabel iken, QButton ise alan olur. Hem öge hemde pencereye atanabilir durumdadır.

QGridLayout

QGridLayout, ögelere göre ekranı bölmelere yanı ızgaralara ayıran bir Layoutdur. Hem öge hemde pencereye atanabilir durumdadır.

QStackedLayout

Sayfa sayfa gibi bir görünüm sağlar. Ögeler farklı sayfalarda bulunabilir.
mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots:
    void sifirinciSayfa();
    void birinciSayfa();

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    connect(ui->pushButton, &QPushButton::clicked, this, &MainWindow::sifirinciSayfa);
    connect(ui->pushButton_2, &QPushButton::clicked, this, &MainWindow::birinciSayfa);
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::sifirinciSayfa()
{
    ui->stackedWidget->setCurrentIndex(0);
}
void MainWindow::birinciSayfa()
{
    ui->stackedWidget->setCurrentIndex(1);
}

Boşlukçu

Boşlukçu, Layoutlarda bazı yerlere boş yapmamızı sağlayan bir ögedir. Kullanım yönünden yatay ve dikey olarak iki adet bulunur.

Boyut Politikası

Boyut politikası; Layoutlarda bir ögenin hangi şartlar altında olursa olsun, belirlenen boyutlarda bulunması kuralıdır. Hem minimum hemde maksimum durumları için politikaları vardır. Minimumda öge belirtilen değerlerin altına inemezken, maksimumda belirtilen değerlerin üstüne boyut olarak çıkamamasını sağlar.
