CMake

CMake Nedir?

CMake; C, C++ ve vb. dillerin derleme otomasyon aracıdır.
Peki nedir bu "Derleme Otomasyon" aracı? Derleme otomasyonu; Bir komutla tanımlı bütün kaynak kodları ve kütüphaneleri derliyen ve kullanım kolaylığı sağlayan araçlara denir? Yani sizin projenizde yüz adet kaynak kod varsa, derlerken yüz adet kaynak kod dosyalarının isimlerini teker teker girmek yerine bir komuta bağlayıp tek seferde derliyebiliyorsunuz.
Peki neden CMake? C ve C++ programlama dillerin derleme otomasyonları küçük büyük proje fark etmez her zaman gereklidir. Çünkü doğası bir çok kütüphane ve kodların ayrı şekilde yazılması gereken bir dildir. Biz bu yazdığımız bütün kodları teker teker yazmak yerine bir derleme otomasyonuna tanımlayıp tek bir komutla derlemimizi kolaylaştırabiliriz. Eski zamanlarda bu tarz sistemler işletim sisteminin ve bilimum hangi derliyiciye göre değişiklik gösteren Bash komutları yazılırdı. Bu Bash komutları derlemek kodları derlemek istiyenler için yazılır ve tek bir komutla iş çözülürdü. Lakin sistemler geliştikçe farklı ihtiyaçlar doğruldu ve bu sistem artık hantal ve hatta kendimiz uğraşsak daha kolay olucak bir durum aldı. O zamanlarda Make denilen ve bilgisayarın saf diline çevirlen yani derlenen yazılım dilleri için bir kurtarıcı oldu. Bash benzeri bir sözdizime sahipti ve ayarlamalar ile tüm işletim ve derleyici sistemlerine uyumlu olucak şekilde kodları derliyebiliyordu. Lakin Bash'te yapılan kolaylıkların başına gelen durum Make'inde başına geldi ve oda bir işkenceye dönüştü. Yapısı gereği sözdizimi karmaşıktı ve yeni başlıyanlar zorlanmaya başladı. Bu duruma son noktayı koyan programda ki sayfamızın konusu olan CMake'tır. CMake hem çapraz işletim ve derleyici sistemini hemde sözdizimi sorunlarını "Fonksiyon Tabanlı" bir şekilde çözmüştü.
CMake; 1999 yılında Kitware tarafından geliştirilmiş ve 2000 yılında ilk sürümü çıkartılmış bu derleme otomasyon aracı; C ve C++ programlama dillerini ondan fazla derliyici ile derleme otomasyonunu mümkün kılan derleme otomasyon aracıdır.

CMake Kurulumu

Windows;

pacman -S mingw-w64-x86_64-cmake

Linux

sudo apt install cmake

Proje Oluşturma

CMake ile bir proje oluşturma için ilk olarak boş bir klasör içerisinde "source" ve "build" adlı iki adet klasör oluşturalım. "source" klasörü kaynak kodlarımızın buluncağı, "build" klasörü ise kaynak kodlarının derlenmiş hallerini ve çalıştırabilir dosyalarını barındırcağı klasördür
Ardından "source" klasörüne girelim ve CMake projemiz için gerekli olan "CMakeLists.txt" dosyasını oluşturalım. Bu dosya önemlidir çünkü CMake projemizin kalbı burasıdır. Tüm kaynak kodları ve bağlanması gereken kütüphaneleri bu dosyada tanımlıyoruz.

CMakeLists.txt

Projemiz klasiklerden bir hesap makinesi olsun ki birden fazla dosyaya ihtiyaç duyalım. CMakeLists.txt'de istediklerimizi belirtmek için şu şekilde dolduralım;
cmake_minimum_required(VERSION 3.11) 
# Projemizin minimum sürümünü ayarlıyoruz. 3.11 sürümünden sonraki sürümler kararlı sürümledir

project(hesapMakinesi)
# Projemizin ismini yazdık

set(CMAKE_CXX_STANDARD 23)
# Set komutu bir çok ayarı ayarlamamızı sağlayan bir komuttur. Bu komutta C++ standartlarından C++23 kullanmayı tercih ettim

add_executable(main) 
# Bu kısımda çalıştırabilir dosya ekledim. İsmi "main" olsun

target_sources(main PRIVATE main.cpp mat.hpp mat.cpp)
# Target_sources, eklediğimiz "main" adlı çalıştırılabilir dosyanın kaynak kod dosyalarını ayarlamamızı sağlar. PRIVATE'ın sağındaki dosya isimleri "main" uygulamasına katılıcak olan kaynak kodları temsil eder. Dolayısıyla "source" klasörümüze bu kaynak dosyalarını oluşturalım

CMakeLists.txt dosyamızı oluşturduk. Ardından bu CMakeLists.txt ile CMake'e tanıtmamız lazım. Bunun için bir üst dizine çıkıp "build" klasörüne girelim. Ardından CMake'e bu CMakeLists.txt dosyamızı tanıtalım;

Windows;

cmake -G "MinGW Makefiles" ../build

Linux;

cmake -G "Unix Makefiles" ../build

Ayarlama işleminden sonra artık projemizi derleme otomasyonuyla derliyelibiliriz.

Son olarak CMake'e tanıtırken "-G-" ile tanımlanan "MinGW Makefiles" veya "Unix Makefiles" parametresi dikkatinizi çekmiş olabilir. Bu parametre CMake'deki Generater veya üretici ayarlamamızı sağlar. CMake'te üretici; Derleme otomasyonunda kullanılan derliyicidir. Biz tüm dökümantasyon boyunca GNU G++ kullandığımız için, Windows'daki G++ derliyicisi CMake'de "MinGW Makefiles", Linux'da G++ derliyicisi ise "Unix Makefiles" olarak geçmektedir. Bu sebeble böyle bir ayarlama söz konusu olmuştur. Dilerseniz diğer oluşturucuları gözlemlemek için şu komutu çalıştırabilirsiniz;

cmake -G

Proje İçeriği

Proje içeriğimiz aşağıdaki kodlarla dolduralım;
main.cpp

#include <iostream>

#include "mat.hpp"

using namespace std;

int main()
{
    cout << "4 + 3 = " << topla(4,3) << endl;
    cout << "1 - 5 = " << cikar(1,5) << endl;
    cout << "6 * 5 = " << carp(6,5) << endl;
    cout << "8 / 2 = " << bol(8,2) << endl;

    return 0;
}

mat.hpp

#ifndef _MAT_H_P_P_
#define _MAT_H_P_P_
 
int topla(int x,int y);
int cikar(int x,int y);
int carp(int x,int y);
int bol(int x,int y);

#endif

mat.cpp

int topla(int x,int y)
{
    return x + y;
}
int cikar(int x,int y)
{
    return x - y;
}
int carp(int x,int y)
{
    return x * y;
}
int bol(int x,int y)
{
    return x / y;
}

Projemizin içeriği bu şekildedir.

Tüm kodlar hazır. Şimdi "build" klasöründe projemizi derlemek için şu komutu çalıştıralim;

cmake --build .

Ardından

main

Çıktısı;

Kütüphane Oluşturma

Kütüphane oluşturmak için CMakeLists.txt dosyamızın içeriğini bu komutlarla değiştirelim;
cmake_minimum_required(VERSION 3.11) 

project(hesapMakinesi)

set(CMAKE_CXX_STANDARD 23)

include_directories(.)
# Başlık dosyalarının dizini

add_library(mat SHARED mat.cpp)
# Kütüphanemizi oluşturduk. İsmi "mat" olsun. SHARED ifadesi bu kütüphanenin bir dinamik Native dosya olucağını belirtir fakt standartlar gereği statik Native dosyasıda yanında oluşturulur

# Projemizden main.cpp dosyasını silelim ki artık ihtiyacımız yok

Ardından ayarlama komutunu girelim ki kütüphanemiz olsun;

Windows;

cmake -G "MinGW Makefiles" ../build

Linux;

cmake -G "Unix Makefiles" ../build

Ardından

cmake --build .

Kütüphanemiz oluşturulmuştur!

Dış Kütüphane Bağlama

CMake'de dış kütüphane bağlamak için CMakeLists.txt dosyamızın içeriğini şu şekilde değiştirelim;
cmake_minimum_required(VERSION 3.11) 

project(hesapMakinesi)

set(CMAKE_CXX_STANDARD 23)

link_directories(${PROJECT_SOURCE_DIR})
# Projemizi "source" klasöründe ara

add_executable(main)

target_link_libraries(main PRIVATE libmat.dll)
# Main'e libmat.dll kütüphanesini bağladık

# Son olarak mat.hpp ve mat.cpp dosyalarını silelim. Çünkü onlar şuan libmat.dll dosyalarında
# Ayrıca libmat.dll dosyamızı hem source hemde build klasörüne kopyalayalım

target_sources(main PRIVATE main.cpp)

Ardından main.cpp dosyamız;

#include <iostream>

using namespace std;

int topla(int x,int y);
int cikar(int x,int y);
int carp(int x,int y);
int bol(int x,int y);

int main()
{
    cout << "4 + 3 = " << topla(4,3) << endl;
    cout << "1 - 5 = " << cikar(1,5) << endl;
    cout << "6 * 5 = " << carp(6,5) << endl;
    cout << "8 / 2 = " << bol(8,2) << endl;

    return 0;
}

Paket Bağlama

Paket bağlama, CMake'de nlohmann Json kütüphanesi gibi büyük çaplı kütüphaneleri bağlamamızı sağlayan bir komuttur.
Şimdi ise Json konusundaki kodları CMake ile yeniden derliyelim;

CMakeLists.txt

cmake_minimum_required(VERSION 3.11) 

project(hesapMakinesi)

set(CMAKE_CXX_STANDARD 23)

add_executable(main)

find_package(nlohmann_json 3.12.0 REQUIRED)
# nlohmann_json kütüphanesini buldurduk

target_link_libraries(main PRIVATE nlohmann_json::nlohmann_json)
# Bağlıyoruz

target_sources(main PRIVATE main.cpp)

main.cpp;

#include <iostream>
#include <fstream>
#include <nlohmann/json.hpp>

using namespace std;

int main()
{
    nlohmann::json verilerim; 

    verilerim["Isim"] = "Data";
    verilerim["Soyisim"] = "Delete";
    verilerim["Yasim"] = 15;
    verilerim["En sevdigim sayi"] = 3.14f;
    verilerim["Adresim"]["Turkiye"] = "Izmir";
    verilerim["Becerilerim"] = {"C", "C++", "Java"};

    string verilerimStr = verilerim.dump();

    std::ofstream bilgilerimDotJson("bilgilerim.json");

    bilgilerimDotJson << verilerimStr;

    bilgilerimDotJson.close();

    ifstream bilgilerimDotJsonOkuma("bilgilerim.json");

    nlohmann::json bilgilerimiOkuma = nlohmann::json::parse(bilgilerimDotJsonOkuma);

    bilgilerimDotJsonOkuma.close();

    cout << "Bilgilerim;" << endl;
    cout << "Isim: " << verilerim["Isim"] << endl;
    cout << "Soyisim: " << verilerim["Soyisim"] << endl;
    cout << "Yasim: " << verilerim["Yasim"] << endl;
    cout << "En sevdigim sayi: " << verilerim["En sevdigim sayi"] << endl;
    cout << "Ev Adresim: " << verilerim["Adresim"]["Turkiye"] << endl;
    cout << "Becerilerim: " << verilerim["Becerilerim"] << endl;

    return 0;
}
