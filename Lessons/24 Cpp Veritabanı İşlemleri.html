Veritabanı İşlemleri

Veritabanı Nedir?

Veritabanı, internette veya kendi bilgisayarımızda bilgileri belirli bir formatta tutarak, belirli bir sözdizimi ile de o verileri bizlere geri veren bir yapıdır. Bir çok veritabanı olasada biz bu sayfada kendi bilgisayarımızda veritabanı oluşturup üstelik bunu bir dosya üzerinden yürüten Sqlite'ı kullanacağız.
Şimdi akıllar karıştırsa düzeltelim; Veritabanlarını bir binanın bir katı olarak düşünebilirsiniz. Her daire "tablo" dediğimiz yapıları ve o yapılarda veri tutcularımız olan insanlar tutulur. Yani bir nevi bir veriyi saklamanın bir başka yöntemlerinden biridir.
Peki neden veritabanı veya onun dili olan SQL? Çünkü evrensellik! Json veya Xml dosyaları sizlerin kendi projenizde kullanıcağız formatlardır. Sizler anlasanızda bir başkası kullandığınız veri saklama formatını bilmediği için ve her yiğidin yoğurt yiyişide farklı olduğu için anlamakta güçlük çekicektir. Bir başka sebeb ise internettir. İnternette verinlerin neredeyse tamamı veritabanlarında saklanır ve o veritabanlarıyla iletişim için SQL dili kullanılır. Yani SQL ve veritabanları bizler için internetdeki alanlarla iletişim dilimizdir. SQL ile veri alırız ve veririz.
Geldik SQLite'ın ne olduğuna... Başta konuştuğumuz gibi SQLite dosya tabanlı bizlere bir veritabanı hizmeti sunar. Diğer veritabanlarının aksine herhangi bir internet veya herhangi bir üyelik satın alıp size sunucu vermez. Kendi bilgisayarında ve kendi belirlediğiniz dosyalarda işlemlerinizi gerçekleştirirsiniz. Tabi internet üzerinden bir sunucu satın alıp bir veritabanı yapmak isterseniz, hangi veritabanına bağlı olarak kütüphane değişicektir. Ama biz bu sayfada SQLite'ı anlatıcağız...

SQLite Kurulumu

SQLite kütüphanesini kurmak için;

Windows; pacman -S mingw-w64-x86_64-sqlite3
Linux; sudo apt install libsqlite3-dev

Veritabanı Kurma

Teorikten çıktık gelidk şimdi pratiğe! Normal şartlarda SQL dilinde bir veritabanı create database veritabaniIsmi ile oluşturuldu fakat SQLite bizlere bunu bizlere ".db" dosyası oluşturarak sunar. Yani her .db dosyası bizim için bir veritabanıdır.
Şimdi biraz klasik gelicek ama bir müşteri kayıt sistemi yapabiliriz... İlk olarak bir veritabanı oluşturalım. Veritabanımın adı ise "musteriler" olsun.

#include <iostream>
#include <sqlite3.h> // SQLite kütüphanemiz. Bir C kütüphanesidir

using namespace std;

int main()
{
    sqlite3 *musterilerDb; // Veritabanımızın nesnesi
    int acildiMi = sqlite3_open("musteriler.db", &musterilerDb); // Veritabını açıyoruz. Yoksa da açıyoruz
    // int acildiMi = ; Fonksiyon eğer başarılı olursa 1 döner, başarılı olursa 0 döner
    // "musteriler.db"; Dosya ismi
    // &musterilerDb; Veritabanı nesnesi

    if (acildiMi) // Eğer başarısız olursa
    {
        cout << "musteriler.db acilamadi" << endl;
    }
    
    sqlite3_close(musterilerDb); // Veritabanını kapatır
    
    return 0;
}

g++ main.cpp -o main -lsqlite3

Tablo Oluşturma

Analojimizden gidicek olursak demiştik ki katlardaki daireler bizim tablomuzdur. Hadi gelin tablo oluşturalım! Analoji bir yana tablolar bizler için verileri tutan depolar gibidir. Yani bir veritabanında veri tutucak ise tablo içerisinde olması zorunludur. Bu tablolarıda Excel'deki tablolara benzetebiliriz. Yanı sütünlar ve satırlar mantığına sahiptirlerdir.
SQL dilinde bir tablo oluşturmak için;

create table tabloIsmi(sutunIsmi sutunTuru, ...)

Gelin şimdi müşteriler için bir tablo oluşturalım;

#include <iostream>
#include <sqlite3.h>

using namespace std;

int main()
{
    sqlite3 *musterilerDb;
    int acildiMi = sqlite3_open("musteriler.db", &musterilerDb);
    if (acildiMi)
    {
        cout << "musteriler.db acilamadi" << endl;
    }
    
    acildiMi = sqlite3_exec(musterilerDb, "create table musteriler_tbl(id int, isim varchar(128), soyad text, musterikTarigi date)", 0, 0, 0); // Veritabanımıza SQL göndermemizi sağlar
    // acildiMi = ; Eğer fonksiyon başarısız 0 döner, başarılı olursa 0'dan farklı bir değer döner
    // musterilerDb; Etki ediceğimiz veritabanı nesnesi
    // "create table musteriler_tbl(id int, isim varchar(128), soyad text, musterikTarigi date)"; Gönderilecek SQL
    // 0; Geri dönen veriler için bir Callback kısmı, 0 ise es geçilir
    // 0; Birinci çıktı için Callback kısmı
    // 0; Eğer bir hata çıkarsa yazdırılacak bir bellek alanı. Çoğu durumda bizlere Segmentation Fault yedirdiği için kullanmıyoruz
    
    // Ayrıca SQL dilinde "varchar(256)" demek tıpkı C++ dili gibi "bana 256 karakterlik bir yazı alanı ver" demektir. Text ise uzunluğu değiştirilebilen bir yazı türüdür. Tıpkı String gibi

    if (acildiMi != 0) // Eğer başarısız olursa
    {
        cout << sqlite3_errmsg(musterilerDb) << endl; // sqlite3_errmsg ile hatayı görebiliriz
    }
    else // Başarılı ise
    {
        cout << "musteriler tablosu olusturuldu!" << endl;
    }

    sqlite3_close(musterilerDb);
    
    return 0;
}

Çıktısı ise;
Fark etti iseniz programı iki kere çalıştırdım. Bunun sebebi aynı tablo varsa bir veritabanında hata çıkarma olayını gösterme niyetimdir.

Veri Sorgulama

Veri sorgulamak aslında SQL dilinde bir nevi verileri ekrana basmak gibidir. Bir tablodaki tüm verileri çıkarmak için SQL'de bu komut kullanılır;

select getirilecekOlanSutunlarKiGeneldeYildizIsaretiIleTumSutunlarGetirtilir from tabloIsmi

Ayrıca C++ programlama dilinde verileri elde etmek için Callback sistemi kullanılır. Her satır için sırayla sütünları ve sütünlarındaki verilerle Callback fonksiyonuna verilir.

Hadi tablodan verilerimizi çekelim;

#include <iostream>
#include <sqlite3.h>

bool ilkSeferMi = true; // Bir tablo görüntüsü vermek için bir kontrol ekliyorum

{
    if (ilkSeferMi) // İlk sefer ise
    {
        ilkSeferMi = false; // İLk seferi kapat

        for (int i = 0; i < sutunSayisi; i++) // Gelen veri kadar dön
        {
            cout << sutunIsimleri[i] << "    "; // Sütün isimlerini yazdır
        }

        cout << endl << endl; // Daha sonra iki satır koy
    }
    
    for (int i = 0; i < sutunSayisi; i++) // Gelen veri kadar dön
    {
        cout << sutunVerileri[i] << "    ";
    }
    
    cout << endl; // Sonunda bir satır koy

    return 0; // Diğer veriye geç
}

Veri Güncelleme

Veri güncellemek için SQL komutu olarak;

update tabloIsmi set sutunIsmi='olmasiIstenen'

Fakat bu komut SQL'de "Şu tablodaki 'sutunIsmi'ndeki bütün verileri 'olmasiIstenen' yap" demektir ki biz bu durumu pek istemeyiz. Bu sebeble SQL'de "Koşul" ifade olarak kullandığımız where ile bütün verilerin yerine koşulda yazan veriyi değiştirme imkanı bizlere sunar;

update tabloIsmi set sutunIsmi='olmasiIstenen' where sutunIsmi='suAnKiVeriDegeri'

Güvenli Sorgu Yazma

Şimdi biz bu sorguları yazıyoruz ama kendimiz yazıyoruz. Yani eklediğimiz veriler bizim eklediğimiz veriler. Peki ya kullanıcı? Kullanıcılardan gelen verileri direkt olarak String birleştirme gibi bir sorgu yaparsak; zamanında Google, Yahoo veya Yandex gibi arama motoru devlerinin başına geldiği gibi SQL Injection saldırısına maruz kalabilrisiniz. Evet biz SQL biliyoruz ama kullanıcı bilmiyor olabilir. Ama kötü niyetli kullanıcılar kesinlikle SQL bilirler.
Peki ne demeyi mi çalışıyorum? SQL dilinde her dilde olduğu gibi yorum satırı operatörü(--) bulunur. Bu operatör kullanılan SQL komutlarını açıklamak içindir. Ama kötü niyetli kullanıcılar için en önemli veritabanını silme komutunu çalıştırma aracı "drop database primaryDatabase --" aracıdır. Bu komut der ki; "'primaryDatabase' adlı veritabanını sil ve geri kalan satırı yorum yap" der. Böylelikle tüm önemli verileri silinip toz olur gider...
İşte bu durumu önlemek için "Prepared Statements" adlı bir önden tanımlama sistemi kullanılır. Bu sistem kötü niyetli kullanıcının girdiği zararlı sorguyu sanki sadece bir yazı verisiymiş gibi tanıtır ve çalışabilme geçerliğini yitirir. Böylelikle veriler korunmuş olur.
Gelin beraber kullanıcının girdiği değerlerle tabloya veri ekleyen ve bunu güvenli bir şekilde yapan bir sistem geliştirelim;

#include <iostream>
#include <sqlite3.h>

using namespace std;

bool ilkSeferMi = true;

int tumMusterilerYazdir(void* bosVeri, int sutunSayisi, char** sutunVerileri, char** sutunIsimleri)
{
    if (ilkSeferMi)
    {
        ilkSeferMi = false;

        for (int i = 0; i < sutunSayisi; i++)
        {
            cout << sutunIsimleri[i] << "    ";
        }

        cout << endl << endl;
    }
    
    for (int i = 0; i < sutunSayisi; i++)
    {
        cout << sutunVerileri[i] << "    ";
    }
    
    cout << endl;

    return 0;
}

int main()
{
    sqlite3 *musterilerDb;
    int hataKontrol = sqlite3_open("musteriler.db", &musterilerDb);
    if (hataKontrol)
    {
        cout << "musteriler.db acilamadi" << endl;
    }
    
    hataKontrol = sqlite3_exec(musterilerDb, "create table musteriler_tbl(id int, isim varchar(128), soyad text, musteriOlmaTarigi text)", 0, 0, 0);
    if (hataKontrol != 0)
    {
        cout << sqlite3_errmsg(musterilerDb) << endl;
    }
    else
    {
        cout << "musteriler tablosu olusturuldu!" << endl;
    }

    cout << endl << "musteriler tablosundaki Id sutununa veri ekleyin: ";
    string yeniMusteriId;
    getline(cin, yeniMusteriId); // Getline ile kullanıcının girdiği bütün girdiği verirs

    cout << endl << "musteriler tablosundaki Isim sutununa veri ekleyin: ";
    string yeniMusteriIsmi;
    getline(cin, yeniMusteriIsmi);

    cout << endl << "musteriler tablosundaki Soyad sutununa veri ekleyin: ";
    string yeniMusteriSoyad;
    getline(cin, yeniMusteriSoyad);

    cout << endl << "musteriler tablosundaki musteriOlmaTarigi sutununa veri ekleyin(format; Yil-Ay-Gun): ";
    string yeniMusteriTarigi;
    getline(cin, yeniMusteriTarigi);

    // Veriler aldık şimdi güvenli sorgu yapımızda

    sqlite3_stmt *guvenliSorguNesnesi; // Güvenli sorgu nesnemiz, güvenli veri doldurma işlemlerimiz bu nesne üzerinden yapıcağız
    char sqlSorgusu[] = "insert into musteriler_tbl(id, isim, soyad, musteriOlmaTarigi) values(?, ?, ?, ?)"; // Sorgumuzu tanımladık. Soru işaretleri(?) yerine bizim güvenli veri yerleştirmede kullanıcağımız fonksiyonlar ile verileri doldurucağız

    sqlite3_prepare_v2(musterilerDb, sqlSorgusu, -1, &guvenliSorguNesnesi, nullptr);// Güvenli sorgu nesnesini başlatır
    // musterilerDb; Veritabanımız
    // sqlSorgusu.c_str(); String şeklinde sorgumuz
    // -1; Sorgu ne kadar olucak. -1 değeri otomatik olarak ayarlanacak demektir
    // &guvenliSorguNesnesi; Güvenli değişkenimiz
    // 0; Hata mesajları. Şimdilik es geçtim
    
    sqlite3_bind_int(guvenliSorguNesnesi, 1, (int)(yeniMusteriId.c_str()[0] - 48)); // Güvenli sorgu nesnemize Integer değerini güvenli bir şekilde ekler
    // (int)(yeniMusteriId.c_str()[0] - 48); Güvenli sorgu nesnemiz
    // 1; Kaçıncı soru işaretine ekleneceği
    // yeniMusteriId; Eklenicek veri

    sqlite3_bind_text(guvenliSorguNesnesi, 2, yeniMusteriIsmi.c_str(), yeniMusteriIsmi.length() + 1, 0); // String verisini güvenli bir şekilde ekler
    // guvenliSorguNesnesi; Güvenli sorgu nesnemiz
    // 2; Kaçıncı soru işaretine ekleneceği
    // yeniMusteriIsmi.c_str(); Eklenicek veri
    // yeniMusteriIsmi.length() + 1; eklenicek olan verinin uzunluğu
    // 0; Boş veri

    sqlite3_bind_text(guvenliSorguNesnesi, 3, yeniMusteriSoyad.c_str(), yeniMusteriSoyad.length() + 1, 0);

    sqlite3_bind_text(guvenliSorguNesnesi, 4, yeniMusteriTarigi.c_str(), yeniMusteriTarigi.length() + 1, 0); // Tarih türüde String şeklinde eklenir

    char* guvenliSql = sqlite3_expanded_sql(guvenliSorguNesnesi); // Güvenli SQL nesnesini verileriyle birlikte SQL sorgusu olarak verir

    hataKontrol = sqlite3_exec(musterilerDb, sqlite3_expanded_sql(guvenliSorguNesnesi), 0,0,0);
    if (hataKontrol != 0)
    {
        cout << sqlite3_errmsg(musterilerDb) << endl;
    }
    else
    {
        cout << "musteriler tablosuna veriler eklendi!" << endl;
    }

    ilkSeferMi = true;

    hataKontrol = sqlite3_exec(musterilerDb, "select * from musteriler_tbl", tumMusterilerYazdir,0,0);
    if (hataKontrol != 0)
    {
        cout << sqlite3_errmsg(musterilerDb) << endl;
    }
    else
    {
        cout << endl << "musteriler yazdirildi!" << endl;
    }


    sqlite3_close(musterilerDb);
    
    return 0;
}
