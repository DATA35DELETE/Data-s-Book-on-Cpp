Signal ve Slot

Signal ve Slot Nedir?

Signal ve Slot Türkçe isimleriyle sinyal ve yuva, objeler arasında fonksiyonları birbirlerine bağlamak için kullanılan bir sistemdir.
Mantık ise çok basittir. Bir sinyal bir veya birden fazla yuvaya bağlı olarak kullanım sağlar. Yani aslında sinyal fonksiyonun çağırdığımızda yuva fonksiyonunu çağırmış oluruz. Bu genelde "Tıklama" veya "Fare üzerinde" gibi durumlarda kullanılan bir sistemdir.
Sizlere bir yerlerden bu sistem tanıdık gelebilir... Evet, Callback yapısı! Aslında tam olarak Callback olmasada arkada Callback yapısı kullanılır. Peki neden Qt'de sinyal ve yuva kullanılır. Cevap C++'ın Callback yapısının dayanaksızlığıdır. Düz Callback sisteminde direkt olarak fonksiyonun işaretçisi verildiğinden ve işaretçilerde bazen bizim istediğimiz gibi çalışamadıkları için çoğu durumda hataya yol açarlar, hatta programların çökmelerine kadar sorun yaratabilirler. İşte bu duruma çözüm olarak Qt sinyal ve yuva sistemini getirtmiştir. Sinyal ve yuva mekanizması bu duruma çağre olarak üst kontrol sistemini kullanılır. Üst sisteminin amacı ise "Doğru işaretçi çağrıld mı?" kontrollü yapmaktır. Böylelikle kararlılık kazanılmıştır.

Sinyal ve Yuva Tanımlama

Şimdi gelin penceremize bir buton koyalım ve onun "Tıklama" fonksiyonunu yani sinyalini bizim kendi tanımlandığımız "butonTiklamaHaberiniVer" fonksiyonuna yani yuvasına bağlıyalıp, çalıştıralım ve butona basarak neler olduğunu gözlemleyelim.
İlk olarak butonumuzu koyalım. Projemizin mainwindow.ui dosyasına gidelim ve bir PushButton'nu sürükliyerek pencere alanımıza bırakalım.
Ardından mainwindow.h dosyamıza gelelim ve yuvamızı tanımlayalım;
#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots: // Yuvamızı tanımlıyoruz. PushButton'nun "clicked" sinyalini bu yuvaya bağlıcağız
    void butonTiklamaHaberiniVer();

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H

Ardından mainwindow.cpp dosyamıza gidelim;

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    MainWindow::connect(ui->pushButton, SIGNAL(clicked()), this , SLOT(butonTiklamaHaberiniVer())); // Sinyal fonksiyonları yuva fonksiyonlarına bağlamamızı sağlar
    // ui->pushButton; Sinyalin bulunduğu sınıf. Bir önceki sayfada anlatılan Meta-Object sistemi sayesinde herhangi bir engel olmadan direkt ekrandaki Item'lerimize erişebiliyoruz
    // SIGNAL(clicked()); SIGNAL makrosu ile sinyal fonksiyonu hazırlanır. Bu durumda pushButton sınıfındaki "clicked" fonksiyonu sinyal durumdadır
    // this; Yuvanın bulunduğu sınıftır. this işaretçisi ile bu sınıfta olduğunu belirttik
    // SLOT(butonTiklamaHaberiniVer()); SLOT makrosu ile yuva fonksiyonunu hazırlar. Bu durumda bizim "butonTiklamaHaberiniVer" fonksiyonumuz oluyor
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::butonTiklamaHaberiniVer() // Tanımladığımız yuvamızın işlevini dolduruyoruz
{
    qDebug() << "pushButton'a basıldı!" << Qt::endl;
    // Qt'de standart Cout kullanılmaz. Bunun yenine qDebug kullanılır. Fakat aralarında hiçbir fark yoktur
    // Qt::endl; Qt'deki std::endl'dır
}

Kodlar hazır. Şimdi çalıştıralım;

Yeni Yazım Şekliyle Sinyal ve Yuva Tanımlama

Bu yazım şekli eski Qt sürümlerinden kalmadır. Bu yazım şeklinde String tabanlı olduğu için bellek israfı yaptıkları için yeni sürümde işaretçi tabanlı bir sinyal-yuva sistemi kullanılır. Gelin beraber uygulayalım;

mainwindow.cpp

#include "mainwindow.h"
#include "./ui_mainwindow.h"

#include <QPushButton> // Sinyal fonksiyonunun kullanılcağı kütüphane. Biz QPushButton kullandığımız için onu dahil ettik

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    connect(ui->pushButton, &QPushButton::clicked, this , &MainWindow::butonTiklamaHaberiniVer); // Yeni yazım şekli ile connect
    // ui->pushButton; Sinyalin bulunduğu sınıf. Bir önceki sayfada anlatılan Meta-Object sistemi sayesinde herhangi bir engel olmadan direkt ekrandaki Item'lerimize erişebiliyoruz
    // &QPushButton::clicked; Sinyalin bulunduğu sınıfın kendisine özel tanımlanmış isim alanındaki sinyal fonksiyonunun işaretçisi
    // this; Yuvanın bulunduğu sınıftır. this işaretçisi ile bu sınıfta olduğunu belirttik
    // &MainWindow::butonTiklamaHaberiniVer; Yuvanın bulunduğu sınıfın kendisine özel tanımlanmış isim alanındaki yuva fonksiyonunun işaretçisi
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::butonTiklamaHaberiniVer()
{
    qDebug() << "pushButton'a basıldı!" << Qt::endl;
}

Çıktı değişmicektir fakat artık belleğimizi tasaruflu bir şekilde kullanıyor olduk.

Lambda Tanımlama

Yeni yazım şekli ile gelen özelliklerden biriside yuvaları Lambda fonksiyon olarak tanımlayabiliriz.

Hadi deniyelim;

İlk olarak mainwindow.h dosyasını eski haline döndürelim;

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


Ardından yuvamızı lambda olarak tanımlayalım;

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    connect(ui->pushButton, &QPushButton::clicked, this ,
    [] () // Lambda fonksiyonumuz
    {
        qDebug() << "QPushButton'a lambda tanımlanan bir yuvaya gönderilen bir sinyal geldi!" << Qt::endl;
    });
}

MainWindow::~MainWindow()
{
    delete ui;
}

Çıktı ise;

Sinyalin Yuva Bağlantısını Koparma

Bu işlem için disconnect metodu kullanılır.
Bu işlem genelde; İşlevini kaybetmiş veya sadece bir kere tıklanabilir nesneler için kullanılır. Bir kere bağlandıktan sonra bir kere bağlantısı kopartabilir.
Şimdi gelin bir örnek yapalım. Butonumuz dursun, o butona sadece bir kere tıklanabilirlik uygulayalım. Bunun için yeni yazım şeklie ile sinyalli yuvaya bağlayıp ardından bağlantıyı kopartıcağız;

mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots:
    void butonaTekBirKereBasma(); // Yuvamız

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    connect(ui->pushButton, &QPushButton::clicked, this , &MainWindow::butonaTekBirKereBasma); // Bağlıyoruz
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::butonaTekBirKereBasma()
{
    qDebug() << "Butona basildi! Bir daha basilmicaktir!" << Qt::endl;

    disconnect(ui->pushButton, &QPushButton::clicked, this , &MainWindow::butonaTekBirKereBasma); // Aynı şekilde bağlantıyı kopartıyoruz
}

Çıtkı;

Sinyal-Yuva Bağlantı Türleri

Belirtmedik ama connect komutunun beşinci parametresi bizden bir bağlantı türü istemektedir. Varsayılan parametre ile o parametre AutoConnection türü olarak işlenmektedir. Aşağıdaki bağlantı türleri tablo olarak verilmiştir.
İsmi Açıklaması Kullanımı
AutoConnection Kullanımı en uygun olan bağlantı türüdür. Sinyal ve yuva aynı iş parçacağındaysa DirectConnection, değilse QueuedConnection olarak davranır. Qt::AutoConnection
DirectConnection Sinyal ve yuva aynı iş parçacağındaysa kullanılır. Bu bağlantı türü Callback'e biraz daha benzemektedir. Çünkü direkt olarak çağırma işlemini gerçekleştiririr. Qt::DirectConnection
QueuedConnection Sinyal ve yuva farklı iş parçacıklarında ise bu bağlantı türü kullanılır. Gelen sinyal isteklerini bir kuyruk listesine koyar ve sırayla işler. Çünkü iş parçacıkları arasında zaman uyumsuzlukları oluşmaması içindir. Qt::QueuedConnection
