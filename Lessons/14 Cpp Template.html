Template

Template Nedir?

Temlate; fonksiyonlarda, değişkenlerde ve sınıflarda tür bağımsız yapılar kurabilmemizi sağlayan bir araçtır.
Amacı ise kendi küçüktür büyüktür parantezlerinde yer alan parametrelerinde gerek veri türü ismi gerek veri değeri girilerek tür bağımsız bir şekile programlama yapabilmemizi sağlayan özel bir araçtır.

Fonksiyonlarda Template

Daha önceden bir örneğini vermiştik "Fonksiyonlar" sayfasında;

#include <iostream>

using namespace std;

// Şablon ile fonksiyon bu şekilde tanımlanır
template<typename girilenTur> girilenTur topla(girilenTur a, girilenTur b) // Şablonların içerisine yazılan veri türünün aynı bir değişken gibi "girilenTur" adlı bir tür değişkenine atadık. Ardından tür bağımsız olucak olan kısımlara uygun olacak şekilde yerleştirdik
{
    return a + b;
}

int main()
{
    cout << "2 + 3 = " << topla<int>(2,3) << endl << endl; // Integer türü ile çağırdık

    cout << "2.43 + 3.321 = " << topla<double>(2.43,3.321) << endl; // Double türü ile çağırdık

    return 0;
}

Sınıflarda Template

Sınflarda Template kullanımı aynı fonksiyonlarda Template kullanımı gibidir.

Gelin mevcut örneğimizi geliştirelim;

#include <iostream>

using namespace std;

template<typename girilenTur> class hesapMakinesi // Nesnesi oluşturulken hangi veir türü ile işlem yapılcağı önceden Template ile belirlenir. Daha sonraki işlemlerde girilen veri türünde devam edelir
{
    public:
        girilenTur topla(girilenTur x, girilenTur y)
        {
            return x + y;
        }
        girilenTur cikar(girilenTur x, girilenTur y)
        {
            return x - y;
        }
        girilenTur carp(girilenTur x, girilenTur y)
        {
            return x * y;
        }
        girilenTur bol(girilenTur x, girilenTur y)
        {
            return x / y;
        }
};

int main()
{
    hesapMakinesi<int> integerIslemleri; // Integer işlemleri için nesnemiz

    cout << "2 + 2 = " << integerIslemleri.topla(2,2) << endl;
    cout << "10 - 4 = " << integerIslemleri.cikar(10,4) << endl;
    cout << "5 * 6 = " << integerIslemleri.carp(5,6) << endl;
    cout << "100 / 5 = " << integerIslemleri.bol(100,5) << endl << endl;

    hesapMakinesi<double> doubleIslemleri; // Double işlemleri için nesnemiz

    cout << "2.4 + 2.3 = " << doubleIslemleri.topla(2.4,2.3) << endl;
    cout << "10.2 - 4.5 = " << doubleIslemleri.cikar(10.2,4.5) << endl;
    cout << "5.2 * 6.4 = " << doubleIslemleri.carp(5.2,6.3) << endl;
    cout << "100.8 / 5.2 = " << doubleIslemleri.bol(100.8,5.2) << endl << endl;

    return 0;
}

Çıktısı;

Değişkenlerde Template

Değişkenlerde tıpkı fonksiyonlar ve sınıflarda oluduğu gibi kullanım aynıdır. Ayrıca C++14 standartı ile dile girmiştir.

Basit bir örnek yazalım;

#include <iostream>

using namespace std;

template<typename girilenTur> girilenTur degisken = 123.543; // Bu şekilde tanımlanır

int main()
{
    cout << "123.543 saysinin Integer hali: " << degisken<int> << endl; // Template ile Integer halini aldık
    cout << "123.543 saysinin Double hali: " << degisken<double> << endl; // Template ile Double halini aldık

    return 0;
}

Çıktısı;

Varsayalın Tür Atama

OOP'nin özelliği olan varsayalın atama Template'de de vardır.

Bir önceki örneği bu özellik ile yeniden düzenleyelim:

#include <iostream>

using namespace std;

template<typename girilenTur = double> girilenTur degisken = 123.543;

int main()
{
    cout << "123.543 saysinin Integer hali: " << degisken<int> << endl;
    cout << "123.543 saysinin Double hali: " << degisken<> << endl; // Template ile varsayılan halini aldık

    return 0;
}

Çıktı değişmicektir lakin yöntem değişiklik göstericektir.

Template Üzerinden Değer Aktarma

Dilersek Template'ler üzerinden değer aktarabiliriz.

Hadi bir dönüştürücü örneği yapalım;

#include <iostream>

using namespace std;

template<typename girilenTur, typename degerTur, degerTur deger> girilenTur donustur()
{
    return (girilenTur)deger;
}

int main()
{
    cout << "32.53 sayisinin Integer hali; " << donustur<int, double, 32.53>() << endl;

    return 0;
}
