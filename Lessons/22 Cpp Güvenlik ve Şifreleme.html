Buffer Overflow Koruması

Bir önceki sayfalardan bildiğimiz üzere Buffer Overflow, bellek alanlarının işgali sonucu oluşan bir hatadır. Bazı durumlarda diğer programların işliyişini baltalayabilirken, bazı durumlarda direkt olarak işletim sistemini bozabilmeye kadar uzanan geniş çaplı ve sonucu belirsiz olan bir çok zararı olur. Bu sebeble Buffer Overflow özellikle güvenlikte sıklıkla göz önünde bulundurulur.
Buffer Overflow hatasını belkide en çok çıkartan işlemlerden biriside Char dizisi işlemleridir. C++'daki String sınıfı her ne kadar işimizi görsede düşük seviyeli ve C üzerinde kurulmuş sistemlerde Char dizisi kullanmalıyız. Aksi takdirse sistem bizi anlıyamaz. Şimdi gelin hata yönetimiyle beraber bir Char dizisi atama kontrol yapalım!

#include <iostream>
#include <string.h>

using namespace std;

#define SORUNSUZ_ISLEM 0 // Sorunsuz işlem makromuz
#define BUFFER_OVERFLOW 1 // İşlemde Buffer Overflow yaşandığına dair makro

// Kontrol fonksiyonumuz
int charDizisiEkleme(char* hedef, int hedefUzunluk, char* kaynak)
{
    if (strlen(hedef) + strlen(kaynak) > hedefUzunluk) // Toplamları hedef uzunluğu geçiyorsa 
        return BUFFER_OVERFLOW; // Buffer Overflow riski
    
    strcat(hedef, kaynak); // Char dizilerini birleştirdik

    return SORUNSUZ_ISLEM; // Ardındından sorunsuz olduğuyla ilgili bir değer döndürdük
}

int main()
{
    char hedef1[100] = "Selam sana C"; // 1. Hedef
    char kaynak1[] = "++!"; // 1. Kaynak
//              |-> 4

    int islemSonucu = charDizisiEkleme(hedef1, 100, kaynak1);

    if (islemSonucu == SORUNSUZ_ISLEM) // İşlem sorunsuz ise
    {
        cout << "Islem sorunsuz gecti!" << endl << "Cikti; " << hedef1 << endl << endl;
    }
    else if (islemSonucu == BUFFER_OVERFLOW) // Buffer Overflow yaşandı ise
    {
        cout << "BUFFER OVERFLOW YASANDI!" << endl << "\"" << hedef1 << "\" <-x- \"" << kaynak1 << "\"" << endl << endl;
    }
    
    // Buffer Overflow'lu işlem

    char hedef2[30] = "C++, C'nin gelismisidir."; // 2. Hedef
    char kaynak2[] = " Bu sebeble ++ eki almistir.";

    islemSonucu = charDizisiEkleme(hedef2, 30, kaynak2);

    if (islemSonucu == SORUNSUZ_ISLEM) // İşlem sorunsuz ise
    {
        cout << "Islem sorunsuz gecti!" << endl << "Cikti; " << hedef2 << endl << endl;
    }
    else if (islemSonucu == BUFFER_OVERFLOW) // Buffer Overflow yaşandı ise
    {
        cout << "BUFFER OVERFLOW YASANDI!" << endl << "\"" << hedef2 << "\" <-x- \"" << kaynak2 << "\"" << endl << endl;
    }

}

Girdi Doğrulama(Input Validation)

Bu kavram bir tık daha soyut kavramdır. Girdi doğrulama, kullanıcının girmiş olduğu verilerin ana işleme katılıp katılmacağını doğrulayan, stilinden yazım şekline kadar pek çok niteliğini incelenen kodlardır. İki ana kolda incelenir. Syntactic ve Semantic'dir. Syntactic yazım şekilleri gibi yazı için somut kısımları inceleme yapılırken, Semantic ise girdinin anlamını yani soyut kısmını inceler. Örnek olarak telefon numarası verilebilir. Kullanıcı yanlış telefon numarasını girmediğini anlamak için ilk önce Syntactic ile yazının kurallara uyduğunu kontrol ederiz, ardından Semantic ile gerçek bir telefon numarasımı diye bir arama gerçekleştiririz.

OpenSSL

OpenSSL kütüphanesi, C++ ve C programlarının güçlü şifre bilimi(Cryptography) kütüphanesidir. SHA256'tan RSA şifreleme gibi geniş bir yelpazede fonksiyonlar sağlar.

Hashing Algoritmaları

Hashing algoritmaları, veriyi geri dönülemez şeklinde şifreleyen ve şifreninde bir eşinin yani benzersiz olarak bir sayı karşılığını alabildiğimiz algoritmalara denir. En çok kullanılan algoritmalarda SHA256 ve MD5'dir.

Şimdi bu iki algoritma ile bir program yazalım;

#include <iostream>
#include <openssl/sha.h> // SHA256 için
#include <openssl/md5.h> // MD5 için

using namespace std;

int main()
{
    string orjinalVeri = "Data Delete"; // Orjinal veri
    unsigned char sha256Verisi[SHA256_DIGEST_LENGTH]; // Hash verisini tutacak olan değişken

    SHA256_CTX sha; // SHA256 nesnemiz

    SHA256_Init(&sha); // SHA256 nesnemizi başlattık
    SHA256_Update(&sha, orjinalVeri.c_str(), orjinalVeri.length()); // Update ile nesnemize verimizi verdik. OpenSSL bellek yönetimi için güncelleme tabanlı bir Hashing sağlar

    SHA256_Final(sha256Verisi, &sha); // Final diyerek nesmizdeki verinin Hash'ini birinci parametredeki başlangıç işaretçisine kayıt eder

    cout << orjinalVeri << " -SHA256-> ";

    for (size_t i = 0; i < SHA256_DIGEST_LENGTH; i++) // SHA256 verisini bu şekilde yazdırıyoruz. Yoksa anlamsız karakterler görebiliriz
    {
        printf("%x", sha256Verisi[i]);
    }
    
    // Aynı şekilde MD5 içinde yapıyoruz

    unsigned char MD5Verisi[MD5_DIGEST_LENGTH];

    MD5_CTX mda;

    MD5_Init(&mda);
    MD5_Update(&mda, orjinalVeri.c_str(), orjinalVeri.length());

    MD5_Final(MD5Verisi, &mda);

    cout << endl << endl << orjinalVeri << " -MD5-> ";

    for (size_t i = 0; i < MD5_DIGEST_LENGTH; i++)
    {
        printf("%x", MD5Verisi[i]);
    }

}

Simetrik Şifreleme (AES)

Simetrik şifreleme, bir veriyi tek bir Key yani anahtar ile şifreleyip aynı anahatar ile şifreyi çözebilceğimiz bir şifrelemedir. Bu anahtara'a Public Key yani herkese açık anahatar denir.
Şimdi bir mesajlaşma örneği yapalım! Mantık basit, bir taraf Public Key'i oluşturucak ve mesaj içeriğini onunla şifreleyip, bir dosyaya mesajı bir dosyayada oluşturulan anahatarı yazıcak. Diğer tarafta o anahtarı alıp mesaj içeriğini çözüp ekrana bastırıcak.

İlk olarak şifreliyici;
sifreleyici.cpp

#include <iostream>
#include <fstream>
#include <openssl/aes.h> // Simetrik şifreleme için kütüphanemiz
#include <openssl/sha.h> // Şifremiz için SHA256 kütüphane. SHA256 ile şifreliyip çözüceğiz

using namespace std;

int main()
{
    string orjinalVerimiz = "Selam sana C++!";

    unsigned char hashVeri[SHA256_DIGEST_LENGTH];

    SHA256_CTX sha;

    SHA256_Init(&sha);
    SHA256_Update(&sha, orjinalVerimiz.c_str(), orjinalVerimiz.length());

    SHA256_Final(hashVeri, &sha);

    // Anahtarımız hazır. Şimdi veriyi anahtar ile şifreleyelim

    unsigned char sifreliVeri[orjinalVerimiz.length()]; // Aynı boyut ile şifrelenmiş verinin kayıt edilceği değişken

    AES_KEY sifreliyici; // Şifreliyicimiz

    AES_set_encrypt_key(hashVeri, 256, &sifreliyici); // Şifreliyici oluştur
    // hashVeri; Şifreliyicinin anahtarı
    // 256; Bit değeri
    // &sifreliyici; Şifreleyici nesnesi

    AES_encrypt((unsigned char*)orjinalVerimiz.c_str(), sifreliVeri, &sifreliyici); // Şifreleme işlemi
    // (unsigned char*)orjinalVerimiz.c_str(); Orjinal veri
    // sifreliVeri; Şifrelenmiş verinin kayıt edilceği başlangıç işaretçisi
    // &sifreliyici; Şifreleyici nesnesi

    ofstream sifreDotSifre("sifre.sifre");
    sifreDotSifre << sifreliVeri;
    sifreDotSifre.close();

    ofstream sifreDotKey("sifre.key");
    sifreDotKey << hashVeri;
    sifreDotKey.close();
}

#include <iostream>
#include <fstream>
#include <openssl/aes.h>

using namespace std;

int main()
{
    string sifreleriVeri;

    ifstream sifreDotSifre("sifre.sifre");
    getline(sifreDotSifre, sifreleriVeri);
    sifreDotSifre.close();

    string key;

    ifstream sifreDotKey("sifre.key");
    getline(sifreDotKey, key);
    sifreDotKey.close();

    // Veriler hazır. Şimdi şifreyi çözelim;

    AES_KEY cozucu; // Çözücü nesne

    AES_set_decrypt_key((unsigned char*)key.c_str(), 256, &cozucu); // Çözücü ayarlama
    // (unsigned char*)key.c_str(); Anahtar
    // 256; Bit değeri
    // &cozucu; Çözücü nesnein bellek adresi

    unsigned char cozulmusVeri[32]; // Çözülmüş verinin kayıt edilceği değişken

    AES_decrypt((unsigned char*)sifreleriVeri.c_str(), cozulmusVeri, &cozucu); // Çözmek
    // (unsigned char*)sifreleriVeri.c_str(); Şifreli verinin başlangıç işaretçisi
    // cozulmusVeri; Çözülmüş verinin kayıt edilceği başlangıç işaretçisi
    // &cozucu; Çözücü nesnesinin bellek adresi

    cout << cozulmusVeri << endl; // ekrana yazdırıyoruz

    return 0;
}

Asimetrik Şifreleme

Asimetrik şifreleme, simetrik şifrelemenin gelişmiş versiyonudur. Simetrikde bulunan anahtar, verileri hem şifreler hemde şifreyi çözer. Asimetrikde ise iki adet anahtar bulunur.
Public Key, bu anahtar asimetrik şifrelemelede verileri şifrelemek için kullanılır. Private Key ise Public Key ile şifrelenen veriyi çözmek için kullanılır.
Asimetrik şifreleme; Whatapps, Telegram, Signal ve Discord gibi mesajlaşma uygulamalarda endüstiri standartıdır. Çünkü bu uygulamalarda kullanılan bu şifreleme sistemi Dünya üzerindeki en güçlü şifreleme sistemidir. Gücü kendisinden ziyade bilgisayarların sınırlarından gelir. Düşün; Bu sistem ile şifrelenmiş bir veriyi elenizde Private Key olmadan çözmek isterseniz, en güçlü bilgisayarla bile asırlarca sürecek bir çözme işlemi gerçekleştirirsiniz. Yani siz çözene kadar veri çoktan önemini kaybetmiş olucaktır. Bu sebeble Hacker bu sistemi kırmaya tesebbüs bile etmezler. İşte bu yüzden asimetrik şifreleme endüstiri standartıdır.
Asimetrik şifreleme ile beraber kullanılan bir başka sistem ise uçtan uca şifreleme kısaca E2EE(End-to-End Encryption)'dir. E2EE ise iki kullanıcı arasında oluşturulan Private ve Public Key'leri, sadece Public Key'leri aralarında paylaşarak sadece kendi aralarında konuşmasını sağlayana basit bir yöntemdir. Kendisi basit ama kırması imkansız bir yöntem... Daha anlaşılır olması için bir görsel sunalım;

#include <iostream>
#include <fstream>
#include <filesystem>
#include <string.h> // Aşama kontrol için
#include <openssl/rsa.h> // RSA şifreleme için
#include <openssl/pem.h> // Anahtar oluşturmak için

using namespace std;

int main(int argc, char* argv[])
{
    if (!strcmp(argv[1], "asama1")) // 1. Aşama, Key'lerin oluşturulması
    {
        RSA* rsaAnahtarOlusturucu = RSA_new(); // Yeni bir RSA nesnesi oluşturduk. Aynı nesneden hem Public hemde Private Key oluşturucağız ki matematiksel olarak birbirlerinin şifreleyicisi-çözücüsü olsunlar

        RSA_generate_key_ex(rsaAnahtarOlusturucu, 2048, NULL, NULL); // RSA nesnesini başlatır
        // rsaAnahtarOlusturucu; RSA nesnesi
        // 2048; Bit derinliği. Ne kadar çok olursa o kadar Private Key uzun ve karmaşık olur

        FILE* taraf1PrivateDotPem = fopen("taraf1Private.pem", "w"); // taraf1 Private Key dosyası
        PEM_write_RSAPrivateKey(taraf1PrivateDotPem, rsaAnahtarOlusturucu, NULL, NULL, 0, NULL, NULL); // RSA nesnesinden Private Key oluşturur ve onu C dosya nesnesine yazdırır
        // taraf1PrivateDotPem; Yazdırılıcak olan C dosya nesnesi
        // rsaAnahtarOlusturucu; RSA nesnesi
        // NULL, NULL, 0, NULL, NULL; Boş parametreler
        fclose(taraf1PrivateDotPem);

        FILE* taraf1PublicDotPem = fopen("taraf1Public.pem", "w"); // taraf1 Public Key dosyası
        PEM_write_RSAPublicKey(taraf1PublicDotPem, rsaAnahtarOlusturucu); // RSA nesnesinden Public Key oluşturur ve onu C dosya nesnesine yazdırır
        // taraf1PublicDotPem; Yazdırılıcak olan C dosya nesnesi
        // rsaAnahtarOlusturucu; RSA nesnesi
        // NULL, NULL, 0, NULL, NULL; Boş parametreler
        fclose(taraf1PublicDotPem);

        RSA_free(rsaAnahtarOlusturucu); // Bellek yönetimi için serbest bıraktık

        /*
        İşlem sonucu taraf1 klasöründe taraf1Private.pem ve taraf1Public.pem olmak üzere iki adet dosya oluşur. İşte bunlar Private ve Public Key'lerdir
        */
    }
    else if (!strcmp(argv[1], "asama2")) // 2. Aşama, Public Key'lerin paylaşımı
    {
        filesystem::copy("../taraf2/taraf2Public.pem","taraf2Public.pem"); // Normal şartlarda bu paylaşma internet üzerinden olur. Ama şuan aynı bilgisayarda olduğumuz için basit bir kopyalama işlemi bize yeticektir
    }
    else if (!strcmp(argv[1], "asama3")) // 3. aşama, Public Key'ler elimizde olduğu için karşı tarafa mesaj yazabiliriz
    {
        RSA *rsaPublicKey = RSA_new(); // Veriyi şifreleyiceğimiz olan RSA nesnesi

        FILE* taraf2PublicDotPem = fopen("taraf2Public.pem", "rb"); // Taraf2'nin Public Key nesnemiz
        rsaPublicKey = PEM_read_RSAPublicKey(taraf2PublicDotPem, &rsaPublicKey, NULL, NULL); // Dosya üzerinden Public Key'i okuyoruz
        // rsaPublicKey = ; Sonucunda çıkartılan RSA nesnesi
        // taraf2PublicDotPem; Okunan RSA Public Key Pem dosyası
        // &rsaPublicKey; Üzerinde işlem yapılan RSA nesnesi
        
        fclose(taraf2PublicDotPem);
        
        string taraf2YeVeri = "Selam!"; // Taraf2'ye verimiz
        unsigned char sifreliVeri[4096]; // Şifrelenmiş verinini kayıt edilceği değişken

        int sifreninUzunlugu = RSA_public_encrypt(taraf2YeVeri.length() + 1, (unsigned char*)taraf2YeVeri.c_str(), sifreliVeri, rsaPublicKey, 1); // Public Key ile veriyi şifreler
        // int sifreninUzunlugu = ; Şifrenin uzunluğunu değişken olarak verir
        // taraf2YeVeri.length() + 1; Şifrenelecek olan verinin uzunluğu
        // (unsigned char*)taraf2YeVeri.c_str(); Şifrelenecek olan verinin başlangıç işaretçisi
        // sifreliVeri; Şifrelenmiş verinin kayıt edilceği başlangıç işaretçisi
        // rsaPublicKey; RSA Public Key nesnesi
        // 1; Veri bozulmasın diye içine konulan boşluk.

        RSA_free(rsaPublicKey);

        // Şifreleme işlemi tamamlandı şimdi o şifrelenmiş veriyi gönderme vakti

        ofstream msg("../taraf2/msg"); // Normal şartlarda gönderme işlemi internet aracığıyla olur. Ama bu kısımda basit bir "Karşı taraf klasörüne oluştur" mantığı iş görür
        for (size_t i = 0; i < sifreninUzunlugu; i++) // Dönen şifre boyutu kadar
        {
            msg << sifreliVeri[i]; // Her harfi teker teker yazdırıyoruz
        }
    }
    else if(!strcmp(argv[1], "asama4")) 
    {
        RSA* rsaPrivateKey = RSA_new();

        FILE* taraf1PrivateDotPem = fopen("taraf1Private.pem", "rb");
        rsaPrivateKey = PEM_read_RSAPrivateKey(taraf1PrivateDotPem, &rsaPrivateKey, NULL, NULL);

        fclose(taraf1PrivateDotPem);

        ifstream msgFile("msg");

        char msg[256];

        msgFile.read(msg, 256);

        msgFile.close();

        unsigned char cozulmusVeri[4096];

        RSA_private_decrypt(256, (unsigned char*)msg, cozulmusVeri, rsaPrivateKey, 1);

        cout << cozulmusVeri;

        RSA_free(rsaPrivateKey);
    }
    
}

        msgFile.close();

        unsigned char cozulmusVeri[4096]; // Çözülmüş veri için değişken

        RSA_private_decrypt(256, (unsigned char*)msg, cozulmusVeri, rsaPrivateKey, 1); // RSA Private Key ile taraf1'denki taraf2'deki RSA Public Key işe şifrelenmiş olna veriyi çözer

        cout << cozulmusVeri; // Veriyi yazdırır

        RSA_free(rsaPrivateKey);
    }
    if (!strcmp(argv[1], "asama4")) // 4. aşama, taraf2'den taraf1'de mesaj atma
    {
        RSA *rsaPublicKey = RSA_new();

        FILE* taraf1PublicDotPem = fopen("taraf1Public.pem", "rb");
        rsaPublicKey = PEM_read_RSAPublicKey(taraf1PublicDotPem, &rsaPublicKey, NULL, NULL);
        fclose(taraf1PublicDotPem);

        string taraf1YeVeri = "Selam!";
        unsigned char sifreliVeri[4096];

        int sifreninUzunlugu = RSA_public_encrypt(taraf1YeVeri.length() + 1, (unsigned char*)taraf1YeVeri.c_str(), sifreliVeri, rsaPublicKey, 1);

        RSA_free(rsaPublicKey);

        ofstream msg("../taraf1/msg");
        for (size_t i = 0; i < sifreninUzunlugu; i++)
        {
            msg << sifreliVeri[i];
        }
    }
    
}

Rastgele Sayı Üretme

Rastgele sayı, çoğu durumda oyunlarda veya etkinliklerde kullanılan ve kullanıcıya "Bilinmezlik" duygusunu veren bir olaydır. C programlama dilinde gerçekten rastgele bir sayı üretmek için "sodium" adlı bir kütüphaneye ihtiyaç duyardık. Ama C++ programlama dilinde bizler için kendi yerel algoritmalarıyla bize rastgele sayı sağlar. Bu kütüphane adındanda anlaşılcağı üzere random kütüphanesinde bulunur.
Random kütüphanesiyle rastgele sayı üretmek için iki ana nesne kullanılır. Oluşturucu ve dağıtıcılar. Oluşturucu rastgele sayı üretmek amacıyla kullanılan algoritma, dağıtımcı ise oluşturucuların algoritmalarını çalıştırarak verdiğimiz aralıkta bizlere rastgele sayı üretmemizi sağlayan nesnelerdir.
Bir çok algoritma bulunsada aralarında kriptofik olmayan sistemlerde başarılı ve yaygın olarak kullanılan algoritmaların başında ise mt19937 gelir ki biz bu konuda mt19937 ile rastgele sayı üretmeyi göstereceğiz.
Gelin beraber her çalıştırmada farklı bir sayı üreten bir program yazalım;

#include <iostream>
#include <random> // Kütüphanemiz

using namespace std;

int main()
{
    random_device mtCihaz; // mtCihaz, Cihazlar denilen bir nesne ile algoritmalara ortam sağlanır
    mt19937 mtOlusuturucu(mtCihaz()); // Oluşturucu nesnesini tanımladık. İçerisine cihazımızı yerleştirdik ki algoritmaya ortam sağlasın

    uniform_int_distribution<int> mtDagitici(1,10); // Dağıtıcımız. İçerisine 1,10 yazdık ki 1 ila 10 arasında 10'da dağil olması şartıyla bir aralık sunduk. Template'deki tür ise üretilen sayının türüdür

    cout << mtDagitici(mtOlusuturucu); // Ardında dağtıcımıza oluşturucumuzu ilave ettik ve bize sonucunda rastgele bir sayı üretti

    return 0;
}
