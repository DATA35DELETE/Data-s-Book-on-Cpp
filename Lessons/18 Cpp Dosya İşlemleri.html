Fstream Kütüphanesi

Fstream kütüphanesi, C++ programlama dilinde dosya işlemleri için kullanılan bir kütüphanedir.

İfstream

İfstream, fstream kütüphanesi altında dosyalardan veri okumak için kullanılan bir sınıftır.
Tahmin edebiliyorum ki bu dökümantasyonu okuyanları C programlama dili ile ilgili olan Data's Book on C dökümantasyonumu okumamıştır. Ama okuyanlar için bu komutlar bir yerlerden tanıdık gelicektir... Hadi "main.c" dosyasını ifstream ile okuyalım;

#include <iostream>
#include <fstream> // Kütüphanemiz

using namespace std;

int main()
{
    ifstream dosya1("main.c"); // Dosya okuma nesnemiz
    string satir; // Okumada kullanılan satir değişkeni

    while (getline(dosya1, satir)) // Getline, verilen dosya nesnedeki her bir satırı sırayla 2. parametredeki string ifadesine atar
    {
        cout << satir << endl; // Alınan satırları yazdırma
    }
    
    dosya1.close(); // Serbest bırakma. Bellek yönetimi için gereklidir

    return 0;
}
