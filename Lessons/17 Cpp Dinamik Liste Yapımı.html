Dinamik Liste Yapımı

Dinamik Listeler Nedir?

Dinamik listeler, boyutu içeriğine göre uzayıp kısalabilen yapılardır. Yani ne kadar içine içerik varsa o kadarda boyutları büyük olurlar. Aynı zamanda içlerindeki içeriğe erişim sağlarlar.
Peki diğer Array veya dizilerden farkı nedir? Adındanda anlaşılcağı üzere dinamik yani ortama göre değişkenlik gösterme becerileridir. Siz bir sayı dizisi tanımladığınızda RAM'de belirtilen alan kadar sabit bir bellek alırsınız. On verilik bir alan ise siz o dizise on adet veri yazabilirsiniz. Fazlası ise Buffer Overflow ile sonuçlanır. Fakat dinamik listeler ise sabit bir alana sahip olmayan ve ortama göre büyüp küçülebilen yapılardır.
C++ programlama dili C'den farklı olarak STL kütüphanesi ile dinamik liste ihtiyacını karşılar. Fakat şuan öğrenceklerimiz ise STL kütüphanesinin kapsayıcı elemanlarının temel yapı taşıdır. Biz görmesekte STL kapsayıcıların arka planında birazdan görüceğimiz yapılar bulunur. Pek tabi C'de bırakın STL'i hazır kütüphane bulunmadığından, C'de bu işlemler sık kullanılırdı. C'de C++'ın atası olduğundan öğrenmekte fayda vardır elbet.

Linked List

Linked List veya bağlantılı liste, kendilerinden sonraki veya önceki elemanların bellek adreslerinin kendi içlerinde tutan ve dilendiği zamanlarda geçiş yapılabilen belkide en ilkel dinamik liste yapısıdır. Üç adet türü vardır.

Tek Yönlü

Tek yönlü bağlantılı liste, içinde kendisinden sonraki elemanın bellek adresini barından bir yapı sunar.
Bu bağlantılı liste türündeki elemanlar bir sonrakinin bellek adresine tutuyor demiştik. Peki en sondaki neyi tutuyor? Bir elemanı tutamacağı için nullptr tutar. Böylelikle listenin sonuna geldiğimizi anlarız. Daha iyi anlaşılması için bir görsel örnek gösterelim;
Gelin bir ekmek sırası programı yapalım. Şaka bir yana ekmek sıraları bir nevi tek yönlü bağlantılı liste gibi çalışır. Ekmek almak için bir önünüzde kişininde ekmek alması yani sıradan çıkması gerekir ki sıranız gelsin. Hadi fırın açalım!

#include <iostream>

using namespace std;

class kisi
{
    private:
        int alinicakEkmekSayisi = 0; // Tek yönlü bağlantılı listedeki elemanın içindeki veri

        kisi* sonrakiKisi; // Bir sonraki elemanın bellek adresini tutacak olan değişken

    public:
        string kisiIsmi = ""; // Birde isim bilgisi yer alsın

        int kacEkmekAlincak() // İçindeki veriyi almak için
        {
            return alinicakEkmekSayisi;
        }
        void ekmekAlincaSayisiAyarla(int sayi) // İçeriği ayarlama
        {
            alinicakEkmekSayisi = sayi;
        }

        kisi* sonrakineGec() // Sonraki elemana geçmek için
        {
            return sonrakiKisi;
        }
        void sonrakiniAyarla(kisi* snrkks) // Sonraki elemanı ayarlamak için
        {
            sonrakiKisi = snrkks;
        }

        kisi(string isim) // Yapıcı olarak da isimle yapıcı olsun
        {
            kisiIsmi = isim;
        }
};

int main()
{
    // Şimdi kişileri oluşturalım. 5 adet
    kisi ahmet("Ahmet");
    ahmet.ekmekAlincaSayisiAyarla(3);
    kisi mehmet("Mehmet");
    mehmet.ekmekAlincaSayisiAyarla(5);
    kisi ayse("Ayse");
    ayse.ekmekAlincaSayisiAyarla(8);
    kisi fatma("Fatma");
    fatma.ekmekAlincaSayisiAyarla(1);
    kisi remzi("Rezmi");
    remzi.ekmekAlincaSayisiAyarla(6);

    // İçerikleni ayarladık şimdi birbirlerine bağlıyalım. Sırası; ahmet -> mehmet -> ayse -> fatma -> remzi
    ahmet.sonrakiniAyarla(&mehmet);
    mehmet.sonrakiniAyarla(&ayse);
    ayse.sonrakiniAyarla(&fatma);
    fatma.sonrakiniAyarla(&remzi);
    remzi.sonrakiniAyarla(nullptr);
    // Liste tamam. Şimdi içeriğini görüntüleyelim

    kisi* genelSira = &ahmet; // Genel tüm insanları tutacak olan nesne. Ahmet'ten başlıyoruz

    while (genelSira != nullptr) // genelSira nullptr olmadığı süreççe
    {
        cout << &genelSira->kisiIsmi << " adresinden " << genelSira->kisiIsmi << " su kadar ekmek alicak; " << genelSira->kacEkmekAlincak() << endl << endl; // İçeriğini bellek adresi ile görüntüleyelim

        genelSira = genelSira->sonrakineGec(); // Sonraki veriye geçelim
    }
    
    return 0;
}

Çıktısı ise;
Fark etti iseniz kendisine "Liste" desekte RAM bu yapıları bir liste değil bir nesne gibi görüyor ki bellek adreslerinin Pointer aritmetiğinde anlıyabiliriz bunu. Bu sebeble diziler gibi *(i + 1) gibi bir mantık bağlantılı listelerde pek işe yaramazdır.

Çift Yönlü

Çift yönlü bağlantılı liste ise kendisinden önceki ve sonraki elemanın bellek adresini tutan, dilendiği vakitde elemanlar arasında geçiş yapmamızı sağlayan bir başka türdür.
Tek yönlülerde olduğu gibi çift yönlülerde de son eleman nullptr değeri tutar. Peki çift yönlü bağlantılı listede ilk eleman önceki elemanı tutmak için neyi tutuyor? Tabiki oda nullptr tutuyor. Daha iyi anlaşılması için bir görsel sunalım;
Şimdi gelin bir delilik edelim ve ekmek sıramızda sondan başa ve baştan sona şeklinde gidip gelelim;

#include <iostream>

using namespace std;

class kisi
{
    private:
        int alinicakEkmekSayisi = 0; // Çift yönlü bağlantılı listedeki elemanın içindeki veri

        kisi* oncekiKisi; // Bir önceki elemanın bellek adresini tutacak olan değişken
        kisi* sonrakiKisi; // Bir sonraki elemanın bellek adresini tutacak olan değişken

    public:
        string kisiIsmi = "";

        int kacEkmekAlincak()
        {
            return alinicakEkmekSayisi;
        }
        void ekmekAlincaSayisiAyarla(int sayi)
        {
            alinicakEkmekSayisi = sayi;
        }

        kisi* sonrakineGec()
        {
            return sonrakiKisi;
        }
        void sonrakiniAyarla(kisi* snrkks)
        {
            sonrakiKisi = snrkks;
        }
        kisi* oncekineGec() // Önceki elemana geçmek için
        {
            return oncekiKisi;
        }
        void oncekiniAyarla(kisi* nckks) // Önceki elemanı ayarlamak için
        {
            oncekiKisi = nckks;
        }

        kisi(string isim)
        {
            kisiIsmi = isim;
        }
};

int main()
{
    kisi ahmet("Ahmet");
    ahmet.ekmekAlincaSayisiAyarla(3);
    kisi mehmet("Mehmet");
    mehmet.ekmekAlincaSayisiAyarla(5);
    kisi ayse("Ayse");
    ayse.ekmekAlincaSayisiAyarla(8);
    kisi fatma("Fatma");
    fatma.ekmekAlincaSayisiAyarla(1);
    kisi remzi("Rezmi");
    remzi.ekmekAlincaSayisiAyarla(6);

    // İçerikleni ayarladık şimdi birbirlerine bağlıyalım. Sırası; ahmet <-> mehmet <-> ayse <-> fatma <-> remzi
    ahmet.oncekiniAyarla(nullptr);
    ahmet.sonrakiniAyarla(&mehmet);
    mehmet.oncekiniAyarla(&ahmet);
    mehmet.sonrakiniAyarla(&ayse);
    ayse.oncekiniAyarla(&mehmet);
    ayse.sonrakiniAyarla(&fatma);
    fatma.oncekiniAyarla(&ayse);
    fatma.sonrakiniAyarla(&remzi);
    remzi.oncekiniAyarla(&fatma);
    remzi.sonrakiniAyarla(nullptr);
    // Liste tamam. Şimdi içeriğini görüntüleyelim

    kisi* genelSira = &ahmet; // Genel tüm insanları tutacak olan nesne. Ahmet'ten başlıyoruz

    while (genelSira != nullptr) // genelSira nullptr olmadığı süreççe
    {
        cout << &genelSira->kisiIsmi << " adresinden " << genelSira->kisiIsmi << " su kadar ekmek alicak; " << genelSira->kacEkmekAlincak() << endl << endl; // İçeriğini bellek adresi ile görüntüleyelim

        genelSira = genelSira->sonrakineGec(); // Sonraki veriye geçelim
    }

    cout << "------------------------------------------------------" << endl << endl; // Ayırma çizgisi

    // Şimdi tam tersi gidelim
    genelSira = &remzi;

    while (genelSira != nullptr) // genelSira nullptr olmadığı süreççe
    {
        cout << &genelSira->kisiIsmi << " adresinden " << genelSira->kisiIsmi << " su kadar ekmek alicak; " << genelSira->kacEkmekAlincak() << endl << endl; // İçeriğini bellek adresi ile görüntüleyelim

        genelSira = genelSira->oncekineGec(); // Önceki veriye geçelim
    }
    
    return 0;
}

Dairesel

Dairel bağlantılı listelerde de çift yönlüye benzer bir yapıya sahiptir. Tek farkı en sondaki eleman en baştaki, en baştaki elemanda en sondaki elemanın bellek adresini tutar. Yani bir nevi daire gibi bir yapı oluşur. Görsel ile destekliyelim;
Ancak dikkat dairsel bağlantılı listelerde kısır döngü riski çok fazladır. Bu sebeble durdurma noktaları için ilk ve son elemanın bellek adreslerini tutan "Geçici değişkenler" tanımlayalım.
Şimdi hayal gücümüzü zorlayalım... Biz öyle iyi ekmek yapıyoruz ki götürenler doyamıyor ve bir gün içinde dört kez geliyor olsunlar. Garip bri şekilde iki kere düz iki kere de ters sıra halinde geliyor. Hadi bu similasyonu kodluyalım;

#include <iostream>

using namespace std;

class kisi
{
    private:
        int alinicakEkmekSayisi = 0; // Dairesel bağlantılı listedeki elemanın içindeki veri

        kisi* oncekiKisi; // Bir önceki elemanın bellek adresini tutacak olan değişken
        kisi* sonrakiKisi; // Bir sonraki elemanın bellek adresini tutacak olan değişken

    public:
        string kisiIsmi = "";

        int kacEkmekAlincak()
        {
            return alinicakEkmekSayisi;
        }
        void ekmekAlincaSayisiAyarla(int sayi)
        {
            alinicakEkmekSayisi = sayi;
        }

        kisi* sonrakineGec()
        {
            return sonrakiKisi;
        }
        void sonrakiniAyarla(kisi* snrkks)
        {
            sonrakiKisi = snrkks;
        }
        kisi* oncekineGec()
        {
            return oncekiKisi;
        }
        void oncekiniAyarla(kisi* nckks)
        {
            oncekiKisi = nckks;
        }

        kisi(string isim)
        {
            kisiIsmi = isim;
        }
};

int main()
{
    kisi ahmet("Ahmet");
    ahmet.ekmekAlincaSayisiAyarla(3);
    kisi mehmet("Mehmet");
    mehmet.ekmekAlincaSayisiAyarla(5);
    kisi ayse("Ayse");
    ayse.ekmekAlincaSayisiAyarla(8);
    kisi fatma("Fatma");
    fatma.ekmekAlincaSayisiAyarla(1);
    kisi remzi("Rezmi");
    remzi.ekmekAlincaSayisiAyarla(6);

    // İçerikleni ayarladık şimdi birbirlerine bağlıyalım.
    // Sırası; ahmet <-> mehmet <-> ayse <-> fatma <-> remzi
    //           î                                       î
    //           |                                       |
    //           L_______________________________________J
    ahmet.oncekiniAyarla(&remzi);
    ahmet.sonrakiniAyarla(&mehmet);
    mehmet.oncekiniAyarla(&ahmet);
    mehmet.sonrakiniAyarla(&ayse);
    ayse.oncekiniAyarla(&mehmet);
    ayse.sonrakiniAyarla(&fatma);
    fatma.oncekiniAyarla(&ayse);
    fatma.sonrakiniAyarla(&remzi);
    remzi.oncekiniAyarla(&fatma);
    remzi.sonrakiniAyarla(&ahmet);
    // Liste tamam. Şimdi içeriğini görüntüleyelim

    kisi* genelSira = &ahmet; // Genel tüm insanları tutacak olan nesne. Ahmet'ten başlıyoruz

    for (int i = 0; i < 10; i++) // For ile yapalım ki kısır döngü yaşamayalım
    {
        cout << &genelSira->kisiIsmi << " adresinden " << genelSira->kisiIsmi << " su kadar ekmek alicak; " << genelSira->kacEkmekAlincak() << endl << endl; // İçeriğini bellek adresi ile görüntüleyelim

        genelSira = genelSira->sonrakineGec(); // Sonraki veriye geçelim
    }
    

    cout << "------------------------------------------------------" << endl << endl;

    // Şimdi tam tersi gidelim
    genelSira = &remzi;

    for (int i = 0; i < 10; i++)
    {
        cout << &genelSira->kisiIsmi << " adresinden " << genelSira->kisiIsmi << " su kadar ekmek alicak; " << genelSira->kacEkmekAlincak() << endl << endl; // İçeriğini bellek adresi ile görüntüleyelim

        genelSira = genelSira->oncekineGec(); // Önceki veriye geçelim
    }
    
    return 0;
}

Stack

Stack, LIFO mantığı ile çalışan bir dinamik listedir ki sıkça bahsettik bu konudan. Bu sebeble direkt kodu verceğim;
Hadi ekmek sıramız Stack ile yeniden şekillensin;

#include <iostream>
#include <vector>
#include <tuple>

using namespace std;

class stackEkmekSirasi
{
    private:
        vector<tuple<string,int>> veriler; // Hadi biraz STL nimetlerinden faydalanalım. Ayrıca evet STL kapsayıcıların içeriğini başka kapsayıcılarla doldurabiliyoruz
        // string; Müşteri ismi
        // int; Alıcağı ekmek miktarı

        int enUstdekiEleman; // Bu değişken ise Stack'deki Top yani en üstdeki elemanın Index numarası görevi görür

    public:
        stackEkmekSirasi() // Yapıcısı
        {
            enUstdekiEleman = -1; // -1 yaptık çünkü ilk oluşturulduğunda herhangi bir eleman olmucaktır. 0 değil çünkü 0'da bir Index karşılığı vardır
        }

        void ekle(tuple<string, int> kisi) // Veri ekleme
        {
            veriler.emplace_back(kisi); // En arka kısma ekle

            enUstdekiEleman++; // En üstdeki elemanın Index'sini tutacak olan değişkenide 1 arttır
        }

        tuple<string, int> ustdekiVeriyiGetir() // En üstdeki veriyi getirme
        {
            if (enUstdekiEleman != -1) // Eğer Stack boş değil ise
                return veriler.at(enUstdekiEleman); // En üstdeki elemanı getir
            else
                return {"", -1}; // Boş ise boş bir Tuple değeri gönder
        }

        void sil()
        {
            veriler.pop_back(); // En arkadaki veriyi sil

            enUstdekiEleman--; // Üstdeki elemanın Index numarasını tutan değişkeni 1 eksilt. -- operatörü değişkenlerde 1 değer kadar eksiltir
        }
};

int main()
{
    stackEkmekSirasi genelSira; // Nesnemiz
    genelSira.ekle({"Ahmet", 3});
    genelSira.ekle({"Mehmet", 5});
    genelSira.ekle({"Ayse", 8});
    genelSira.ekle({"Fatma", 1});
    genelSira.ekle({"Remzi", 6});

    // Liste Stack olduğu ve sınıf içerisinde sıra işi otomatik ayarlandığı için sıralamaya gerek yoktur

    while (get<1>(genelSira.ustdekiVeriyiGetir()) != -1) // Üstdeki veri boş değil ise
    {
        cout << get<0>(genelSira.ustdekiVeriyiGetir()) << " adli kisi su kadar ekmek almak istiyor; " << get<1>(genelSira.ustdekiVeriyiGetir()) << endl << endl; // Veriyi yazdır

        genelSira.sil(); // En üstdeki veriyi sil
    }
    
    return 0;
}

Queue

Hadi Stack olan yapımızı Queue'e çevirelim;

#include <iostream>
#include <vector>
#include <tuple>

using namespace std;

class queueEkmekSirasi
{
    private:
        vector<tuple<string,int>> veriler;

        int sondakiEleman;
        int ondekiEleman;

    public:
        queueEkmekSirasi() // Yapıcısı
        {
            ondekiEleman = -1; // Elemanları ayarlıyoruz
            sondakiEleman = 0;
        }

        void ekle(tuple<string, int> kisi) // Veri ekleme
        {
            veriler.emplace(veriler.begin().operator+(sondakiEleman), kisi);

            sondakiEleman++;
        }

        tuple<string, int> ustdekiVeriyiGetir() // Veriyi getirme
        {
            if (ondekiEleman != sondakiEleman - 1) // Eğer boş değil ise
                return veriler.at(ondekiEleman + 1); // En öndeki elemanı getir
            else
                return {"", -1}; // Boş ise boş bir Tuple değeri gönder
        }

        void sil() // Silme işlemi
        {
            veriler[ondekiEleman + 1] = {"", -1};

            ondekiEleman++;
        }
};

int main()
{
    queueEkmekSirasi genelSira;
    genelSira.ekle({"Ahmet", 3});
    genelSira.ekle({"Mehmet", 5});
    genelSira.ekle({"Ayse", 8});
    genelSira.ekle({"Fatma", 1});
    genelSira.ekle({"Remzi", 6});

    while (get<1>(genelSira.ustdekiVeriyiGetir()) != -1)
    {
        cout << get<0>(genelSira.ustdekiVeriyiGetir()) << " adli kisi su kadar ekmek almak istiyor; " << get<1>(genelSira.ustdekiVeriyiGetir()) << endl << endl;

        genelSira.sil();
    }
    
    return 0;
}

Generic Liste

Generic veya genel liste, tür bağımsız bir şekilde tanımlanabilen ve kullanılabilen listelere denir.
