Fonksiyonlar

Fonksiyonlar Nedir?

Fonksiyonlar, belirli bir amacı yerine getirmek için yazılmış kodların bütün haline getirilmesiyle oluşan yapıdır.
Fonksiyonlar aslında bizim için çok önemli yapıladır. Çünkü bir kod parçasını sürekli çalıştırmamız gereken durumlar olucaktır. Bu gibi durumlarda o kod parçasını sürekli yazıcak mıyız? Tabiki hayır! O kod parçasına göre bir fonksiyon yazacağız ve ihtiyacımız olduğunda çağrıcaz. Böylelikle kod tasarufu hemde alan tasarufu etmemizi sağlar. Ayrıca program akışını etkileyebilirler. Ana akış fonksiyon bitene kadar fonksiyondaki akışı bekler.
Dökümantasyonun başında Main fonksiyonun programın ilk başlıyan kısmı olduğunu söylemiştik. İşte Main fonksiyonu bu sebeble en önemli fonksiyondur.s Tüm programlar ve yazılım dilleri istisnasız Main fonksiyonuyla başlar. Eğer biz Main fonksiyonunu tanımlamazsak derliyici bizlere hata vericektir.

Void Fonksiyonlar

Void fonksiyonlar, gerisin geriye bir sonuç vermeyen sadece program akşını etkileyen fonksiyonlardır.
Şimdi gelin beraber "Hello World" programı yazalım. Fakat yazdırma komutunu başka bir fonksiyona yazalım ve o fonksiyonu çağrınca çıktı olarak "Hello World" yazdırsın;

#include <iostream>

using namespace std;

// Fonksiyonumuz
void helloWorldYazdir()
{ // Fonksiyonumuzun içeriği
    cout << "Hello World" << endl;
}

int main(){
    helloWorldYazdir(); // Fonksiyonumuzu çağrıyoruz

    return 0;
}

Çıktı;

Return'lu Fonksiyonlar

Return'lu fonksiyonlar, çağrıldıklarında değer olarak bir sonuç veren ve Void'li fonksiyonlar gibi program akşını etkiliyen fonksiyon türüdür. Fonksiyon içerisinde "return" ifadesi ile değer dödürülür. Ayrıca return ifadesinden sonra fonksiyon biter. Dolayısıyla return komutundaki sonraki satırlara fonksiyon için kod yazılmaz. Return'lu yazmak için fonksiyon isminin bir önceki kısmına, döndüreceğimiz değerin türü girilir.
Şimdi öğrendiğimiz bu yeni bilgi ile programızı güncelleyelim;

#include <iostream>

using namespace std;

// Döndürüceğimiz değerin türü String olduğunu için "string" yazdık
string helloWorldStringiniAl()
{
    return "Hello World"; // Değerimizi bu satır ile döndürdük
}

int main(){
    cout << helloWorldStringiniAl() << endl; // Fonksiyonumuzu çağırdık

    return 0;
}

Çıktı değişmicektir fakat yöntemizin değiştiğini gözlemleyebilirsiniz.

Return Kodları ile Hata Yönetimi

Programcılar bilir ki her zaman hazır kütüphaneler ile kod yazılmaz. Yeri geldi mi kendisine özel kütüphane yazacak kadar bilgiye sahip olmalıdır. Kütüphane yazarken de hata yönetimi yapılır. "Hata Yönetimi" sayfasında gördüğümüz gibi hata yönetimi yapmazsak program beklenmeyen şekilde davranabilir. İşte bu sebeble return ile hata kodlarını bilmemiz gerekir.
Genel olarak C ve C++ kütüphanelerinde hatasız durumlar için sıfır, hatalı durumlar içinde sıfırdan farklı değerler kullanılır. Bizde iki adet fonksiyon tanımlayım. Biri hatasız fonksiyon olsun ve dönüş değeri sıfır olsun. Diğeri ise hatalı kod içeriyormuş gibi bir değerini döndürsün. Ardından karar yapıları ile bu durumlara özel mesaj yazdıralım.

#include <iostream>

using namespace std;

int dogruFonk(){

    // Kodlar

    return 0;
}

int yanlisFonk(){

    // Kodlar

    return 1;
}

int main(){

    int birinciDurum = dogruFonk();

    if (birinciDurum == 0)
    {
        cout << "Fonksiyon hatasiz calisti" << endl << endl;
    }
    else
    {
        cout << "Fonksiyon hata kodu; " << birinciDurum << endl << endl;
    }

    int IkinciDurum = yanlisFonk();

    if (IkinciDurum == 0)
    {
        cout << "Fonksiyon hatasiz calisti" << endl << endl;
    }
    else
    {
        cout << "Fonksiyon hata kodu; " << IkinciDurum << endl << endl;
    }
}

Çıktı ise;
Aynı sebebten ötürü Main fonksiyonunda da Return kodu ile hata yönetimi yapılır. Eğer program sıfır dönerse sorunsuz, farklı bir sayı dönerse ise sorunlu çalışıp sona erdiğini anlayabiliriz.

Parametreli Fonksiyonlar

Parametreli fonksiyonlar, parantezlerine tanımlanmış değerlere göre fonksiyona değerler gönderebildiğimiz bir fonksiyon kullanımıdır. Hem Void hemde Return fonksiyonlarda kullanılabilirdir.
Şimdi hem Void hemde Return fonksiyonlarında bu bilgiyi kullanalım. Parametresine tanımlanmış bir String değeri ekrana yazdıran, parametresine girilen iki Integer sayıyı toplayıp sonucu döndüren iki adet fonksiyon yazalım.

#include <iostream>

using namespace std;

void yazdir(string yazi)
{
    cout << yazi << endl << endl;
}

int topla(int a, int b)
{
    return a + b;
}

int main(){
    yazdir("2 + 2 =");

    cout << topla(2, 2) << endl;

    return 0;
}

Çıktı;

Varsayılan Parametreler

Varsayılan parametreler, parametreli fonksiyonlarda çağrıldıklarında parantezlerindeki tanımlanmış parametrelere herhangi bir değer gönderilmemişse programcı tarafından seçilen değer ile parametreye atanan parametrelerdir.
Örnek olarak "topla" fonksiyonumuzdaki parameterli varsayılan değerlerini iki değeri olarak belirleyelim. Böylelikle eğer fonksiyon çağrıldığında parametrelerine değer gönderilmemişse iki olarak atansın

#include 

using namespace std;

int topla(int a = 2, int b = 2)
{
    return a + b;
}

int main(){
    cout << topla(5) << endl; // Gördüğünüz gibi ilk parametresine 5 değerine verdik fakat ikinci parametreyi boş bıraktık. Fonksiyon bu durumu fark edecek ve ikinci parametreyi varsayılan değer olan 2 ile işlem yapıcak

    return 0;
}

Çıktı ise;

Fonksiyonu Aşırı Yükleme

Fonksiyonu aşırı yükleme, parametreliri farklı fakat isimleri aynı olan fonksiyonlara denir. Amaç ise organizasyon ya da farklı veri türleri için farklı isimli fonksiyon oluşurturmamaktır. Yani kullanım kolaylığı sağlar.
Parametreli fonksiyonlardaki örneğimizi bu bilgi ile yeniden yazalım.

#include <iostream>

using namespace std;

void toplaVeyaYazdir(string yazi) // Aşırı yüklenmiş fonksiyon
{
    cout << yazi << endl << endl;
}

int toplaVeyaYazdir(int a, int b) // Aşırı yüklenmiş fonksiyon
{
    return a + b;
}

int main(){
    toplaVeyaYazdir("2 + 2 =");

    cout << toplaVeyaYazdir(2, 2) << endl;

    // Aynı isimli fonksiyonlar çağrılsada parametreleri sayesinde farklı işlemler yapılabilir

    return 0;
}

Çıktı değişmicektir fakat uygulayış biçimiz değiştirmiş bulunmaktayız.

Özyenilemeli Fonksiyonlar

Özyenilemeli fonksiyonlar, fonksiyon kendi içinde kendini tekrar çağırma durumudur. Bir nevi döngü gibidir.
Şimdi ise özyenilemeli fonksiyon kullanarak bir sayaç yapalım.

#include 

using namespace std;

int sayac; // Sayaç için değişkenimiz
void sayacFonk(int syc = 10) // Sayaç olucak özyenilemeli fonksiyonumuz. Ayrıca herhangi bir değer girilmezse otomatik olarak 10 değerinde başlıcak şekilde ayarladık 
{
    sayac = syc; // Girilen veya varsayılan değeri değişkene atama

    cout << sayac << ". adim" << endl; // Sayaç adımını bildirme

    if (sayac == 0) // Sayaç bitti ise
    { // Çalıştır
        return; // Fonksiyonu bitir. Void'li fonksiyonlarda Return kullanılabilir fakat herhangi bir değer döndürülemez
    }
    else // Bitmedi ise
        sayac--; // Sayacı 1 eksilt. -- operatörü değerleri 1 azaltmamızı sağlar. Ayrıca karar yapsının çalıştırıcağı kod bir satırlık ise kod blokları istersek açmaya biliriz. Karar yapısı sadece bir altadaki kodu çalıştırır onun dışında diğer kodlar karışamaz

    sayacFonk(sayac); // Fonksiyonun içerisinde kendi çağıran kısım burasıdır. Parametre olarak mevcut sayac'ın değerini yolladık çünkü boş bırakırsak sayaç döngüye girerdi
}

int main(){
    cout << "Sayac basladi..." << endl << endl;

    sayacFonk(20); // 20 değerin gönderdik

    cout << endl << "Sayac bitti..." << endl;

    return 0;
}

Çıktısı;

Satır İçi Fonksiyonlar

Satır içi fonksiyonlar veya Inline fonksiyonlar, çağrıldıkları kısımda fonksiyon içeriğini çağrıldıkları kısıma yapıştıran ve Compiler edildiğin o şekilde derlenen fonksiyonlardır. Inline fonksiyon yazmak için fonksiyon başına inline ifadesi konulur.
Peki farkı nedir? Bu durum şunu benzetebilirisiniz; Sabah kalktınız ve evde ekmek olmadığını fark ettiniz. Her insanın yapacağı üzere kendinizde "firinaGit" fonksiyonunu çalıştırdığınız ve fırına gittiniz. İşte normal fonksiyonlar bu şekilde çalışır. Çalıştıklarında ana fonksiyondan çıkıp yani sizin evden çıkmanız gibi kendi alanlarına giderler ve işlerini halledip tekrar Main fonksiyona geri dönmeleri gibi... Tıpkı sizinde ekmek alıp eve gelmeniz gibi... Fakat Inline fonksiyonlar ise fırına gitmek yerine fırının size geldiğini hayal edin. Kodda ise bu durum fonksiyon Main'den alıp kendi alanına götürmek yerine fonksiyonun kendi alanını Main fonksiyonuna taşımaktadır. İşte Inline fonkisyonlar bu şekilde çalışır.
Inline fonksiyonlar genel olarak Compiler'a kolaylık sağlarlar. Compiler iki program akışını birbirne bağlamak yerine fonksiyondaki akışı Main program akışının içine koyar. Bu durumu bir görsel ile gösterelim;

Makro ile Satır İçi Fonksiyonlar

Makro ile satır içi fonksiyonlar, satır içi fonksiyonlar ile aynı işleve sahip sadece akışı ana akışın içine yerleştirme kısmında kodların derlenme sürecindeki önişlemciler kısmında yapılması farkı ile başka bir satır içi fonksiyondur. Fakat inline kadar güvenli değildir. return etmek için kelime kullanılmaz ve fonksiyon içeriğini direkt geçirir.
Inline fonksiyonlardaki örneğimizin makro şekilde yeniden yazalım.

#include <iostream>

using namespace std;

#define topla(x,y) x + y
// Şeklinde tanımlanır
int main()
{
    cout << topla(2,2) << endl << endl; // Ve kullanılır

    return 0;
}
        
Çıktı ise;

Lambda Fonksiyonlar

Lambda fonksiyonlar, akış içerisinde isimsiz fonksiyon oluşturabildiğimiz fonksiyon türüdür. Geneillikle kısa ve öz kullanım için uygundur. Ayrıca C++11 standartı ile C++'a eklenmiştir.
#include <iostream>

using namespace std;

int main()
{
    auto topla = [](int a, int b){
        cout << a + b;
    }; // Fonksiyonu tanımladık

    topla(1,2); // Fonksiyonu çağırdık

    return 0;
}

Çıktısı;

Fonksiyon Şablonları

Fonksiyon şablonları, tür bağımsız şekilde fonksiyon yazmamızı sağlayan fonksiyonlardır. Kullanımı ise temple<typename girilenTur> şeklinde kullanılır.
Bu yapı size Array konusundan tanıdık gelebilir. Aynen öyle Array gibi yapılar Temple mantığı ile yazılır. Şimdi ise yazacağımız fonksiyon ise hem Integer hemde Float veri türleri için toplama sağlayan bir fonksiyon olucak.

#include <iostream>

using namespace std;

// Şablon ile fonksiyon bu şekilde tanımlanır
template<typename girilenTur> girilenTur topla(girilenTur a, girilenTur b) // Şablonların içerisine yazılan veri türünün aynı bir değişken gibi "girilenTur" adlı bir tür değişkenine atadık. Ardından tür bağımsız olucak olan kısımlara uygun olacak şekilde yerleştirdik
{
    return a + b;
}

int main()
{
    cout << "2 + 3 = " << topla(2,3) << endl << endl; // Integer türü ile çağırdık

    cout << "2.43 + 3.321 = " << topla(2.43,3.321) << endl; // Double türü ile çağırdık

    return 0;
}

Çıktısı ise;

Fonksiyon Prototipleri

Fonksiyon prototipleri, önceden dönüş türü, ismi ve parametreli tanımlanmış bir fonksiyonun daha sonra içini doldurulmuş fonksiyon araçlarına denir.
C++ yukarıdan aşağı kodları çalıştıran bir yazılım dilidir. Dolayısıyla yukarıda tanımlanan fonksiyonlar aşağıda çalıştırabilirdir. Fakat eğer fonksiyon aşağıda tanımlanıp yukarıda çalıştırılmak isternirse? İşte o zaman derliyici hata vermektedir. Bu sebeble fonksiyon prototipleri veya imzaları vardır. Fonksiyonun baş(Header) kısmını içeriğini(dönüş tipini, ismini ve parametrelerini) yazılıp ardından istenilen yerde içeriğini(Body) doldurulmasını sağlar.
Şimdi gelin bir önceki konudaki örneğinin fonksiyon prototipli versiyonunu yazalım;

#include <iostream>

using namespace std;

template<typename girilenTur> girilenTur topla(girilenTur a, girilenTur b); // Fonksiyonumuzun imzası

int main()
{
    cout << "2 + 3 = " << topla(2,3) << endl << endl;

    cout << "2.43 + 3.321 = " << topla(2.43,3.321) << endl;

    return 0;
}

template<typename girilenTur> girilenTur topla(girilenTur a, girilenTur b)
{
    return a + b;
}

Çıktı değişmicektir fakat uygulayış biçimi farklılık göstermektedir.

Fonksiyon Pointer'ları

"Pointerlar" sayfasında da anlattığımız üzere Pointer'lar yapıların bellek adreslerini temsil eden ve onların üzerinden verilere erişebildiğimiz araçlardır. Şimdi bu konunun fonksiyon tarafını inceleyelim.

Tanımlama ve Kullanımı

Tanımlama ve kullanımı aynı değişkenlerin Pointer işlemleri gibi yapılır.

#include <iostream>

using namespace std;

int topla(int a, int b)
{
    return a + b;
}

int main()
{
    int (*toplaPtr)(int a,int b) = topla; // Pointer tanımlama bu şekilde yapılır. Bellek adresini aLma operatörü olan ampersend(&) kullanılmaz. Çünkü fonksiyonlar zaten bellek adresleri gibi çalışırlar

    cout << toplaPtr(2,2) << endl; // Bu şekilde de kullanılır
}

Çıktısı ise;

std::function Kullanımı

std::function, functional kütüphanesiyle beraber gelen ve C++11 standartı ile C++'a eklenen bir fonksiyon değişken türüdür. Yanında getirdiği özelliklerle beraber bir nevi fonksiyon Pointer'ların yerine kullanılır.
Bir önceki örneği bu sefer std::function ile yeniden yazalım.

#include <iostream>
#include <functional> // Kütüphanemiz

using namespace std;

int topla(int a, int b)
{
    return a + b;
}

int main()
{
    std::function<int(int, int)> toplaPtr = topla; // Bu şekilde kullanılır
    // std::function, Temple şeklinde ayarlanır."int(int, int)" ifadesindeki dış int dönüş tipidir, parantezin içerisindeki türler ise parametrelerin sırayla türleri yazılır

    cout << toplaPtr(2,2) << endl;
}

Çıktı değişmicektir fakat yapılış biçimi farklıdır.

Callback

Callback, bir fonksiyon parametresinde başka bir fonksiyonu gönderip, fonksiyonun içerisine parametredeki fonksiyonu çağırma yapısına denir.
Örnek olarak ise iki adet fonksiyon yazalım. Biri toplama diğeri ise çıkarma işlemlerini içersin. Ardından iki fonksiyonuda yönetebildiğimiz ana fonksiyon olsun ve o fonksiyon üzerinden diğer işlemlere erişelim.

#include <iostream>

using namespace std;

int topla(int a, int b) // Toplama
{
    return a + b;
}

int cikarma(int a, int b) // Çıkarma
{
    return a - b;
}

int anaFonk(int (*callback)(int, int), int a, int b) // Callback'li fonksiyonumuz
{
    return callback(a,b); // Callback fonksiyonuna tanımlanan fonksiyonu çağırma
}

int main()
{
    cout << "10 + 2 = " << anaFonk(topla, 10, 2) << endl << endl; // anaFonk üzerinden toplama işlemi

    cout << "10 - 2 = " << anaFonk(cikarma, 10, 2) << endl; // anaFonk üzerinden çıkarma işlemi
}

Çıktı ise;

Fonksiyon Dizisi

Aynı veri türleri gibi fonksiyonlarında dizisi olabilir. Aynı mantık ile tanımlanır ve kullanılır.
Fonksiyon Pointer ile bir önceki örneğimizi anaFonk'suz bir şekilde yeniden yazalım.

#include <iostream>

using namespace std;

int topla(int a, int b) // Toplama
{
    return a + b;
}

int cikarma(int a, int b) // Çıkarma
{
    return a - b;
}

int main()
{
    int (*fonksiyonlar[])(int, int) = {topla, cikarma};

    cout << "10 + 2 = " << fonksiyonlar[0](10, 2) << endl << endl; // Fonkisyon dizisi üzerinden 0. Index'deki toplama işlemi

    cout << "10 - 2 = " << fonksiyonlar[1](10, 2) << endl; // Fonkisyon dizisi üzerinden 1. Index'deki çıkarma işlemi
}

Çıktı değişmicektir.

Aynı şekilde std::function ile yeniden yazalım.

#include <iostream>
#include <functional>

using namespace std;

int topla(int a, int b) // Toplama
{
    return a + b;
}

int cikarma(int a, int b) // Çıkarma
{
    return a - b;
}

int main()
{
    std::function<int(int, int)> fonksiyonlar[] = {topla, cikarma};

    cout << "10 + 2 = " << fonksiyonlar[0](10, 2) << endl << endl; // std::function fonkisyon dizisi üzerinden 0. Index'deki toplama işlemi

    cout << "10 - 2 = " << fonksiyonlar[1](10, 2) << endl; // std::function fonkisyon dizisi üzerinden 1. Index'deki çıkarma işlemi
}
