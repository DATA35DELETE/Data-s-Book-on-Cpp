Bellek Yönetimi

Bellek Yönetimi Nedir?

Bellek yönetimi, yazılım program tarafından kontrol edilmeyen ve kontrolu tamamiyle programcıda olduğu veri yapılarının yönetiminidir.
Bellek yani RAM'de bir programcılar olarak özel alanlar istiyebiliriz. Normal şartlarda bellek yönetimi program tarafından yapılır. Program kapsama adı verilen ve bizim kod blokları adını veridiğimiz küme parantezlerinde({ ... }) tanımlanan yerel değişkenleri programın kendisi yönetir. Değişken tanımlandığı kod blokları içerisinde aktiflik gösterir taki program akışı değişkenin kod bloklarının sonuna geldiğinde değişkeni serbest yani RAM'e geri verir. Bu durumu bilgisayar özelinden anlatırsak biz programcı olarak değişkenimizi tanımlarken RAM'e "Şu kadar alanda bana yer aç" diye bir komut veriyoruz. RAM'de eğer yer varsa uygun alanı açıyor ve bize erişim sağlıyor ki o erişim bizim değişkenimiz oluyor. Daha sonra o erişim yani değişken üzerine kendimize özel RAM'den tahsis ettirdiğimiz alanda işlemlerimizi gerçekleştiriyoruz. Ardından program o değişkenin kod bloklarının sonuna geldiğinde RAM'e gidip "Bu değişkenle işim bitti. Dolayısıyla bu alan sana geri veriyorum" der ve değişkenimizi RAM geri alır. Bu durum bir nevi ödünç alma ilişkisidir. İhtiyacımız olduğunda RAM'den ödünçlük yer isteriz. RAM verdiği ödünçlük alanda istediğimizi yaparız ve ardından ödünç aldığımız alanı RAM'e geri teslim ederiz. Bu olaylar programcıdan ziyade program tarafında yapılır. Biz sadece tanımlar kullanılır ve geçeriz. Gelin bir örnek yazalım;
#include <iostream>

using namespace std;

int main()
{

    int sayi1 = 12; // Örnek bir sayı tanımladık

    { // Kod blokları içerisinde başka kod blokları açabiliriz.
        cout << "sayi1 = " << sayi1 << endl << endl; // Üst kod bloklarında tanımlanan değişkeni bu kısımda kullanabiliriz

        int sayi2 = 54; // Şimdi bu kod blokları içerisinde bir değişken tanımlayalım
        
        cout << "sayi2 = " << sayi2 << endl << endl; // Ardından kullanalım
    } // sayi2 değişkeninin serbest bırakıldığı yani RAM'e geri verildiği kısım

    cout << "sayi1 = " << sayi1 << endl << endl; // Hala aynı kod blokları içerisinde olduğumuz için sayi1 değişkenini kullanabiliriz
    
    //cout << "sayi2 = " << sayi2 << endl << endl;
    // Fakat sayi2 değişkeni kendi kod bloklarında serbest bırakıldığı için başka kod bloklarında kullanılamaz

    return 0;
}

Çıktısı ise;
Görüceğiniz üzere yerel değişkenler program tarafından yönetilir.
Peki ya biz yönetseydik? Bazı durumlar olucak ve bizim o kod bloklarının içinden başka kod bloklarına veri aktarmamız gerek durumlar elbette olucaktır. İşte bu durumlarda bellek yönetimi devreye gidiyor... Bellek yönetimi asasen programcı tarafından yönetilen bellek demek. Yani değişken tanımlarken biz talimat vericeğiz ve biz yer ayırttıp boşaltacağız. Bu işlemleri ise new ve delete komutları ile gerçekleştiriceğiz. Ayrıca bellek yönetimi direkt olarak işaretçilerden yürür. Bu sebeble Pointerlar konusunda eksiğiniz bulmaması önemle rica olunur. Gelin bir örnek daha yaplım;
#include <iostream>

using namespace std;

int main()
{
    int *sayi2Ptr; // Şimdilik tanımlayalım. 2. kod bloğunda new ile alan açıcağımızda bu değişkene atıcağız. Yoksa program olarak mümkün değil kod blokları arasında veri iletişimi. İşte bu yüzden Pointer'lar bizim en yakın dostumuzdur

    int *sayi1Ptr = new int; // sayi1Ptr adlı bir işaretçi tanımlıyoruz ve new komutu ile RAM'den bir Integer'lık alan talep ediyoruz. New eğer başarılı olursa bize ayrdığı belleğin adresini döndürür. Başarısız olursa bize nullptr döndürür
    if (sayi1Ptr == nullptr) // Eğer başaramazza. Genelde RAM çok dolu olduğunda bellek ayrılma işlemi doğal olarak başarısız olur ve bize new nullptr döndürür. Daha önceki sayfalarda konuştuğumuz gibi nullptr bir felakete yol açmadan hemen önce fark edilip programın durdurulması veya doğru yönetilmesi gerekir
    {
        cout << "Bellek ayrilamadi" << endl; // Hata mesajı

        delete sayi1Ptr; // Ayıramadığı için serbest bırakalım
    }

    // Başarılı bir şekilde ayrılırsa

    *sayi1Ptr = 12; // Atama gerçekleştirelim
    
    { // Başka bir kod bloğu açalım
        cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl << endl; // Hem bellek adresini hemde bellek adresindeki veriyi yazdıralım

        sayi2Ptr = new int(56); // Şimdi new ile sayi2Ptr'yi RAM'de özel alan ayırtalım. Eğer parantezlere bir değer yazarsak, new başarılı olursa direkt atama gerçekleştirir
        if (sayi2Ptr == nullptr) // Kontrol
        {
            cout << "Bellek ayrilamadi" << endl; // Hata mesajı

            delete sayi2Ptr; // Ayıramadığı için serbest bırakalım
        }

        cout << "sayi2Ptr = " << sayi2Ptr << " -> " << *sayi2Ptr << endl << endl;
    } // new ile ayrdığımız için değişken bu kısımda RAM'e geri verilmez

    cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl << endl;
    // Şimdi ikisini beraber bu kod bloklarında kullanabiliriz
    cout << "sayi2Ptr = " << sayi2Ptr << " -> " << *sayi2Ptr << endl << endl;

    delete sayi1Ptr; // Ardından RAM'den ödünç aldığımız alanları RAM'e geri veriyoruz
    delete sayi2Ptr; // ki program bellek hatalarıyla ve sızmalarla karşılaşmasın. Bu tüm new ile ayrılan veriler için geçerlidir

    return 0;
}

Çıktısı;
Artık istediğimiz gibi kullanabiliriz...
İşte bellek yönetimi tamda budur. Bellek yönetimi programcıya mutlak güç verir. Pek tabi büyük güç büyük sorumluluk gerektirir. Eğer gücü kullanıp sorumluluğu yerine getirmezsek RAM'ın gazabına uğrarız. RAM'den ödünç alınan her alan ne olursa olsun program kapanmadın geri verilmelidir. Yoksa RAM gereksiz yere şişer ve o belleklere erişemez hale geliriz. Buda RAM'de eve işgal edip kira dahi ödemeyen bir misafir olur. Bu misafir günümüzde pek önemsemesede eskiden RAM'ler dolayısıyla evler küçüktü. Bu zamanki RAM'leri eski RAM'lerle karşılaştırıcaksak bizim RAM'lerde eskilere göre koca bir megakent. Eski RAM'ler bir nevi küçük bir köy gibi kalıyor. Nasıl Megakentlerde kira vermeyen oturan insanlar önemsemiyorsa şimdiki zamanlarda aynı şekilde bu serbest bırakılmayan RAM alanlarıda aynı şekilde önemsemiyor. Keza eskiden bu durum tam bir baş belasıydı. Ama eğer şimdi o davetsiz misafirlerle ilgilenmezsek yarın bir gün onlar bizi misafir hatta evsiz bile bırakabilir.... Dikkatli olmakla fayda var.

RAM'in Katmanları

RAM'ın belirli başlı katmanlara sahiptir. Bu katmanlar farklı amaçlar doğrultusunda kullanılır. Gelin beraber incelemek için bir görsel gösterelim;

Yazı Katmanı(Text Segment)

Yazı katmanı, programlarımızın derlenmiş hallerinin RAM'de saklandığı kısımdır.
Bu katman salt okunur olarak kullanılır. Yani okunabilir fakat yazılamaz. Bu önemlin amacı canlı olarak çalışan programın içeriğini değiştirilmesini önlemektir. Yani evet programlar sanılınanın aksine SSD veya HDD'de değil RAM'in kendi içindeki yazı katmanında çalışırlar.

Veri Katmanı(Data Segment)

Veri katmanı programda tanımlanan değişkenlerin saklandığı kısımdır.
Tanımlanan değişkenler şekillerine göre bu katmanın alanları olan başlatılmış ve BSS yani başlatılmamış alanlara yazılır. Başlatılmış değişkenler tanımlandığı an itibariyle değeri atanan değişkenlerdir. BSS yani başlatılmamış değişkenler ise tanımlandığı anda tanımlanmayan değişkenlere denir. Gelin bir örnek yapalım;
#include <iostream>

using namespace std;

int main()
{
    int BSS_Degisken; // Veri katmanındaki BSS alanında depolanır

    int baslatilmisDegisken = 23; // Veri katmanındaki başlatılmış alanında depolanır

    cout << "BSS_Degisken = " << BSS_Degisken << endl << endl; // Eğer BSS değişkenlere başlatılmadan erişilmeye çalışınılırsa derleme zamanında rastgele bir değer atanan değeri verir
    cout << "baslatilmisDegisken = " << baslatilmisDegisken << endl << endl;

    return 0;
}
        
Çıktı;

Heap Katmanı(Heap Segment)

Heap katmanında boyutu belli olmayan, programcı tarafından ayrılan değişkenler ve işaretçiler bu katmanda yer alır. Yani bu değişken

int *sayi1Ptr;

Bu katmanda yer alır.

Stack Katmanı(Stack Segment)

Stack katmanı ise boyutu belli olan ve önceden tanımlı veriler yer alır. Yani bu değişken

int sayi1 = 32;

Bu katmanda yer alır.

Segmentation Fault

Segmentation Fault veya katman hatası, bir bellek alanına izinsiz giriş veya nullptr olarak tanımlanan bir işaretçinin bellek adresine erişim çalışmasında gerçekleşen ve programın çökmesiyle sonuçlanan bir hatadır. Gelin bir örnek yazalım;
#include <iostream>

using namespace std;

int main()
{
    int *sayi1Ptr = nullptr; // Bir işaretçiyi kasten nullptr olarak tanımlandık

    cout << "sayi1Ptr = " << *sayi1Ptr << endl << endl; // Erişmeye çalışma ve bam... Program çöker

    return 0;
}

Program sonuç olarak çöker.

New ve Delete Komutları

Sayfanın başında değindiğimiz new ve delete komutlarına değinelim. Bu komutlar bizim bellek yönetimimizde en temel araçlarımızdır. new ile yer ayırtır, delete ile de ayrılan alanları RAM'e geri verilir.
Bir örnek yazalım.

#include <iostream>

using namespace std;

int main()
{
    int *sayi1Ptr = new int(10);

    cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl;

    delete sayi1Ptr;

    return 0;
}

Çıktısı bellek adresi ile "10" olucaktır.
Karşılaştırma açısından birde C programlama dilinde az önce yazdığımız kodun karşılığını yazalım;

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *sayi1Ptr = (int*)malloc(1 * sizeof(int)); // -> new

    *sayi1Ptr = 10;

    printf("%x -> %d\n", sayi1Ptr, *sayi1Ptr);

    free(sayi1Ptr); // -> delete

    return 0;
}


Çıktı aynı olucaktır.
Çıktılar ve amaçlar aynı olsada kullanılan yöntemler birbirinden tamamiyle farklıdır.
C++ programlama dilinde malloc ve free kullanılabilir fakat standartlar doğrultusunda tavsiye edilmez. Çünkü malloc;
  • Dönüş olarak void* gibi bir işaretçi değer döndürür. Bu durum tür güvenliğini tehlikeye atar. Bu sebeble dönüştürme işlemi yapılır.
  • Başarısız olursa NULL döndürür ki NULL bir nevi sıfır demektir.
  • Tahsis edilmesi gereken alan bayt cinsinden belirtilmelidir. Bu sebeble "1 * sizeof(int)" kolaylık açısından yazılır.
  • Dizi tanımlamak için herhangi bir yardımcı yoktur.
Gibi sebeblerden dolayı modern C++ kodlarında malloc kullanılmaz. new'i ele alıcaksak eğer;
  • Dönüş tipi olarak, tanımlanan türün işaretçisini döndürür. Ekstra dönüştürmeye gerek yoktur.
  • Başarısız olursa nullptr döndürür.
  • Tahsil edilmesi gereken alanın belirtilmesine gerek yoktur.
  • Dizi tanımlamak için yardımıcısı bulunur.
Gibi nedenlerde dolayı new C++ programlama dilinde bellek yönetimi için birer standarttır.

Dizi Tanımlama

Tekli veriler tanımlayabiliyoruz da dizi neden tanımlayamamalım? new tur[elemanSayisi] şeklinde dizi tanımlanır ve delete[] ile serbest bırakılır.
Gelin bir örnek yapalım;

#include <iostream>

using namespace std;

int main()
{
    int *sayilar = new int[4]; // 4 elemanlı bir dizi tanımladık

    *sayilar = 10; // Değerler atadık
    *(sayilar + 1) = 20;
    *(sayilar + 2) = 30;
    *(sayilar + 3) = 40;

    cout << "sayilar dizisinin elemanlari;" << endl; // Bellek adresleriyle yazdırdık
    for (int i = 0; i < 4; i++)
    {
        cout << &sayilar[i] << " -> " << *(sayilar + i) << endl;
    }
    cout << endl;

    delete[] sayilar; // Serbest bıraktır

    return 0;
}

Çıktı;

Akıllı İşaretçiler ile Bellek Yönetimi

Akıllı işaretçilerle bellek yönetimi sıklıkla kullanılırlar. Örnek olması açısından akıllı işaretçiler konusundaki unique_ptr'i bellek yöntemiyle beraber yazalım;
#include <iostream>
#include <memory>

using namespace std;

class ornekClass
{
    public:
        int *s;

        ornekClass()
        {
            s = new int;
        }
        ~ornekClass()
        {
            delete s;
        }
};

int main()
{
    unique_ptr<ornekClass> sayi1 = unique_ptr<ornekClass>(new ornekClass()); // İçini new ile değiştirdik
    *sayi1->s = 123; // Değer atadık

    cout << "sayi1'deki s'in degeri; " << *sayi1->s << endl << endl;

    //ornekClass* sayi2 = sayi1; Bu tarz bir kullanıma izin vermez
    unique_ptr<ornekClass> sayi2 = move(sayi1); // Taşıma ile verileri aktardık
    cout << "sayi2'deki s'in degeri; " << *sayi2->s << endl << endl;

    return 0;
}

Çıktısı ise fakat yöntemi farklıdır.

Placement New

Placement New yani belirli alanda New işlemi, new komutunun bir kullanım tarafıdır. new parantezlerine belirtilen bellek alanında istenilen bellek tahsisin gerçekleştiren bir yöntemdir.
Gelin bir örnek yapalım;

#include <iostream>

using namespace std;

int main()
{
    char *belirliBirAlan = new char[8]; // 8 baytlık bir alan tahsis ettik

    int *sayi1 = new(belirliBirAlan) int(100); // 4 baytlık alanın 1. 4 baytlık alanına bir Integer tanımladık ardından 100 değerini atadık

    float *ondalikli1 = new(belirliBirAlan + 4) float(50.5f); // Aynı şekilde bir Float tanımladık. belirliBirAlan'a 4 ekledik çünkü Integer'ın için ayırdığımız bölgeyi işgal etmesin

    // Ardından hepsini yazdıralım
    cout << "sayi1 = " << sayi1 << " -> " << *sayi1 << endl;
    cout << "ondalikli1 = " << ondalikli1 << " -> " << *ondalikli1 << endl;

    delete belirliBirAlan; // Delete işleminde ana alan faz alınır

    return 0;
}

Çıktısı;

Bellek Hataları

Geldik şimdi büyük güçte sorumluğumuzu yerine getirmezsek olacaklardan biraz bahsedelim. Bellek hataları, programcının kendine özel RAM'de açtığı alanları doğru kullanmadığı zamanlarda ortaya çıkan; Veri kaybı, program çökmesi veya başka programları bozma gibi kötü sonuçlanan durumlardır. Genel olarak sıklıkla yapılan hatalar şunlardır;

Dangling Pointer

Dangling Pointer yada sarkan işaretçi, bir değişkene ayrılmış alanın RAM'e geri verildikten sonra tekrar erişmeye işleminde oluşan bir hatadır. Erişilmeye çalışıldığında ya rastgele bir değer yada programın çökmesiyle sonuçlanır.
Gelin bir örnek yazalım;

#include <iostream>

using namespace std;

int main()
{
    int *sayi1Ptr = new int(12); // Kendimize RAM'den alan açtık

    cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl << endl; // Bellek adresi ile beraber yazalım

    delete sayi1Ptr; // Bu kısımdan itibariyle sayi1Ptr erişilmeye çalışıldığında sarkan işaretçi hatası oluşur

    cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl << endl; // Rastgele bir değerle sonuçlanır

    int *sayi2Ptr = nullptr; // Bir işaretçiyi nullptr olarak tanımlayalım

    cout << "sayi2Ptr = " << sayi2Ptr << " -> " << *sayi2Ptr << endl << endl; // Program anaında çöker

    return 0;
}

Çıktısı ise;

Buffer Overflow

Buffer Overflow veya bellek taşması, bir yapının alabilceğinden daha fazla üzerine veri yazdırmadan kaynaklanan, sonuç olarakda başka programların bellek alanlarına izinsiz yazma işlemi gerçekleştirip programların çökmesine neden olabilcek bir bellek hatasıdır. Genelde kullanıcı veri girişlerine veya liste boyutu aşımlarında beydana gelir.
Gelin bir örnek daha yapalım;

#include <iostream>

using namespace std;

int main()
{
    int sayilar[10]; // 10 Integer'lık bir dizi tanımladık

    for (int i = 0; i < 11; i++) // For döngüsü ile 11 eleman yazdırarak Buffer Overflow yaptırıyoruz. Yani başkalarının alanına giriyoruz
    {
        sayilar[i] = i; // Atama işlemi
    }
    
    cout << "sayilar dizisinin elemanlari;" << endl;
    for (int i = 0; i < 11; i++)
    {
        cout << "sayilar[" << i << "] = " << sayilar[i] << endl; // Yazdıralım
    }
    cout << endl;

    // Çıktıda 10. Index yani 11. elemanında göründüğünü görürüz. Ama bizim dizimiz 10 elemanlık. Şuan 11. eleman başkasının bellek alanında ve buda Buffer Overflow demektir!!!

    return 0;
}

Çıktı;

Memory Leak

Memory Leak veya bellek sızıntısı, kendimize özel ayırdığımız alanları geri RAM'e verilmediğinde ortaya çıkan ve metaforunu yaptığımız hatadır. Bu hata dediğimiz gibi davetsiz bir misafir gibi RAM'imizi doldurabilir hatta ev sahibi konumumuzda bizi evden bile kovabilir.
Gelin bir davetsiz misafiri RAM'imize konduralım;
 
#include <iostream>

using namespace std;

int main()
{
    int *sayi1Ptr = new int(10);
 
    cout << "sayi1Ptr = " << sayi1Ptr << " -> " << *sayi1Ptr << endl << endl;

    return 0; // sayi1Ptr RAM'e geri verilmediği için şuan bir davetsiz misafir!!!!
}

RAM'de İletişim(Shared Memory)

RAM'de iletişim, program arası RAM'de özel bir yer açıp aynı yerde veri paylaşımı yapabildikleri bir yöntemdir.
Bu durum asasen aynı odayı birden fazla kişinin kalma durumuna benzetebiliriz. Programlar paylaştıkları alanlarında diğer programlarla konuşabilir veya veri alışverişi gerçekleştirebilir. Böylelikle programlar arası iletişim ağ oluşur ve herkes istediği veri için programa mesaj atıp aldığı veriyi kullanabilir. Bu mesaj hatlarına Pipe yani boru denir.

Linux'da RAM'de İletişim

Linux'da Shared Memory yapabilmek için sıkça karşımıza çıkaçak ve çokça işimize yarıcak olan POSIX yani Portable Operating System Interface(Taşınabilir İşletim Sistemi Arayüzü) kütüphanesi Unix'e benzer işletim sistemlerinde(BSD, Linux, MacOS gibi) işletim sisteminin işlevlerini kolaylaştıran ve bir arayüz sunan bir araçtır. POSIX, dosya işlemlerinden internete, bellek işlemlerine kadar geniş bir yelpazede Unix benzeri işletim sistemlerine bir arayüz sağlıyarak daha kolay kod yazmayı sağlar.
Linux'da iki program arasında RAM'de iletişim için Programlar ARası İletişim Ağı yani PARIA sistemini kodlıyalım;

main.cpp
#include <iostream>

#include <sys/shm.h> // Shared Memory açmamızı sağlayan kütüphaneler
#include <sys/mman.h>
#include <fcntl.h>
#include <unistd.h>

#include <string.h> // strcmp için gerekli C kütüphanesi

using namespace std;

int main()
{
    while (1) // Döngü içerisinde bir sistem olsun ki sürek yeniden başlatmak zorunda kalmıyalım
    {
        cout << "1: PARİA Hattı Kur" << endl;
        cout << "2: PARİA Hattına Katıl" << endl;
        cout << "0: Çıkış" << endl;
        cout << "-->"; // Kullanıcıya bir seçimli menü sunduk

        int inp1 = 0;
        cin >> inp1; // Girdiyi aldık

        if (inp1 == 1) // Kullanıcı PARİA hattı kurmak isterse
        {
            cout << endl;

            cout << "PARİA Hattının İsmi; ";
            string inp2; // Kurulacak PARİA hattının ismini tutacak değişken
            cin >> inp2; // Girdi alma

            cout << endl;

            cout << "PARİA Akışı Kuruluyor..."; // Kullanıcıyı bilgilendirme

            int paria = shm_open(inp2.c_str(), O_CREAT | O_EXCL | O_RDWR, 06660); // shm_open, Shared Memory için dosya akışı açar. Dosya işlemlerinde dosya akışları daha detaylı işlenicektir
            // inp2.c_str(); Açılacak Shared Memory'nin ismi
            // O_CREAT | O_RDWR; Açılacak olan Shared Memory'nin açılma izinleridir
            //  O_CREAT: Oluştur
            //  O_EXCL: Zaten mevcutsa hata ver
            //  O_RDWR; Hem okuma hemde yazma
            // 06660; Açılma modudur

            if (paria < 0) // shm_open başarısız olursa negatif bir sayı döndürür
            {
                shm_unlink(inp2.c_str()); // shm_unlink, shm_open ile oluşturulan Shared Memory dosya akışlarını kapatmamızı sağlar

                cout << "HATA" << endl; // Hata mesajı

                cout << "PARİA AKIŞI KURULAMADI. BU İSİMLE BAŞKA BİR HAT VAR VEYA GEÇERSİZ BİR İSİM GİRDİNİZ!!!" << endl << endl; // Hata mesajı

                continue; // Döngü tekrar döner
            }
            else // Eğer başarılı ise
            {
                cout << "OK" << endl << endl;
            }
            
            cout << "PARİA Akışı Biçimlendiriliyor...";

            ftruncate(paria, 129); // Açılan dosya akışlarını dolayısıyla bizim Shared Memory'mizin biçimlendirmemizi sağlar
            // paria; Dosya akşını, şuanlık bizim için Shared Memory
            // 129; Verilicek boyut, 129 baytlık bir alan açtırdım fakat isterseniz daha fazla açtırtabilirsiniz. Eğer yazma işleminde bu sınır aşılırsa Buffer Overflow yaşanır

            cout << "OK" << endl << endl;

            cout << "PARİA Akışı Belleğe Eşleniyor...";

            char *pariaBellegi = (char*)mmap(NULL, 129, PROT_WRITE, MAP_SHARED, paria, 0); // Bu işlem açılan dosya akışlarını belleğe eşlemek için kullanılan bir komuttur
            // NULL; Boş kısım
            // 129; Belleğe eşlinilecek boyut
            // PROT_WRITE; Yazılabilir
            // MAP_SHARED; Paylaşımlı
            // paria; Dosya akışı, şuanlık bizim için Shared Memory
            // 0; 2. Boş kısım

            cout << "OK" << endl << endl;

            cout << "PARİA AKIŞI OLUŞTURULMUŞTUR...(Devam etmek için bir tuşa basıp Enter'a basın)" << endl; // Bildirme

            cin >> inp2;

            cout << endl;

            continue;
        }
        else if (inp1 == 2) // Kullanıcı bir PARİA Hattına katılmak isterse
        {
            cout << endl;

            cout << "PARİA Hattının İsmi; ";
            string inp2 = "";
            cin >> inp2;

            cout << endl;

            cout << "PARİA Akışına Katılınıyor...";

            int paria = shm_open(inp2.c_str(), O_RDWR, 06660);

            if (paria < 0)
            {
                shm_unlink(inp2.c_str());

                cout << "HATA" << endl;

                cout << "PARİA AKIŞINA KATILINAMADI. İSİMLE BİR HAT BULUNAMADI" << endl << endl;

                cin >> inp2;

                cout << endl;

                continue;
            }
            else
            {
                cout << "OK" << endl << endl;
            }
            
            cout << "PARİA Akışı Biçimlendiriliyor...";

            ftruncate(paria, 129);

            cout << "OK" << endl << endl;

            cout << "PARİA Akışı Belleğe Eşleniyor...";

            char *pariaBellegi = (char*)mmap(NULL, 129, PROT_WRITE, MAP_SHARED, paria, 0);

            cout << "OK" << endl << endl;

            cout << "PARİA Akışına Katılınıldı..." << endl << endl;

            string inp3; // Girdiler için

            while (1) // Sonsuz döngü olsun ki mesaj akışı gerçekleşsin
            {
                cout << "1: Mesaj Al" << endl;
                cout << "2: Mesaj Yaz" << endl;
                cout << "0: PARİA Akışından Çık ve Sil" << endl;
                cout << "-->"; // Seçimli menü ekranı

                cin >> inp1; // Bellek tasarufu için inp1'i kullan

                if (inp1 == 1) // Mesaj yaz denirse
                {   
                    if (!strcmp(pariaBellegi, "")) // Strcmp, iki char dizisi ifadeyi karşılaştırır. Aynı ise 0, değil ise 1 değer döndürür
                    { // Mesaj yoksa
                        cout << endl  << "Bir mesaj bulunamamıştır..." << endl << endl;
                    }
                    else // Mesaj varsa
                    {
                        cout << endl << "Mesaj; " << pariaBellegi << endl << endl; // Mesajı yaz

                        memset(pariaBellegi, 0, 129); // Mesaj kısmını sıfırla. Memset C dilinde bir bellek alanının belirtilen alan kadar sıfırlanmasını sağlar
                        // pariaBellegi; Bellek alanı
                        // 0; Sıfırlanması için üstüne yazılacak olan karakterin ASCII kodu
                        // 129; Sıfırlanacak alan
                    }
                }
                else if (inp1 == 2) // Mesaj yazmak istenirse
                {
                    cout << endl << "Mesaj: ";

                    cin >> inp3;

                    snprintf(pariaBellegi, 128, "%s", inp3.c_str()); // Snprintf, C dilinde Char dizelerine formatlı bir şekilde char dizesi yazdırmamızı sağlar
                    // pariaBellegi; Yazılacak char dizesi
                    // 128; Boyutu
                    // "%s"; Format
                    // inp2.c_str(); Formatın içerisinde olucak olan değer

                    cout << "Mesaj yazıldı..." << endl << endl;
                }
                else if (inp1 == 0) // Çıkmak isterse
                {
                    cout << "Çıkılıyor...";

                    munmap(pariaBellegi, 129); // Shared Memory için ayrıldığımız alanı tekrar RAM'e geri verir
                    shm_unlink(inp2.c_str());

                    cout << "OK" << endl;
                    
                    cin >> inp2;

                    cout << endl;

                    break;
                }
                else
                {
                    cout << "Geçersiz Bir Seçim Girdiniz!" << endl << endl;
                }
                
            }
        }
        else if (inp1 == 0) // Çıkmak istenirse
        {
            break; // Döngüyü kır
        }
        else
        {
            cout << "Geçersiz Bir Seçim Girdiniz!" << endl << endl;
        }
    }

    return 0;
}

Windows'da RAM'de İletişim

Windows'da RAM'de iletişim Linux'un adımlarıyla aynıdır. Aynı şekilde dosya akışı oluşturulur ve MAP işlemi ile RAM'e bağlanır. Sadece Windows'ın kendi kütüphanesindeki fonksiyon çağrılır.
Aynı şekilde PARİA sistemini Windows içinde kodlıyalım;

main.cpp
#include <iostream>

#include <windows.h> // Shared Memmory için gerekli kütüphaneler Windows'un kendi gelen kütüphanesinde yer alır

#include <string.h> // strcmp için gerekli C kütüphanesi

using namespace std;

int main()
{
    SetConsoleCP(CP_UTF8); // Bu ayarlamalar
    SetConsoleOutputCP(CP_UTF8); // Windows'da Türkçe karakter gözükmeme sorunun çözen ayarlardır. Konsolu Türkçemizinde bulunduğu UTF-8 ayarına getir. Böylelikle harfler bozuk gözükmez

    while (1) // Döngü içerisinde bir sistem olsun ki sürek yeniden başlatmak zorunda kalmıyalım
    {
        cout << "1: PARİA Hattı Kur" << endl;
        cout << "2: PARİA Hattına Katıl" << endl;
        cout << "0: Çıkış" << endl;
        cout << "-->"; // Kullanıcıya bir seçimli menü sunduk

        int inp1 = 0;
        cin >> inp1; // Girdiyi aldık

        if (inp1 == 1) // Kullanıcı PARİA hattı kurmak isterse
        {
            cout << endl;

            cout << "PARİA Hattının İsmi; ";
            string inp2; // Kurulacak PARİA hattının ismini tutacak değişken
            cin >> inp2; // Girdi alma

            cout << endl;

            cout << "PARİA Akışı Kuruluyor..."; // Kullanıcıyı bilgilendirme

            HANDLE pariaHandle = CreateFileMappingA(INVALID_HANDLE_VALUE, NULL, PAGE_READWRITE, 0, 129, inp2.c_str()); // POSIX'deki shm_open'e eş değerdir
            // INVALID_HANDLE_VALUE; Dosya sayfalama yapma
            // NULL; Varsayılan güvenlik ayarları
            // PAGE_READWRITE; Yazma ve okuma izni
            // 0; Boyutunun en üsteki DWORD'u
            // 129; İstenilen alan (129 karakterlik bir Char)
            // inp2.c_str(); Açılacak olan Shared Memory'nin ismi

            // Fark etti iseniz POSIX'de bir dosya akışı tanımlarken Windows'da HANDLE adı verilen bir yapı tanımladık. Nedeni bilinmez Windows API'larının neredeyse hepsi HANDLE denilen bir tür ile yürütülür. Bu sebeble Shared Memory için bir HANDLE tanımladık. Fakat POSIX'deki mantıkla hiç bir farklığı yoktur

            if (pariaHandle == NULL) // CreateFileMappingA başarısız olursa NULL döndürür
            {
                CloseHandle(pariaHandle); // shm_unlink yerine CloseHandle kullanılır

                cout << "HATA" << endl; // Hata mesajı

                cout << "PARİA AKIŞI KURULAMADI. BU İSİMLE BAŞKA BİR HAT VAR VEYA GEÇERSİZ BİR İSİM GİRDİNİZ!!!" << endl << endl; // Hata mesajı

                continue; // Döngü tekrar döner
            }
            else // Eğer başarılı ise
            {
                cout << "OK" << endl << endl;
            }
            
            // Windows'da POSIX'deki biçimlendirme komutu gerekmez. Bunun sebebi Windows'un kendisine göre biçimlendirmesidir

            cout << "PARİA Akışı Belleğe Eşleniyor...";

            char *pariaBellegi = (char*)MapViewOfFile(pariaHandle, FILE_MAP_ALL_ACCESS, 0, 0, 129); // POSIX'deki mmap'e takbul gelir
            // pariaHandle; Belleğe eşlenicek olan akışın Handle'ı
            // FILE_MAP_ALL_ACCESS; Okuma ve yazmaya izin ver
            // 0; Yüksek mertebeden kaydırma
            // 0; Düşük mertebeden kaydırma
            // 129; Belleğe eşlenicek olan belleğin boyutu

            cout << "OK" << endl << endl;

            cout << "PARİA AKIŞI OLUŞTURULMUŞTUR...(Devam etmek için bir tuşa basıp Enter'a basın)" << endl; // Bildirme

            cin >> inp2;

            cout << endl;

            continue;
        }
        else if (inp1 == 2) // Kullanıcı bir PARİA Hattına katılmak isterse
        {
            cout << endl;

            cout << "PARİA Hattının İsmi; ";
            string inp2 = "";
            cin >> inp2;

            cout << endl;

            cout << "PARİA Akışına Katılınıyor...";

            HANDLE pariaHandle = CreateFileMappingA(INVALID_HANDLE_VALUE, NULL, PAGE_READWRITE, 0, 129, inp2.c_str());

            if (pariaHandle == NULL)
            {
                CloseHandle(pariaHandle);

                cout << "HATA" << endl;

                cout << "PARİA AKIŞINA KATILINAMADI. İSİMLE BİR HAT BULUNAMADI" << endl << endl;

                cin >> inp2;

                cout << endl;

                continue;
            }
            else
            {
                cout << "OK" << endl << endl;
            }

            cout << "PARİA Akışı Belleğe Eşleniyor...";

            char *pariaBellegi = (char*)MapViewOfFile(pariaHandle, FILE_MAP_ALL_ACCESS, 0, 0, 129);

            cout << "OK" << endl << endl;

            cout << "PARİA Akışına Katılınıldı..." << endl << endl;

            string inp3; // Girdiler için

            while (1) // Sonsuz döngü olsun ki mesaj akışı gerçekleşsin
            {
                cout << "1: Mesaj Al" << endl;
                cout << "2: Mesaj Yaz" << endl;
                cout << "0: PARİA Akışından Çık ve Sil" << endl;
                cout << "-->"; // Seçimli menü ekranı

                cin >> inp1; // Bellek tasarufu için inp1'i kullan

                if (inp1 == 1) // Mesaj yaz denirse
                {   
                    if (!strcmp(pariaBellegi, "")) // Strcmp, iki char dizisi ifadeyi karşılaştırır. Aynı ise 0, değil ise 1 değer döndürür
                    { // Mesaj yoksa
                        cout << endl  << "Bir mesaj bulunamamıştır..." << endl << endl;
                    }
                    else // Mesaj varsa
                    {
                        cout << endl << "Mesaj; " << pariaBellegi << endl << endl; // Mesajı yaz

                        memset(pariaBellegi, 0, 129); // Mesaj kısmını sıfırla. Memset C dilinde bir bellek alanının belirtilen alan kadar sıfırlanmasını sağlar
                        // pariaBellegi; Bellek alanı
                        // 0; Sıfırlanması için üstüne yazılacak olan karakterin ASCII kodu
                        // 129; Sıfırlanacak alan
                    }
                }
                else if (inp1 == 2) // Mesaj yazmak istenirse
                {
                    cout << endl << "Mesaj: ";

                    cin >> inp3;

                    snprintf(pariaBellegi, 128, "%s", inp3.c_str()); // Snprintf, C dilinde Char dizelerine formatlı bir şekilde char dizesi yazdırmamızı sağlar
                    // pariaBellegi; Yazılacak char dizesi
                    // 128; Boyutu
                    // "%s"; Format
                    // inp2.c_str(); Formatın içerisinde olucak olan değer

                    cout << "Mesaj yazıldı..." << endl << endl;
                }
                else if (inp1 == 0) // Çıkmak isterse
                {
                    cout << "Çıkılıyor...";

                    UnmapViewOfFile(pariaBellegi); // POSIX'deki unmmap fonksiyonuna tekabul gelir
                    CloseHandle(pariaHandle);

                    cout << "OK" << endl;
                    
                    cin >> inp2;

                    cout << endl;

                    break;
                }
                else
                {
                    cout << "Geçersiz Bir Seçim Girdiniz!" << endl << endl;
                }
                
            }
        }
        else if (inp1 == 0) // Çıkmak istenirse
        {
            break; // Döngüyü kır
        }
        else
        {
            cout << "Geçersiz Bir Seçim Girdiniz!" << endl << endl;
        }
    }

    return 0;
}
