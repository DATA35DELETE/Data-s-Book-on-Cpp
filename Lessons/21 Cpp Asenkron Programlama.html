Asenkron Programlama

Asenkron Nedir?

Asenkron, aynı zamanda birden fazla işi yapabilme yeteneğine denir. Asenkron programlama ise bu eylemin yazılımsal karşılığıdır. Asenkronun tersi ise senkrondur. Senkron ise aynı anda bir çok işi sırayla yapabilme yeteneğidir.
Peki neden Asenkron programlama? Şuan ki uygulamalarda pek ihtiyacımız olmasa gelecek sayfalarda sıklıkla danışıcağımız olan bu kavram, bir yandan pencereleri görüntülerken bir yanda da ağ alışverişlerini yapabilmemizi sağlar. Çünkü programlar doğaları gereği birden fazla işi sırayla yaparlar ki program akışı bu sebeble var olmuştur. Fakat bazenler aynı zaman içerisinde birden fazla iş yapmamız gerekir. Örnek olarak verdiğim uygulama ise bir mesajlaşma uygulaması örneğidir. İlk "pencere" dediğimiz şey aslında bilgisayar veya telefonlarımızdaki uygulamaların görünümleridir. Her uygulamanın bir penceresi yoktur ama her pencerenin arkasında bir uygulama vardır. İşte bu pencereleri görüntülemek veya işlemek için kullanılan sistemler senkrondur. Yani pencere görüntülernirken başka bir iş yapamayız. Tabi senkron bir sistemde... Eğer uygulamda hem pencere hemde ağ işlemleri olucaksa asenkron olarak tasarlanırlar. Bir kısım pencereyi işlerken diğer kısım ise ağ işlemlerini halleder gibi gibi. Yani Asenkron programlama biz insanlar için ikinci veya üçüncü kol gibidir.

Thread Nedir?

Thread veya iş parçacığı, bir işlem yani Process içerisindeki program akışlarına denir. Process ise bir veya birden fazla program akışı içeren ve Thread topluğudur. Process çoğu zaman bir uygulamadır.

C++ Asenkron Programlama

C++ programlama dilinde asenkron programlama işlemleri std::thread kütüphanesi üzerinden yapılmaktadır. C programlama dilinde işletim sistemlerine özel koldar yazılırken C++ bu konuda tamamiyle platformlar arasıdır.

Thread Oluşturma

Şimdi örnek olarak bir Thread oluşturalım;

#include <iostream>
#include <thread> // Thread kütüphanemiz

using namespace std;

void asenkronBirFonksiyon(int x) // Asenkron fonksiyonumuz
{
    cout << "Asenkron program akisinde su parametre girildi: " << x << endl << endl;
}

int main()
{
    cout << "Asenkron fonksiyon baslatildi" << endl << endl;

    thread asenkronFonk(asenkronBirFonksiyon, 12); // Nesne üzerinden başlatılır. Fonksiyon parametre içeriyorsa virgülden sonra yazılır

    asenkronFonk.join(); // Bitmesini bekle. Normal şartlarda beklenmez lakin kurallar gereği uygulamalarda ana Thread olan Main fonksiyonu bittiği an o Process'deki tüm Thread'ler kapatılır
    // asenkronFonk.detach(); istersekde ayırabiliriz ama bahsettiğim kurallardan dolayı bu durum pekde işe yaramaz

    cout << "Asenkron fonksiyon bitti" << endl;

    return 0;
}

Thread Bekletmek

Thread bekletmek, belirli bir sürede Thread'i durdurmak için kullanılan bir metodtur. C++ programlama dilinde bunun için this_thread::sleep_for kullanılır.
Kodumuzu geliştirmek adına gecikmeli biten iki adet Thread yapalım;

#include <iostream>
#include <thread>

using namespace std;

void birinciThread()
{
    cout << "1. Thread basladi!" << endl << endl;

    this_thread::sleep_for(500ms);// 500 milisaniye beklettik. Saniye karşılığı 0.5 saniyedir

    cout << "1. Thread bitti!" << endl << endl;
}

void ikinciThread()
{
    cout << "2. Thread basladi!" << endl << endl;

    this_thread::sleep_for(2s); // 2 saniye beklettik

    cout << "2. Thread bitti!" << endl << endl;
}

int main()
{
    cout << "Ana Thread basladi" << endl << endl;

    this_thread::sleep_for(2s); // 2 saniye ana Thread'i beklettik

    thread birinciT(birinciThread);
    thread ikinciT(ikinciThread);
    // Thread'leri başlattık

    birinciT.join();
    ikinciT.join();
    // Thread'leri bekle

    cout << "Ana Thread bitti" << endl << endl;

    return 0;
}

Veri Yarışı Hatası

Bu hata genelde eş zamanlı olarak iki veya ikiden fazla Thread'in aynı anda bir bellek alanına yani değişkene erişmeye çalışması sonucunda oluşan ve programın kararsız hareket etmesiyle sonuçlanan bir durumdur.
Şimdi veri yarışı sorunu olan bir program yazalım;

#include <iostream>
#include <thread>

using namespace std;

int* veri; // Veri işaretçisi

void thread1()
{
    for (int i = 0; i < 1000; i++)
    {
        ++(*veri);

        this_thread::sleep_for(1ms); // Zaman faktörü
    }
}

int main()
{
    veri = new int(10); // Veriyi oluşturduk

    thread birinciT(thread1);
    thread ikinciT(thread1);

    birinciT.join();
    ikinciT.join();

    cout << "*veri = " << *veri << endl; // Her çalıştırmada farklı veriler gelir

    delete veri;

    return 0;
}

Bu sorunu düzeltmek için C++ programlama dilinde std::mutex ve std::lock_guard kullanılır.

Hadi veri yarışını bitirelim;

#include <iostream>
#include <thread>
#include <mutex> // Mevzu bahis kütüphanemiz

using namespace std;

mutex erisimKontrol; // Aynı andaki erişimleri kontrol edecek genel bir Mutex nesnesi
int* veri; // Veri işaretçisi

void thread1()
{
    erisimKontrol.lock(); // Erişim kontrolunu açıyoruz. Lock ifasesi bu kısımda "Aynı andaki erişimleri kitle" anlamına gelir

    for (int i = 0; i < 1000; i++)
    {
        ++(*veri);

        this_thread::sleep_for(1ms);
    }

    erisimKontrol.unlock(); // Kilidi açıyoruz
}

int main()
{
    veri = new int(10);

    thread birinciT(thread1);
    thread ikinciT(thread1);

    birinciT.join();
    ikinciT.join();

    cout << "*veri = " << *veri << endl; // Her çalıştırmada artık sabit bir değer geliyor

    delete veri;

    return 0;
}

Artık yarışımız bitmiştir.

Koşullu Thread Bekletme

Belirli bir koşula bağlı olarak bir Thread'leri bekletebiliriz. Bu yöntem için C++ programlama dilindeki std::condition_variable kullanılır.
Hadi bir örnek daha yapalım;

#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable> // Koşullu bekletmek için kütüphanemiz

using namespace std;

// Klasik ama bir zamanlayıcı örneği yapabiliriz

mutex mtx; // Veriyi yarışı için
condition_variable genelBekletme; // Bekletme nesnemiz

bool ikinciAsamaKosulu = false;

void birinciAsama()
{
    lock_guard<mutex> kitlemeHatti(mtx); // Lock sistemi ile kitlemeler üzerinden iletişim kurulur

    this_thread::sleep_for(2s); // 2 saniye bekle

    ikinciAsamaKosulu = true; // İkinci aşama için true yap

    genelBekletme.notify_one(); // Bildirimde bulun. Eğer bekliyenler varsa(ki bekliyorlar) Callback tarzı bir uyarımda bulunur
}

void ikinciAsama()
{
    unique_lock<mutex> kitlemeHatti(mtx); // Benzersiz kitleme hattı kur

    genelBekletme.wait(kitlemeHatti, [] {return ikinciAsamaKosulu;}); // Kosulu bekle

    cout << "Ikinci asamaya gecildi" << endl << endl;
}

int main()
{
    thread t1(birinciAsama);
    thread t2(ikinciAsama);

    t1.join();
    t2.join();

    return 0;
}
    
Böylelikle fonksiyonlar birbirlerini beklerler.

Atomik Değişkenler

Son olarak atomik değişkenler ise veri yarışını değişken tarafında engelliyen araçlardır. atomic kütüphanesinde yer alırlar.
Şimdi atomik bir değişken ile örnek yapalım;

#include <iostream>
#include <thread>
#include <atomic> // Kütüphanemiz

using namespace std;

atomic<int> *veri; // Template ile atomik değişkenler oluşturulur

void thread1()
{
    for (int i = 0; i < 1000; i++)
    {
        ++(*veri);

        this_thread::sleep_for(1ms);
    }
}

int main()
{
    veri = new atomic<int>;

    thread birinciT(thread1);
    thread ikinciT(thread1);

    birinciT.join();
    ikinciT.join();

    cout << "*veri = " << *veri << endl; // Her çalıştırmada stabildir

    delete veri;

    return 0;
}

Async ve Future

Async ve Future, C++11 standartı ile bir Thread oluşturmayı son derece kolay ve basitleştiren iki araçtır. Async asenkron olarak fonksiyonları çalıştırdığında bir Future türü döner. Futur üzerinden oluşturulan asenkron fonksiyon yönetilir hatta döndürdüğü değer alınabilir. Kütüphanesi future'dır.
Şimdi kullanımlarını görmek için bir örnek yazalım;

#include <iostream>
#include <thread>
#include <future> // Kütüphanemiz

using namespace std;

void ikiArtiIki() // Düz fonksiyonumuz
{
    cout << "2 + 2 = " << 4 << endl;
}

float cikar(float x, float y) // Hem parametreli hemde dönüşlü fonksiyonumuz
{
    return x - y;
}

int main()
{
    future<void> asenkronIslem1 = async(launch::async, ikiArtiIki); // Normal ve bağımsız çağrı
//     |  |-> İşlemin dönüş tipi   |     |        |-> Fonksiyon ismi
//     v                           v     |-> Bağımsız Çalıştır
// Sınıfımız                     Fonksiyon

    this_thread::sleep_for(1s); // Aralarında 1 saniyelik fark olsun. Çünkü hepsi asenkron olduğu için çıktılar karışırlar

    future<float> asenkronIslem2 = async(launch::async, cikar, 4.2f, 3.12f);
//                                                         |-> Fonksiyon isminden sonrakinler paramtrelerdir

    cout << "4.2f - 3.12f = " << asenkronIslem2.get() << endl; // Dönen değeri alıyoruz.
// asenkronIslem2.get(); Fakat ikinci kez alamayız

    // Lambda işlemler

    this_thread::sleep_for(1s);

    future<void> asenkronIslem3 = async(launch::async,
    [] () 
    {
        cout << "54 / 6 = " << 9 << endl;
    });

    this_thread::sleep_for(1s);

    future<int> asenkronIslem4 = async(launch::async,
    [] (int x, int y) 
    {
        return x, y;
    },
    12, 4); // Aynı şekilde Lambda ifadelerde de parametreler bu şekilde yazılır

    cout << "12 * 4 = " << asenkronIslem4.get() << endl;

    return 0;
}
