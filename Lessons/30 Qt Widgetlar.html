Widgetlar

Widget Nedir?

Widget, Qt'de basit görüntü nesnelerine denilen ve Qt'nin başlangıcından beri var olan bir kütüphanedir. Qt Widget veya Widget; Windows ve Linux işletim sistemlerine sorunsuz bir şekilde çalışan grafik nesneleri sunmaktadır.
Kısacası Qt'nin en temeli ve çıkma sebebi olan çapraz platform uygulamalar için pencere yönetimi sunar. Bu sayfada Qt Creator'un Widget'larını inceleyip, ögelerin önemli sinyallerini kodumuza yuvalayarak işlemleri gerçekleştiriceğiz. Bu sebeble "temelWidget" adında bir proje oluşturalım.

Widget Hiyerarşisi

Gösterimlere girmeden önce şu bölmeyi inceleyelim;
Bu görsel bizim .ui dosyamızı açtığımız vakit çıkan sağ üstdeki hiyerarşidir. Çoğu durumda olduğu gibi bu sistemde de bir hiyerarşi vardır. Bu hiyerarşi ögelerin "Kim kimlere ait" sorularına cevap verir. Daha ögeleri yerleştirmedik ama sizler için ben bir kaç tane koydum. Hiyerarşi, bir ağaca benzetilebelir. Bu pencerede, tüm ögelerin "MainWindow" ögesinin altında barındığını, onun altında "centralwidget"'ın bulunduğunu, onun altında ise çeşitli ögelerin bulunduğu ve diğer ögelerinde içlerinde ögelerin olduğunu belirtir. Mantık basit, kimin altındaysa, onun bölgesinin dışına çıkamaz veya görüntülenemezsin. Bu durumda "pencere" ögesinin altındaki "pencereninAltindekiLabel" ögesi "pencere" ögesinin dışına çıkamaz. Çıksa bile uygulamda görüntülenmez. Bu hiyerarşi sayesinde nesnelerin üzerlerine başka nesneler veya sadece düzen için gerekli oynamalar için kullanılır.
Ayrıca bu pencerenin sol tarafı ögelerin isimlerini, sağ tarafı ise mensub oldukları sınıfları belirtir. Örnek olarak "TiklanabilirBtn" ögesi "QPushButton" sınıfına aittir. Birden fazla aynı sınıfta öge bulunabilir ama aynı isimde öge bulunamaz. Bunu bir okul sınıfı metaforu üzerinden anlatırsak; Sizin isminiz "label" olsun ve "QLabel" sınıfındansanız. Tabi sadece siz "QLabel" sınıfından değilsiniz. Başka kişilerde "QLabel" sınıfından ama sınıfta sizden başka "label" ismine sahip bir kişi yok. Öğretmen sınıfa girdiğinde sınıfa, "QLabel" dediğinde "QLabel" sınıfı ona bakarken, "label" dediğinde sadece siz bakarsınız. İşte mantık böyle çalışır. İleride QSS denilen ve Qt'deki Widget'ları süslemek için kullanacağımız olan dil için bu temeller gerekir.

QPushButton

QPushButton, basılabilir bir butondur. Kullanıcı tarafından basıldığında "pressed", tıklama bittiğinde "clicked" sinyallerini verir.
mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots:
    void fareBasti(); // Pressed
    void fareTikladi(); // Clicked

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

#include "mainwindow.h"
#include "./ui_mainwindow.h"

MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    connect(ui->pushButton, &QPushButton::pressed, this, &MainWindow::fareBasti);
    connect(ui->pushButton, &QPushButton::clicked, this, &MainWindow::fareTikladi);
}

MainWindow::~MainWindow()
{
    delete ui;
}

void MainWindow::fareBasti()
{
    qDebug() << "Fare butona bastı" << Qt::endl;
}

void MainWindow::fareTikladi()
{
    qDebug() << "Fare butona tıkladı" << Qt::endl;
}

QLineEdit

QLineEdit, kullanıcıdan tek satırlık bir girdi alabilmek için kullanılır. Kullanıcı QLineEdit'e odaklanıp daha sonra başka bir ögeye tıklarsa "editingFinished", kullanıcı Enter'e basarsa "returnPressed" ve "editingFinished", kullanıcı yazıyı değiştirirse "textChanged" ile değiştirilmiş yazı ile sinyaller verir.
mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots:
    void fareBasti(); // Pressed
    void fareTikladi(); // Clicked

    void lineEditKullaniciYazmaIsiniBitirdi(); // editingFinish
    void lineEditKullaniciEntereBasti(); // returnPressed
    void lineEditYaziDegistirildi(QString yeniYazi); // textChanged

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

QTextEdit

QTextEdit, QLineEdit'in çok satırlı girdi almak için kullanılan versiyonudur. Ancak sadece kullanıcı yazıyı değiştirdiğindeki sinyal olan "textChanged" sinyali verir. Ama kendisi basit Html kodlarını görüntüleyebilen bir araçtır. Evet yazı hemde Html kodu! Html kodu denemesi için bir önceki sayfamın kaynak kodunu kullanıcağız.

QCheckBox

QCheckBox, bizlere seçilebilir kutucuklar sunan bir ögedir. Bir butonun sinyallerine sahip iken kendi sinyali ise "stateChanged" sinyalidir. By sinyal ise öge kutucuktaki tik değiştiğinde tetiklenir ve parametre olarak kutucuğun işaretli ise bir, değil ise sıfır değerini gönderir. Aynı zamanda kutucuğun yanındaki QLabel ile yazı yazılabilir.
mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

public slots:
    void fareBasti(); // Pressed
    void fareTikladi(); // Clicked

    void lineEditKullaniciYazmaIsiniBitirdi(); // editingFinish
    void lineEditKullaniciEntereBasti(); // returnPressed
    void lineEditYaziDegistirildi(QString yeniYazi); // textChanged

    void qtSeverKontrol(int deger); // stateChanged


private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H

QRadioButton

QRadioButton, tıpkı QCheckBox gibi seçilebilir bir buton sunar. Farklı olarak aynı bir Widget ortamında sadece bir adet seçilmiş QRadioButton kabul eder. Bir butonun sinyallerine sahiptir.
mainwindow.h

#ifndef MAINWINDOW_H
#define MAINWINDOW_H

#include <QMainWindow>

QT_BEGIN_NAMESPACE
namespace Ui {
class MainWindow;
}
QT_END_NAMESPACE

class MainWindow : public QMainWindow
{
    Q_OBJECT

public:
    explicit MainWindow(QWidget *parent = nullptr);
    ~MainWindow() override;

    void qtSevenRadioKontrol(); // Kontrol

public slots:
    void fareBasti(); // Pressed
    void fareTikladi(); // Clicked

    void lineEditKullaniciYazmaIsiniBitirdi(); // editingFinish
    void lineEditKullaniciEntereBasti(); // returnPressed
    void lineEditYaziDegistirildi(QString yeniYazi); // textChanged

    void qtSeverKontrol(int deger); // stateChanged

    void qtSevenVeSevmeyenRadio(); // radioButton -> clicked ve radioButton_2 -> clicked

private:
    Ui::MainWindow *ui;
};
#endif // MAINWINDOW_H


mainwindow.cpp

{

    }
    else if (ui->radioButton_2->isChecked())
    {
        qDebug() << "Kullanıcı Qt'yi sevmiyor, :(" << Qt::endl;
    }
}
